LibreTranslate

Developed by LibreTranslate
Open Source Python Global free
ABOUT

LibreTranslate is a free and open-source machine translation API that is entirely self-hosted. Unlike other APIs, it doesn't rely on proprietary providers such as Google or Azure. Instead, its translation engine is powered by the open-source Argos Translate library, delivering a highly private, independent, and secure translation experience.

CAPABILITIES
  • Fully self-hosted for complete data privacy
  • No dependency on proprietary Google or Azure APIs
  • Powered by the open-source Argos Translate engine
  • Provides standard RESTful API and user-friendly Web UI
