ABOUT

DocsGPT is an open-source AI platform by arc53 for building intelligent agents, assistants, and enterprise search. It features a visual Agent Builder, deep research tools, and comprehensive document analysis for formats like PDF, Office, web, and audio. Supporting both cloud APIs and local models (like Ollama), DocsGPT provides secure, private deployment options alongside rich integration capabilities and hallucination-free QA with citations.
