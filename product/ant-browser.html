Ant-Browser

Developed by black-ant
Open Source Go Global free
ABOUT

Ant-Browser is an open-source desktop anti-detect browser designed for multi-account isolation, proxy binding, and environment management. Powered by fingerprint-chromium, it allows users to safely manage multiple isolated browser instances on a single machine. It features independent proxy routing (supporting HTTP/SOCKS5, Xray, and Mihomo chain proxies) and localized fingerprint control. Equipped with automation script capabilities, API endpoints (CDP), and extension management, it is ideal for cross-border e-commerce, social media operations, and automated testing.

CAPABILITIES
  • Deep Environment Isolation & Anti-Fingerprinting
  • Multi-Protocol Proxy Pool & Chain Proxy Support
  • Automation Script Orchestration & Launch API
  • Browser Kernel & Extension Management
  • 100% Localized Storage & Data Privacy Control
