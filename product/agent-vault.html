Open Source Go Global freemium
ABOUT

Agent Vault is an open-source HTTP credential proxy and vault designed for AI agents like Claude Code, OpenClaw, and custom frameworks. Developed by Infisical, it solves the critical issue of credential exfiltration caused by prompt injections. By utilizing a Man-in-the-Middle (MITM) proxy architecture, Agent Vault enables agents to interact with external services without ever holding or reading the actual secrets. It intercepts egress HTTP requests from agents, automatically injects the required credentials, and forwards the secure requests to target services.

CAPABILITIES
  • Credential Brokering
  • MITM Proxy Architecture
  • Zero Code/Prompt Modification
  • Prompt Injection & Exfiltration Defense
