Go Micro is an agent harness and microservice framework for Go. It integrates agents, services, and workflows into a single runtime, treating an agent as a distributed system. Go Micro automatically turns service endpoints into AI-callable tools and supports interoperability via MCP (Model Context Protocol) and A2A protocols. It provides built-in capabilities like model integration, memory, planning, delegation, safety guardrails, and service discovery, allowing developers to build and operate robust, production-ready AI agent systems.

OPEN SOURCE

Agent Vault is an open-source HTTP credential proxy and vault designed for AI agents like Claude Code, OpenClaw, and custom frameworks. Developed by Infisical, it solves the critical issue of credential exfiltration caused by prompt injections. By utilizing a Man-in-the-Middle (MITM) proxy architecture, Agent Vault enables agents to interact with external services without ever holding or reading the actual secrets. It intercepts egress HTTP requests from agents, automatically injects the required credentials, and forwards the secure requests to target services.

OPEN SOURCE

PentAGI is an open-source, autonomous penetration testing AI agent platform developed by vxcontrol. Utilizing a multi-agent orchestration architecture, it automates security testing within isolated Docker sandboxes. It integrates over 20 professional security tools (e.g., nmap, Metasploit, sqlmap) and leverages Neo4j-based knowledge graphs (Graphiti) alongside pgvector for persistent semantic memory. Supporting over 10 LLM providers, PentAGI provides detailed vulnerability reports, comprehensive monitoring, and web intelligence integration.
