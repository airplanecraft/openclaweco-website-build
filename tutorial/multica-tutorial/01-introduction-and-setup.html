第 1 期: Multica 简介与极速安装

3 MIN READ | UPDATED: 2026-06-16

[Translation Pending]\n\n传统的 AI 开发范式中，我们需要去敲各类 Python 文件，拼凑 LangChain、LlamaIndex 的 Pipeline。而使用 Multica 时，这一切不再是写“执行流”，而是变成了带一个“人”。

本章带你快速体验如何将 Multica 接驳到你的工作生态！

🚀 方式一：Multica Cloud (最快！)

对于初学者和那些不想操心服务器运维的极客，最快的开启方式是直接访问云端平台：multica.ai。 点击右上角的 Get Started 并通过 GitHub 或 Google 账号登入。注册后你可以直接拥有一个 Workspace 工作空间。

🚀 方式二：本地研发环境（CLI工具安装）

真正的强力干货在于配置你的本地开发者套件！只有通过 CLI 获取命令行访问权限，你的本地项目环境才能成为 AI 处理工单的安全演练沙盒。

对于 macOS/Linux 玩家，如果你配备了 Homebrew，你可以直接通过 Tap 安装 Multica 终端：

# 1. 挂载官方 tap 源
brew tap multica-ai/tap

# 2. 直接安装客户端
brew install multica

安装完成后，在终端敲击一下：

multica --version

一旦终端正确回显了客户端版本号，那么恭喜你，你的基础架构地基已经夯实了！下一步最核心的一件事情就是：绑定身份！

# 让你的终端连接上你在 Cloud 的云端账号体系
multica login

此时浏览器会弹出一个验证 OAuth 对话框。点击确认后，你的计算机就算正式接入 Multica 云矩阵。

[!TIP] 为什么要 Login？ 因为 Multica 采用客户端 Daemon 守护进程体系，通过 login 会在你的终端缓存一个包含身份密钥的配置记录。之后我们启动 Daemon 接收平台委派的工单时，就会自动做安全握手。
