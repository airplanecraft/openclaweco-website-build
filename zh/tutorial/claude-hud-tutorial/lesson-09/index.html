第 9 期：高级功能

4 分钟阅读 | 更新于：2026-06-16
核心要点总结 // DIRECT SUMMARY

Prompt Cache 倒计时、会话费用、输出速度、会话时长、自定义颜色等进阶功能的完整配置指南。

本期核心：HUD 不只是看上下文条——它还能显示缓存倒计时、费用、速度和更多进阶数据。

9.1 Prompt Cache 倒计时

启用 showPromptCache: true 后：

Cache TTL: 3m 42s

帮助你判断：

  • 还能等多久不用重新付费
  • 是否需要发送一条消息保持缓存活跃
{
  "display": {
    "showPromptCache": true,
    "promptCacheTtlSeconds": 300
  }
}

Pro 用户保持 300（5 分钟），Max 用户设 3600（1 小时）。

9.2 会话费用显示

启用 showCost: true 后：

$0.42

使用 Claude Code 原生 cost.total_cost_usd 字段。

9.3 输出速度

启用 showSpeed: true 后：

out: 42.1 tok/s

实时输出 Token 速率，判断模型响应速度。

9.4 会话时长

启用 showDuration: true 后：

⏱️ 5m

9.5 会话名称

启用 showSessionName: true 后：

fix-auth-bug

显示 session slug 或通过 /rename 设置的自定义名称。

9.6 其他可选信息

功能 配置 显示效果
Claude Code 版本 showClaudeCodeVersion: true CC v2.1.81
内存使用 showMemoryUsage: true RAM: 12.4 GB
项目路径层级 pathLevels: 2 apps/my-project

9.7 上下文显示格式

{ "display": { "contextValue": "percent" } }     // 45%
{ "display": { "contextValue": "tokens" } }      // 45K/200K
{ "display": { "contextValue": "remaining" } }   // 55% remaining
{ "display": { "contextValue": "both" } }         // 45% (45K/200K)

9.8 自定义颜色

支持颜色名、256 色编号（0-255）和十六进制（#FF6600）：

{
  "colors": {
    "context": "cyan",
    "usage": "cyan",
    "warning": "yellow",
    "critical": "red",
    "model": "cyan",
    "project": "yellow",
    "git": "magenta",
    "gitBranch": "cyan",
    "label": "dim",
    "custom": "#FF6600"
  }
}
