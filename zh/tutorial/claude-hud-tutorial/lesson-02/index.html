第 2 期：安装与版本说明

5 分钟阅读 | 更新于：2026-06-16
核心要点总结 // DIRECT SUMMARY

三步安装 Claude HUD 插件，覆盖 macOS、Linux（EXDEV 修复）、Windows 的平台差异，以及插件市场版与 npm 版的功能对比。

本期核心：从零到 HUD 显示只需三步命令，但不同平台有不同的坑。

2.1 前置条件

  • Claude Code v1.0.80+
  • macOS/Linux: Node.js 18+ 或 Bun
  • Windows: Node.js 18+

2.2 三步安装

在 Claude Code 会话内依次运行：

Step 1：添加 marketplace

/plugin marketplace add jarrodwatts/claude-hud

Step 2：安装插件

/plugin install claude-hud

Step 3：配置 statusline

/claude-hud:setup

完成。HUD 立即出现，无需重启。

2.3 Linux 特别说明

Linux 上 /tmp 通常是独立 tmpfs 文件系统，安装会报错：

EXDEV: cross-device link not permitted

修复：设置 TMPDIR 后启动 Claude Code：

mkdir -p ~/.cache/tmp && TMPDIR=~/.cache/tmp claude

然后在该 session 内执行安装命令。

2.4 Windows 特别说明

如果 setup 提示找不到 JavaScript 运行时：

winget install OpenJS.NodeJS.LTS

重启 shell 后重新运行 /claude-hud:setup。

2.5 版本说明

claude-hud 有三个版本号来源，容易混淆：

来源 版本格式 说明
Claude Code 插件市场 0.1.0 /plugin install claude-hud 安装的版本
GitHub Releases 0.0.1 – 0.0.12 源码发布版本，功能逐步增加
npm Registry 1.0.0 / 1.1.0 npm 发布版本，2026-03-10 发布

本教程基于 v0.1.0（插件市场版本）。通过 /plugin install claude-hud 直接安装，最简单。
