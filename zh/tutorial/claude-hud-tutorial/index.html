📊 Claude HUD 完全教程：18 章从入门到精通

基于 jarrodwatts/claude-hud 插件，实时掌握 Claude Code 的上下文用量、Token 消耗、缓存状态、工具活动与 Agent 进度。从三步安装到深度配置，从上下文窗口原理到 Prompt Cache 优化实战，系统讲解 HUD 的每一个显示元素与数据来源。让你从「盲目使用 Claude Code」变成「精确掌控每一步」。

课时目录 // CURRICULUM

课程内容

01

第 1 期：什么是 Claude HUD

一句话了解 Claude HUD 的价值：用原生 statusline API 在终端实时显示会话状态，不需要 tmux，不需要额外窗口。

[3 分钟阅读 // READ →]
02

第 2 期：安装与版本说明

三步安装 Claude HUD 插件，覆盖 macOS、Linux（EXDEV 修复）、Windows 的平台差异，以及插件市场版与 npm 版的功能对比。

[5 分钟阅读 // READ →]
03

第 3 期：默认显示 — 你看到什么

逐字拆解 HUD 默认两行布局的每一个信息元素：模型名、Git 分支、上下文条、用量条，以及颜色变化规则。

[3 分钟阅读 // READ →]
04

第 4 期：配置与预设

掌握 /claude-hud:configure 交互式配置、三种预设（Full/Essential/Minimal），以及 setup 与 configure 的关键区别。

[5 分钟阅读 // READ →]
05

第 5 期：上下文窗口深度解析

200K tokens 的上下文窗口里到底装了什么？固定部分 vs 动态部分，以及哪些操作会让上下文暴涨。

[7 分钟阅读 // READ →]
06

第 6 期：令牌（Tokens）详解

完整拆解输入/输出/缓存三类 Token 的构成、计费差异，以及实战场景下的 Token 雪球效应和省钱技巧。

[6 分钟阅读 // READ →]
07

第 7 期：用量限制（Usage Limits）

Pro/Max/Team 订阅的 5 小时和 7 天用量窗口在 HUD 中如何显示、颜色如何变化、以及不显示时的排查方法。

[4 分钟阅读 // READ →]
08

第 8 期：Git 状态与工具活动

解读 HUD 的 Git 状态符号（分支/dirty/ahead-behind）、实时工具活动行、Agent 状态行和 Todo 进度行。

[4 分钟阅读 // READ →]
09

第 9 期：高级功能

Prompt Cache 倒计时、会话费用、输出速度、会话时长、自定义颜色等进阶功能的完整配置指南。

[4 分钟阅读 // READ →]
10

第 10 期：最佳实践与常见问题

推荐的开发者配置、上下文管理黄金法则、缓存优化实战、以及完整的 FAQ 排查指南。

[6 分钟阅读 // READ →]
11

第 11 期：HUD 数据来源深度解析

拆解 HUD 的三大数据管道：stdin JSON、Transcript JSONL、Context Cache，理解每个数据字段从哪来。

[6 分钟阅读 // READ →]
12

第 12 期：排错实战 — Token 明细不显示

完整诊断流程：从确认配置到检查数据源，5 步解决 Token 明细不显示的问题。附诊断决策树。

[5 分钟阅读 // READ →]
13

第 13 期：Session 与 Session History

理解 Session 的生命周期、JSONL Transcript 的数据结构、以及 Session 与缓存和 Memory 的关系。

[4 分钟阅读 // READ →]
14

第 14 期：Memory 系统

Claude Code 的持久化记忆系统：存储位置、四种记忆类型、自动加载机制，以及对上下文和费用的影响。

[4 分钟阅读 // READ →]
15

第 15 期：/compact 与 /clear 命令

两种上下文管理命令的深度对比：智能压缩 vs 完全重置，附 Mermaid 流程图和使用场景决策表。

[4 分钟阅读 // READ →]
16

第 16 期：Q&A — Session、上下文、Token 基础

解答 Session 与对话的区别、200K tokens 到底多大、上下文为何暴涨 40%、输入输出 Token 哪个贵等基础问题。

[4 分钟阅读 // READ →]
17

第 17 期：Q&A — Cache 机制与 Token 优化

深入解答 Prompt Cache 的工作原理、5 分钟倒计时的起算点、缓存命中省多少钱、以及保持缓存不过期的技巧。

[4 分钟阅读 // READ →]
18

第 18 期：Q&A — HUD 排错、Memory 与高级话题

最终 Q&A：Token 明细不显示的排查、非原生模型兼容性、expanded 布局截断问题、Memory 对上下文的影响等。

[5 分钟阅读 // READ →]
