核心要点总结 // DIRECT SUMMARY

本文档提供了所有 60+ Claude Code 命令的完整参考，按类别组织。

本文档提供了所有 60+ Claude Code 命令的完整参考，按类别组织。

启动与账户

命令 用途 频率
/login 登录 Anthropic 账户 核心
/logout 登出账户 常用
/status 查看版本、模型、账户状态 核心
/model 选择或更改 AI 模型 核心
/config 调整主题、模型、输出偏好 核心
/doctor 诊断安装和配置问题 核心
/help 显示帮助和命令列表 核心
/exit 退出 CLI（别名 /quit） 核心
/upgrade 升级计划层级 进阶

项目配置

命令 用途 频率
/init 生成 CLAUDE.md 项目说明 核心
/memory 编辑内存文件，管理 auto-memory 核心
/permissions 管理权限规则（别名 /allowed-tools） 核心
/hooks 查看 hook 配置 常用
/agents 管理 agent 配置 常用
/mcp 管理 MCP server 连接 常用
/plugin 管理插件 常用
/skills 列出可用 skills 常用

开发工作流

命令 用途 频率
/plan 进入 Plan Mode 核心
/effort 设置推理深度 核心
/btw 快速附加提问 核心
/goal 设定持续工作目标 常用
/focus 切换精简视图 常用
/compact 压缩对话释放上下文 核心
/context 可视化上下文使用 核心
/copy 复制 Claude 响应 常用
/recap 生成会话摘要 常用
/add-dir 添加工作目录 常用
/ultraplan 浏览器中审阅计划 进阶

会话管理

命令 用途 频率
/clear 开始新对话（别名 /reset、/new） 核心
/resume 恢复对话（别名 /continue） 核心
/branch 创建对话分支（别名 /fork） 核心
/rename 命名会话 常用
/export 导出对话为文本 常用
/stop 停止后台会话 常用

并行与自动化

命令 用途 频率
/background 会话后台化（别名 /bg） 常用
/tasks 列出后台任务（别名 /bashes） 常用
/batch 并行大规模变更（Skill） 常用
/loop 循环运行提示（别名 /proactive，Skill） 常用
/schedule 云端定时任务（别名 /routines） 进阶
/autofix-pr 自动修复 PR 进阶

代码审查

命令 用途 频率
/diff 交互式差异查看器 核心
/review 本地 PR 审查 核心
/security-review 安全漏洞扫描 核心
/simplify 代码质量优化（Skill） 常用
/ultrareview 云端深度审查 进阶

集成与平台

命令 用途 频率
/ide 管理 IDE 集成 常用
/remote-control 远程控制终端（别名 /rc） 常用
/teleport 拉取网页会话（别名 /tp） 常用

/chrome 配置 Chrome 扩展 进阶
/voice 语音听写 进阶
/terminal-setup 配置终端快捷键 进阶
/mobile 下载移动应用 进阶

诊断

命令 用途 频率
