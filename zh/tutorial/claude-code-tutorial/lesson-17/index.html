第 17 章 | Claude Cowork：跨多步骤的自动任务分解

15 分钟阅读 | 更新于：2026-06-16

🎯 学习目标

学完本期你将掌握：

  1. Claude 如何自动将复杂任务分解为多步骤执行计划
  2. 多轮工具调用链的内部运作机制
  3. 如何观察和引导 Claude 的任务规划过程
  4. 复杂跨文件工作流的实战技巧

📖 核心概念讲解

17.1 什么是"任务分解"？

人类的做法:
  "做一个带认证的 REST API"
  → 脑子里列出步骤:
    1. 设计数据模型
    2. 写路由
    3. 加认证中间件
    4. 写测试
  → 按顺序执行

Claude Code 的做法:
  收到同样的指令
  → 内部推理出执行计划 (Agentic Reasoning)
  → 调用 40+ 次工具自动执行
  → 中途遇到问题自动调整计划

关键区别:
  人类: 先规划 → 再执行（分开的）
  Claude: 边规划 → 边执行 → 边调整（一体化的）

17.2 Claude 的内部执行循环

╭────────────── Agent Loop ──────────────────╮
│                                            │
│   接收指令                                 │
│     │                                      │
│     ▼                                      │
│   推理当前应该做什么 (Think)               │
│     │                                      │
│     ▼                                      │
│   选择工具并执行 (Act)                     │
│     │                                      │
│     ▼                                      │
│   观察结果 (Observe)                       │
│     │                                      │
│     ├─ 成功 → 推理下一步 ──→ 回到 Think   │
│     │                                      │
│     └─ 失败 → 调整策略 ──→ 回到 Think     │
│                                            │
│   直到所有步骤完成 → 输出总结              │
│                                            │
╰────────────────────────────────────────────╯

这就是 ReAct (Reasoning + Acting) 模式

17.3 复杂任务的典型分解

用户指令: 
  "给这个 Express 项目添加 JWT 用户认证"

Claude 的内部分解:

  步骤 1: 理解现有架构
    ├─ Read package.json
    ├─ Glob src/**/*.ts  
    └─ Read src/index.ts, src/routes/...

  步骤 2: 安装依赖
    └─ Bash: npm install jsonwebtoken bcrypt

  步骤 3: 创建数据模型
    └─ Write src/models/User.ts

  步骤 4: 创建认证服务
    └─ Write src/services/auth.ts

  步骤 5: 创建认证中间件
    └─ Write src/middleware/auth.ts

  步骤 6: 创建认证路由
    └─ Write src/routes/auth.ts

  步骤 7: 集成到主应用
    └─ Edit src/index.ts

  步骤 8: 保护现有路由
    └─ Edit src/routes/users.ts (添加 auth 中间件)

  步骤 9: 验证
    ├─ Bash: npx tsc --noEmit
    └─ Bash: npm test

  总计: ~20 次工具调用，全自动完成

🔧 涉及的 Tools

工具 任务分解中的角色 说明
Read 理解环节 读取现有代码理解架构
Glob 发现环节 扫描项目结构
Bash 执行环节 安装依赖、运行迁移、测试
Write 创建环节 生成新文件
Edit 集成环节 修改已有文件，连接新旧代码

📝 本期要点回顾

  1. Claude Code 使用 ReAct 模式：边推理边执行边观察
  2. 复杂任务自动分解为 多步骤工具调用链
  3. Plan Mode 可以预览执行计划而不实际执行
  4. 可以通过 限制步骤范围 来控制执行粒度
  5. 失败时 Claude 会 自动调整策略，而不是直接报错
