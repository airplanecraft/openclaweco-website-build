第 02 章 | 环境搭建与授权：Windows/Mac/Linux 极速安装指南

11 分钟阅读 | 更新于：2026-06-16

🎯 学习目标

学完本期你将能够：

  1. 在 Mac / Windows / Linux 上成功安装 Claude Code
  2. 完成终端认证授权
  3. 在第一个项目中启动 Claude Code 会话

📖 核心概念讲解

2.1 安装方式总览

Claude Code 提供多种安装方式，适配不同操作系统和场景：

安装方式 平台 适用场景
Native Install（推荐） Mac / Linux / Windows 自动更新，最稳定
Homebrew Mac Homebrew 用户偏好
WinGet Windows Windows 包管理器
VS Code 扩展 全平台 IDE 内集成
Desktop App Mac / Windows GUI 界面偏好
Web 版 全平台 无需安装

2.2 订阅计划

使用 Claude Code 需要付费订阅：

计划 价格 适用人群
Pro $20/月 日常开发，轻度使用
Max 5x $100/月 每日密集开发
Max 20x $200/月 专业团队/重度用户
API (Console) 按量计费 集成到自动化管道

💻 代码演示：三步安装

Mac / Linux 安装

# 第 2 章：步骤 1：一键安装（推荐方式）
curl -fsSL https://claude.ai/install.sh | bash

# 第 2 章：步骤 2：验证安装
claude --version
# 第 2 章：输出: Claude Code v2.3.0

# 第 2 章：步骤 3：认证登录
claude auth login

Windows 安装（PowerShell）

# 第 2 章：步骤 1：一键安装
irm https://claude.ai/install.ps1 | iex

# 第 2 章：步骤 2：验证
claude --version

# 第 2 章：步骤 3：认证
claude auth login

Homebrew 安装（Mac 替代方案）

# 第 2 章：安装
brew install --cask claude-code

# 第 2 章：升级
brew upgrade claude-code

💻 代码演示：认证状态检查

# 第 2 章：检查当前认证状态
claude auth status

# 第 2 章：输出示例：
# 第 2 章：✓ Authenticated
# 第 2 章：Account: eric@example.com
# 第 2 章：Plan: Max (5x usage)
# 第 2 章：Organization: Personal

# 第 2 章：登出（切换账号时使用）
claude auth logout

# 第 2 章：使用 API Key 认证（CI/CD 场景）
claude auth login --console

🔧 涉及的 CLI 命令

命令 作用 官方文档
claude 启动交互会话 CLI Reference
claude auth login 登录认证 支持 --email, --sso, --console 参数
claude auth status 查看认证状态
claude auth logout 登出
claude --version 查看版本
claude update 更新到最新版

⚠️ 常见问题排查

问题 1：安装后 claude 命令找不到

# 第 2 章：Mac/Linux：将 Claude Code 加入 PATH
export PATH="$HOME/.claude/bin:$PATH"

# 第 2 章：永久生效
echo 'export PATH="$HOME/.claude/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

问题 2：认证窗口无法打开

# 第 2 章：使用 Console 方式手动认证
claude auth login --console
# 第 2 章：它会输出一个 URL，手动在浏览器中打开

问题 3：Windows PowerShell 报 && 错误

# 第 2 章：Windows CMD 和 PowerShell 语法不同
# 第 2 章：如果出错，使用 Git Bash 或 WSL 来运行安装脚本

📝 本期要点回顾

  1. 推荐使用 Native Install 方式安装（自动更新）
  2. 首次使用需要在浏览器中完成 OAuth 认证
  3. 使用 claude auth status 随时检查认证状态
  4. CI/CD 环境使用 claude auth login --console 进行 API Key 认证
  5. 记住常用斜杠命令：/help, /init, /clear, /compact
