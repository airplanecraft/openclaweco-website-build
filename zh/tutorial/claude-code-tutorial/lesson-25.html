第 25 章 | 网络代理与爬虫 MCP (WebFetch / Playwright)

20 分钟阅读 | 更新于：2026-06-16

副标题/大纲：越过本地磁盘：让 Claude Code 在外网上收集参考资料后注入代码项目。

🎯 学习目标

  • 理解网络代理在爬虫中的重要性、工作原理及其在 Claude Code 中的应用场景。
  • 掌握 Claude Code 中通过 WebFetch 工具进行轻量级、静态网页内容抓取的方法。
  • 学习如何利用 Playwright 工具进行复杂的动态网页交互、数据提取与自动化操作。
  • 了解 Claude Code 如何整合这些外部数据收集能力，实现从互联网获取信息并注入到代码项目中的高级工作流。

📖 核心概念讲解

25.1 网络代理与爬虫伦理：数据获取的基石与边界

在进行大规模网络数据抓取时，直接使用本地 IP 地址往往会遇到诸多限制，例如：

  • IP 封禁： 目标网站可能会识别并封禁来自同一 IP 地址的频繁访问。
  • 频率限制： 网站对单个 IP 的访问频率设有阈值，超出即会触发验证码或临时封禁。
  • 地理限制： 部分内容或服务仅对特定地区开放。

网络代理服务器（Proxy Server）正是为了解决这些问题而生。它充当客户端（我们的爬虫）和目标服务器之间的中间人，所有的请求都通过代理服务器转发。

+--------------------+      +-----------------------+      +--------------------+
|  Claude Code /     |      |                       |      |                    |
|  你的爬虫程序      |----->|   代理服务器 (Proxy)  |----->|   目标网站服务器   |
|  (Client)          |      |                       |      |    (Target Server) |
+--------------------+      +-----------------------+      +--------------------+
                           ^                               ^
                           |                               |
                           +-- 客户端看到的是代理IP --------+-- 目标服务器看到的是代理IP

代理的类型：

  • HTTP/HTTPS 代理： 最常见，用于网页浏览。
  • SOCKS 代理： 更底层，支持 TCP/UDP，可用于非 HTTP 协议的流量。
  • 透明代理： 目标网站知道你使用了代理且知道你的真实 IP。
  • 匿名代理： 目标网站知道你使用了代理，但不知道你的真实 IP。
  • 高匿名代理： 目标网站甚至不知道你使用了代理，认为你是直接访问。

爬虫伦理与法律边界： 尽管代理提供了便利，但进行网络爬取时必须严格遵守伦理和法律规定：

  1. robots.txt 协议： 任何负责任的爬虫都应首先检查目标网站的 robots.txt 文件，并遵守其中定义的抓取规则（哪些路径不允许抓取、哪些用户代理不允许抓取等）。
  2. 抓取频率： 模拟人类访问行为，避免在短时间内对服务器造成过大压力，否则可能被视为拒绝服务攻击。
  3. 数据用途： 明确收集数据的合法用途，不得用于侵犯隐私、版权或商业秘密。
  4. 登录与认证： 未经授权不得绕过登录机制，除非是抓取公开数据。
  5. 条款与条件： 遵守网站的服务条款。

Claude Code 在执行网络抓取任务时，会内置对 robots.txt 的初步检查，并提供配置选项来控制抓取频率和代理使用，以帮助用户在合规的前提下高效工作。

25.2 WebFetch：Claude Code 的轻量级网络抓取器

WebFetch 是 Claude Code 内部封装的一个轻量级、高效的网络请求工具，它旨在简化对静态网页内容的获取。你可以将其理解为 curl 或 Python requests 库的高级抽象，专门为 Claude 的任务执行环境优化。

核心特性：

  • 简洁的 API： 通过简单的 JSON 或 YAML 配置即可发起 HTTP/HTTPS 请求。
  • 支持代理： 可轻松集成代理服务器，实现匿名访问或 IP 轮换。
  • 请求头定制： 允许自定义 User-Agent、Referer 等 HTTP 请求头，模拟不同客户端行为。
  • 超时控制： 防止请求无限期等待。
  • 自动重试： 在网络不稳定的情况下，可配置自动重试机制。

典型应用场景：

  • 抓取博客文章、新闻页面等静态 HTML 内容。
  • 获取 API 接口返回的 JSON 或 XML 数据。
  • 检测网站的可访问性或特定内容的更新。

WebFetch 工具定义示例 (假设 Claude Code 的工具配置是 YAML 格式)：

tools:
  - name: WebFetch
    description: "用于通过 HTTP/HTTPS 请求获取网页内容或API数据。"
    parameters:
      type: object
      properties:
        url:
          type: string
          description: "目标URL。"
        method:
          type: string
          enum: ["GET", "POST", "PUT", "DELETE"]
          default: "GET"
          description: "HTTP 请求方法。"
        headers:
          type: object
          description: "自定义HTTP请求头，键值对形式。"
        data:
          type: string
          description: "POST/PUT请求体数据，可以是JSON字符串或表单数据。"
        proxy:
          type: string
          description: "代理服务器地址，格式如 'http://user:pass@host:port' 或 'socks5://host:port'。"
        timeout:
          type: integer
          default: 30
          description: "请求超时时间（秒）。"
        follow_redirects:
          type: boolean
          default: true
          description: "是否跟随HTTP重定向。"
      required: ["url"]

25.3 Playwright：应对动态网页的瑞士军刀

当目标网页大量依赖 JavaScript 进行内容渲染（如单页应用 SPA）或需要复杂的用户交互（如点击按钮、填写表单、滚动页面加载更多内容）时，仅仅使用 WebFetch 这样的 HTTP 客户端是无法满足需求的。这时，我们就需要一个无头浏览器（Headless Browser）。

Playwright 是 Microsoft 开发的一个强大的无头浏览器自动化库，它支持 Chromium (Chrome)、Firefox 和 WebKit (Safari) 三大浏览器引擎，并提供了统一的 API。

核心特性：

  • 多浏览器支持： 在真实浏览器环境中运行测试或爬虫。
  • 无头模式： 可以在后台运行浏览器，无需显示图形界面，节省资源。
  • 丰富的交互 API：
    • 页面导航 (page.goto())
    • 元素选择 (page.locator(), page.$())
    • 点击 (element.click())
    • 输入文本 (element.fill())
    • 键盘/鼠标操作
    • 等待元素出现/网络请求完成 (page.waitForSelector(), page.waitForLoadState())
    • 截图 (page.screenshot())、生成 PDF (page.pdf())
  • 网络拦截： 可以拦截、修改或阻止网络请求，例如加载代理、注入脚本、阻止图片加载等。
  • 上下文隔离： 每个 BrowserContext 都是独立的，拥有自己的缓存、cookie 和本地存储，互不影响。

Playwright 在 Claude Code 中的集成： Claude Code 可以通过一个专门的 Playwright 工具或 browser_automation 工具来调用 Playwright 的能力。用户通过提供一个描述任务的自然语言指令，或者一个预定义的 Playwright 脚本，让 Claude 来执行。

Playwright 工具定义示例 (假设 Claude Code 的工具配置)：

tools:
  - name: Playwright
    description: "用于在无头浏览器中执行复杂网页交互和动态内容抓取。"
    parameters:
      type: object
      properties:
        script:
          type: string
          description: "要执行的Playwright Python脚本代码字符串。"
        url:
          type: string
          description: "可选：初始导航URL，如果脚本未指定。"
        browser:
          type: string
          enum: ["chromium", "firefox", "webkit"]
          default: "chromium"
          description: "使用的浏览器类型。"
        headless:
          type: boolean
          default: true
          description: "是否在无头模式下运行浏览器。"
        proxy:
          type: string
          description: "代理服务器地址，格式如 'http://user:pass@host:port'。"
        args:
          type: array
          items:
            type: string
          description: "传递给浏览器启动的额外参数，例如 '--disable-gpu'。"
        context_options:
          type: object
          description: "Playwright BrowserContext 选项，如 user_agent, locale 等。"
      required: ["script"]

通过 Playwright，Claude Code 能够模拟真实用户行为，绕过 JavaScript 渲染障碍，从而获取到最接近用户浏览器所见的内容，极大地扩展了 Claude 的信息收集能力。

2. Playwright 脚本示例 (模拟用户登录、搜索并截图)

这个 Python 脚本展示了如何使用 Playwright 启动一个浏览器，导航到登录页，输入凭据，执行搜索，并截取搜索结果页面的图片。Claude Code 将执行这个脚本并返回结果。

# 第 25 章：playwright_script.py (此脚本将作为字符串传递给 Claude 的 Playwright 工具)
import asyncio
from playwright.async_api import Page, expect, BrowserContext, request as playwright_request, TimeoutError

async def run(page: Page, context: BrowserContext):
    """
    此函数将在Playwright的Page和BrowserContext中执行。
    """
    try:
        # 1. 导航到登录页面
        print("Navigating to login page...")
        await page.goto("https://www.my-internal-tool.com/login", wait_until="domcontentloaded")
        await page.wait_for_selector('input[name="username"]', timeout=15000)

        # 2. 填写登录凭据
        print("Filling credentials...")
        await page.fill('input[name="username"]', "my_secure_username")
        await page.fill('input[name="password"]', "my_secure_password_from_env") # 假设密码从环境变量或安全存储中获取

        # 3. 点击登录按钮
        print("Clicking login button...")
        await page.click('button[type="submit"]')

        # 4. 等待跳转到内部仪表盘或主页
        print("Waiting for dashboard to load...")
        await page.wait_for_url("https://www.my-internal-tool.com/dashboard", timeout=30000)
        await page.wait_for_load_state("networkidle") # 等待所有网络请求完成

        # 5. 执行搜索操作
        print("Performing search...")
        search_input = page.locator('input[placeholder="Search projects..."]')
        await search_input.fill("critical bug")
        await search_input.press("Enter") # 模拟按下回车键

        # 6. 等待搜索结果加载
        print("Waiting for search results...")
        await page.wait_for_selector('.search-results-list', timeout=20000)
        await page.wait_for_load_state("networkidle")

        # 7. 截图保存结果
        screenshot_path = "search_results.png"
        await page.screenshot(path=screenshot_path, full_page=True)
        print(f"Screenshot saved to {screenshot_path}")

        # 8. 提取搜索结果的标题和链接
        result_elements = await page.locator('.search-results-list .result-item h3 a').all()
        results = []
        for el in result_elements:
            title = await el.text_content()
            href = await el.get_attribute('href')
            results.append({"title": title.strip(), "link": href})

        return {"status": "success", "screenshot": screenshot_path, "search_results": results}

    except TimeoutError:
        print("Playwright operation timed out.")
        return {"status": "error", "message": "Playwright operation timed out. Check selectors or network issues."}
    except Exception as e:
        print(f"An unexpected error occurred: {e}")
        return {"status": "error", "message": str(e)}
