第1集：工具全景与核心定位

3 分钟阅读 | 更新于：2026-06-16
核心要点总结 // DIRECT SUMMARY

Claude Code、Gemini CLI、Antigravity 究竟是什么？它们各自解决什么问题？

三家 AI Coding Agent 工具的横向对比与选型指南（截至 2026 年 4 月）

三大主角登场

工具 厂商 形态 核心定位
Claude Code Anthropic 终端 CLI + IDE 插件 工程师向、可编程的 AI 编码助手
Gemini CLI Google 终端 CLI（开源） 开放、可 fork 的多功能 AI Agent
Antigravity Google 完整 IDE（VS Code fork）+ Web 多 agent 协作的"agentic IDE"

一句话区分

  • Claude Code 和 Gemini CLI 是同形态的竞品，主打“终端 + 工具集”模式。它们像是在你的终端里塞进了一个经验丰富的专家。
  • Antigravity 则是完全不同的范式，它把 IDE 本身当作 Agent 的操作平台（Agentic IDE），更侧重于可视化、多 Agent 调度和跨模型切换。

为什么我们需要这些工具？

传统的“对话式 AI”（如网页版 ChatGPT 或 Claude）属于 Chat 范式：你问，它答，你负责执行。

而这三款工具属于 Agent 范式：

  1. 自主权：它们能理解你的意图，并自主规划步骤。
  2. 行动力：它们拥有“手”和“脚”，能直接读写文件、运行终端命令、执行测试甚至操作浏览器。
  3. 可编程性：你可以通过规则文件、Skill 或 Hook 来定义它们的行为，让它们成为真正理解你项目规范的数字员工。

接下来，我们将深入研究它们的相同点与不同点，助你做出最明智的选型决策。
