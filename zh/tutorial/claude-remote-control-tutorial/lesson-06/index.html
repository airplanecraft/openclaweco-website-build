官方 Remote Control：高级工作流与玩法

3 分钟阅读 | 更新于：2026-06-16

Remote Control 开启了几个超越简单聊天的强大工作流。

典型场景

场景 操作
移动端继续 使用 /remote-control → 在外出时通过移动端应用继续任务。
跨设备恢复 机器 A /teleport → 在机器 B 上继续。
Agent 主动通知 开启推送 → 当任务结束时，Claude 调用 push notification 工具提醒你。
远程方案审阅 在 plan 模式下生成方案 → 在手机上审阅、编辑或批准。

进阶能力

  • Ultraplan / Ultrareview: Claude.ai 订阅者可以触发基于云端的多 Agent 任务。v2.1.110 增加了用于 PR 的 /ultrareview。
  • 后台 Agent: 长时间运行的任务可以移动到后台，其状态在 Remote Control 客户端中可见。
  • 同步特性: 主题颜色 (/color) 和会话名称 (/rename) 在 CLI 和 Web 端之间双向同步。

典型节奏示例

sequenceDiagram
  participant U as 你 (移动端)
  participant Web as claude.ai/code
  participant CLI as 本地 CLI
  U->>Web: 打开会话
  Web->>CLI: 输入 "对 PR #482 运行 /ultrareview"
  CLI->>CLI: 触发云端审查
  CLI-->>Web: 流式传输对话记录
  CLI->>U: 发送推送通知 (任务完成)
  U->>Web: 审阅结果，合并或进一步修改
