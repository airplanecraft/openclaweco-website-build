Telegram 插件：安装与配置

3 分钟阅读 | 更新于：2026-06-16

设置 Telegram 插件涉及创建一个机器人并配置 MCP 服务器。

前置条件

  • Bun: MCP 服务器运行在 Bun 上。可以使用 curl -fsSL https://bun.sh/install | bash 安装。
  • Telegram 机器人令牌: 从 Telegram 上的 @BotFather 获取。

安装步骤

  1. 创建机器人: 给 @BotFather 发消息，发送 /newbot，按照提示操作获取你的 令牌 (Token)。

  2. 安装插件: 在 Claude Code 中：

    /plugin install telegram@claude-plugins-official
/reload-plugins

  3. 配置令牌:

    /telegram:configure <你的机器人令牌>

  4. 使用 Channel 启动: 使用 Channel 标志重启 Claude Code：

    claude --channels plugin:telegram@claude-plugins-official

  5. 配对: 从你的 Telegram 账户向你的机器人发送一条消息。它会回复一个 6 位数的代码。在 Claude Code 中输入：

    /telegram:access pair <代码>

  6. 设置策略: 切换到 allowlist 模式以防止陌生人访问你的机器人：

    /telegram:access policy allowlist
