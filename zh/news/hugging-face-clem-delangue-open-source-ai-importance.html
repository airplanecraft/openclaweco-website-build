Hugging Face CEO：高昂成本正逼迫企业从闭源API转向开源AI

2026年7月11日 | 3 分钟阅读
#huggingface#opensource#robotics#mcp#llm

开源AI正在蓬勃发展。Hugging Face 联合创始人兼 CEO Clem Delangue 指出，该公司近年来已发展成为AI领域的“GitHub”，AI开发者可以在这里分享和下载开源模型及数据集。目前，全球约有半数的 Fortune 500（财富500强）企业在使用 Hugging Face 的服务。Delangue 观察到了一个反复出现的行业规律：许多企业在起步时会选择使用前沿的 闭源API，但随着业务规模的扩大，高昂的使用成本最终会迫使他们转向开源模型。

在 TechCrunch 的 Equity 播客节目中，Delangue 与主持人 Rebecca Bellan 深入探讨了在 Anthropic 暂停发布 Fable 模型之后，开源与闭源之争为何变得如此重要。他还表达了自己的担忧，即少数几家巨头最终可能会控制整个 AI 生态系统。

节目中还探讨了以下核心议题：首先，中国实验室 正在生产目前在美国被下载的绝大多数开源模型。Delangue 认为这是一个需要积极应对并解决的竞争与合作问题，而不是以此来质疑和排斥开源本身。其次，Hugging Face 选择了优先考虑 资金效率，而不是盲目遵循硅谷传统的融资模式，这也是为什么该公司在去年拒绝了来自 Nvidia 的巨额投资。

此外，Delangue 认为，相比于聊天机器人或代码助手，机器人领域（#Robotics）对开源、透明的 AI 系统有着更迫切的需求。考虑到机器人未来会深入家庭和个人生活，能够实时接触到大量的隐私数据，其底层的 AI 逻辑必须是开源且可审计的。

AgentUpdate 深度解析

Hugging Face 作为 AI 时代的“GitHub”，其对开源生态的捍卫不仅关乎模型的可访问性，更直接决定了未来 AI Agent（智能体） 生态的走向。从闭源 API 走向开源是 Agent 大规模落地的必然路径。在构建多 Agent 协同系统（如 LangChain 或 CrewAI）时，底层模型调用的高频次会导致 API 成本呈指数级上升。开源模型不仅极大地降低了 Agent 的运行成本，还允许开发者在边缘端或本地进行深度微调，实现更低延迟和更高的数据隐私安全性。更为重要的是，机器人作为实体 Agent 的终极形态，其感知与决策系统如果被少数闭源巨头垄断，将带来极大的安全隐患。开源技术将赋予 Agent 开发者自主权，打破巨头垄断，促进异构 Agent 之间通过开放协议（如 MCP，Model Context Protocol）进行无缝协作，这是构建真正民主化、泛在化智能体生态的基石。
