Perplexity确认2028年上市，不受OpenAI上市影响

2026年6月9日|3 分钟阅读
#perplexity#search-agent#ai-search#ipo

2026年6月9日消息，AI 搜索领域的领头羊 Perplexity 首席执行官 Aravind Srinivas 近日在接受采访时明确指出，无论市场对 OpenAI 和 Anthropic 的上市反响如何，#Perplexity 都将按原计划于 2028年 启动首次公开募股（#IPO）。

斯里尼瓦斯表示，公司的上市规划属于长期战略，原本就定在 2028 年，这一决策不依赖于其他生成式 AI 巨头的资本动作。当前，随着 AI 搜索及 Agent 技术的成熟，Perplexity 正在逐步建立其独有的商业化路径和广告分成模式，这也是支撑其长期独立上市决心的底气所在。

AgentUpdate 深度解析

作为主动式 AI Agent 商业化的先驱，Perplexity 决定不盲从 OpenAI 和 Anthropic 的上市节奏，展现了其对“AI 搜索引擎/答复引擎”这一垂直生态长期价值的信心。相较于追求通用大模型（AGI）的巨头，Perplexity 更专注于端到端的复杂任务解决与主动检索代理（Search Agents）。这种定位使其能更早地跑通商业闭环。然而，到 2028 年，AI 搜索将从“单次对话检索”彻底演变为“全自动多模态执行 Agent”。Perplexity 能否在资本市场证明其持续构筑壁垒的能力，取决于其能否在苹果、微软等底层系统级 Agent 的夹击下，构建起不可替代的、结合广告生态与知识网络的 Agent 流量入口。
