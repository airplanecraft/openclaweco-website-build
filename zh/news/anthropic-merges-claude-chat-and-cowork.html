Anthropic统一Claude与Cowork界面：打破应用边界，强化协同AI体验

2026年9月17日|3 分钟阅读
#claude#anthropic#cowork#artifacts

Anthropic 正在将其 Claude 聊天前端与 Cowork 协同工作流进行合并，旨在解决用户在处理不同任务时频繁切换标签页的困扰。

这一全新统一的界面允许用户在单一窗口内无缝访问聊天（Chat）、#Cowork 协同区以及 Artifacts（#Claude 的互动工作区功能）。此外，今年 4 月专为网站和原型设计推出的 Claude Design 功能，如今也可以在 Claude 内部的任何场景下直接调用。

在此次更新前，#Anthropic 官方表示，用户常常在面对不同任务时难以抉择该使用哪个标签页。通过全新的设计，Claude 将能够自动路由用户的请求，无需用户手动切换标签或窗口。此举旨在消除产品功能碎片化带来的困惑，用一个统一的前端将工作智能分发至应用的不同模块。

此外，Anthropic 还推出了专门用于制作演示文稿和文档的新功能。用户现在可以命令 AI 助手创建、编辑并展示幻灯片，甚至可以直接将生成的演示文稿导出为 PDF 或 PowerPoint 格式。

同样，在全新的 Docs（文档）功能中，用户可以与 Claude 协同编写段落、提出问题并对已完成的内容发表评论。用户不仅可以通过链接分享这些生成的文档或幻灯片，还能在手机端进行便捷编辑。此外，用户可以在桌面端启动文档创作，并随时通过手机 App 查看任务进度。

这些新特性将在未来几周内率先向 Claude 的 Pro 和 Max 计划用户开放（涵盖 Web 端、桌面端和移动端），并计划在晚些时候推向免费版和团队版用户。此次更新紧随 Cowork 的记忆层（Memory Layer）升级之后，该升级旨在帮助 Claude 在跨聊天会话中更好地保留和理解用户上下文。

AgentUpdate 深度解析

Anthropic 此次将 Claude Chat 与 Cowork 融为一体，本质上是对 AI Agent 交互范式（Interaction Paradigm）的一次深刻变革。传统的 AI 助手往往依赖单一的对话框，但在复杂的、长周期的协作任务中，纯文本交互的信息密度极低。通过将 Artifacts、内存层、设计工具与协同画布（Cowork）在单一界面中进行‘无感式路由’，Anthropic 正在从‘聊天工具’演变为‘主动式的空间代理（Spatial Agent）’。与 OpenAI 现有的多标签或分屏方案相比，Anthropic 的‘自动路由’代表了更高级的智能体意图识别能力。这也预示着，未来的 AI Agent 将不再只是等待指令的被动实体，而是能够根据任务属性，自主调配底层画布、内存与外部工具，并以最适合人类消费的视觉形式呈现在统一空间中的全能协作伙伴。
