Anthropic Claude Code上线Ultraplan：AI编程任务规划迈入云端

2026年4月11日 | 3 分钟阅读
#claude#anthropic#task planning#developer tools#cloud ai

Anthropic为#Claude Code新增了“Ultraplan”功能，旨在将编程任务的规划阶段转移到云端。通过这一功能，开发者可以在终端启动规划作业，随后Claude会在其Code网页界面上处理并生成规划方案，而终端在此期间则可以继续执行其他任务，从而提高工作效率。

根据code.claude.com上的官方文档，Ultraplan相较于本地规划模式，主要有三大改进：首先，用户现在可以针对规划方案的单个部分发表评论，而无需一次性回复整个方案；其次，规划过程完全在云端后台运行；最后，完成的规划方案既可以在浏览器中执行，也可以回到终端进行操作。此外，浏览器界面还支持内联评论、表情符号反应以及修订请求，进一步提升了协作和交互体验。

使用Ultraplan功能需要一个Claude Code网页账户、一个GitHub仓库，以及Claude Code至少2.1.91或更高版本。值得注意的是，该功能目前不兼容Amazon Bedrock、Google Cloud Vertex AI或Microsoft Foundry等主流云平台。#Anthropic员工Thariq在X（原Twitter）上指出，Ultraplan的token消耗量与此前的规划模式大致相同。目前，该功能已作为预览版面向所有已激活Claude Code网页版的用户开放。
