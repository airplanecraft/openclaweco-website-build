曝Anthropic年花150亿美元向SpaceX买算力

2026年5月21日 | 3 分钟阅读
#anthropic#spacex#compute#claude#gpu

根据周三曝光的#SpaceX最新美国监管申报文件，人工智能初创公司#Anthropic已同意在2029年5月之前，每月向SpaceX支付高达12.5亿美元，以获取其云算力基础设施。这意味着Anthropic每年将向其竞争对手控制的实体输送约150亿美元，这一惊人数字表明，算力获取已成为先进人工智能研发竞赛中最关键的瓶颈。

本月早些时候，Anthropic与SpaceX宣布达成协议，使这家#Claude开发商得以使用Colossus和Colossus II的GPU资源。这两个横跨田纳西州和密西西比州的数据中心拥有超过1吉瓦（Gigawatt）的计算能力。SpaceX最初是为了给其开发Grok聊天机器人的xAI部门快速建设这些设施，但埃隆·马斯克表示，他的公司最终并不需要其全部的计算能力。该交易的具体财务条款此前从未公开。

SpaceX在S-1招股书中表示，在每月12.5亿美元的费率于今年7月正式生效之前，Anthropic将在5月和6月支付一笔金额未公开的折扣费用。这一令人瞩目的数字凸显了Anthropic对算力资源的极度饥渴，其需要这些资源来支持其日益流行的AI编程工具等产品。据《华尔街日报》报道，Anthropic在2026年第二季度的收入预计将超过100亿美元。

Anthropic发言人向WIRED证实了上述数据。SpaceX未立即回应置评请求。马斯克在X平台关于该交易的帖子中透露，SpaceX“正在与其他公司讨论进行类似的合作”。

SpaceX表示，预计将为其算力基础设施“签署更多类似的劳务合同”，同时也将继续自用其数据中心。招股书称：“我们拥有足够的容量来为我们自己的AI模型提供计算支持，包括满足我们的训练和推理需求，并履行这些协议项下的义务。我们相信，我们的‘双重变现’策略为投资资本的回报提供了多种途径。”

该申报文件详细阐述了SpaceX在首次公开募股（IPO）前面临的商业机遇与风险。SpaceX正寻求进行历史上规模最大的IPO，希望以1.75万亿美元的估值筹集约750亿美元。该公司于4月1日向美国证券交易委员会（SEC）秘密提交了初步申请。周三发布的版本是经过修改后的清洁版本，不过在其中文在纳斯达克上市（股票代码：SPCX）之前可能还会有其他调整，预计上市最快将在6月12日进行。

AgentUpdate 深度解析

这一史诗级交易彻底揭示了生成式 AI 竞赛中，算力马太效应的严酷现实。即使拥有谷歌和亚马逊等巨头支持的 Anthropic，也不得不向对手购买高溢价算力。对于 AI Agent 生态而言，这也拉响了“运行成本警报”。随着 Agent 从单次对话交互演进为高频、多轮、跨系统的自主工作流，推理和训练成本呈指数级上升。拥有像 Colossus 这样超吉瓦级、极速交付的超级数据中心，将成为未来多 Agent 协同（Multi-Agent）和全天候具身智能落地不可逾越的竞争壁垒，掌控算力的平台将在制定 Agent 行业标准上拥有绝对的定价权。
