OpenAI GPT-5.5 与 Codex 正式登陆 Amazon Bedrock

2026年6月2日 | 3 分钟阅读
#bedrock#openai#gpt-5.5#codex#aws

OpenAI 的前沿大模型 #GPT-5.5、GPT-5.4 以及编程模型 Codex 现已在 Amazon #Bedrock 上正式全面可用（General Availability）。这意味着企业和开发者现在可以在 Bedrock 高性能、高可靠且安全的推理引擎上，直接部署和运行面向生产环境的 AI 应用和 AI Agent。

此次更新距离双方宣布扩大合作仅一个月。Amazon Bedrock 作为构建和运行大规模 AI 应用的核心平台，其底层的下一代推理引擎专为高并发、低延迟和强安全性而设计。最值得关注的是，在 Amazon Bedrock 上调用这些 #OpenAI 模型的定价与 OpenAI 官方第一方费率完全一致，不额外收取通道费用，且 Codex 的使用额度可以直接抵扣企业现有的 AWS 消费承诺合同。

在性能和功能上，作为 OpenAI 目前最先进的模型，GPT-5.5 具备极强的意图理解能力，能够自主处理复杂的多步骤任务。它在跨大型代码库编写与调试代码、数据分析、文档和表格生成以及多工具协同操作方面表现尤为突出。这些能力提升在 Agent 编程和知识性工作中尤为关键，因为这类应用高度依赖于长期上下文的维持以及跨时间的持续执行力。

与此同时，Amazon Bedrock 为这些模型提供了独有的企业级基础设施保障。Bedrock 的推理引擎为用户提供隔离的专用队列与自动容量管理，即使在高负载下也能确保性能的预测性。更为独特的是其状态持久化机制：在请求运行过程中，系统会持续且持久地捕获完整状态。一旦发生硬件故障或节点重启，请求可以从中断处无缝恢复，而无需重新开始。此外，所有调用都无缝继承了 AWS 的安全治理体系，包括 IAM 权限控制、VPC 和 PrivateLink 隔离、KMS 加密和 AWS CloudTrail 审计日志，且输入的用户提示词和输出结果绝不会被用于训练模型或与模型提供商共享。

生物制药巨头安进（Amgen）对此表示，OpenAI GPT-5.5 等前沿模型在能力、质量和一致性上带来了令人瞩目的进步。在科学准确性和决策质量要求极高的复杂生命科学领域，这些工具将有效加速新疗法的开发并为团队赋能。

AgentUpdate 深度解析

AWS 将 OpenAI GPT-5.5 与 Codex 纳入 Bedrock 生态，是 AI Agent 走向企业级落地的一座重要里程碑。相较于微软 Azure 长期垄断 OpenAI 企业级服务的局面，AWS 的介入彻底打破了单一云巨头的绑定。从技术架构上看，Bedrock 引入的“中途状态持久化（stateful persistence）”和“隔离队列”是一项关键创新。对于需要执行长任务、多步骤的 AI Agent 而言，网络波动或硬件故障导致的状态丢失是生产环境的致命痛点。AWS 的这一底层支持，实质上在基础设施层解决了 Agent 执行的鲁棒性问题。随着 OpenAI 前沿模型与 AWS 庞大的企业客户群、现有工作流和安全边界的无缝融合，企业级 Agent 生态的构建门槛将大幅降低，多 Agent 协同的工业级应用将迎来爆发。
