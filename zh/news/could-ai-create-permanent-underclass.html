AI会制造“永久底层”吗？FT警示技术鸿沟与就业极化

2026年8月9日 | 3 分钟阅读
#ai-agents#automation#cognitive-computing#mcp

随着生成式AI的爆发，科技界和经济学界开始警惕一个前所未有的危机：AI是否会创造一个永久底层阶级（Permanent Underclass）？《金融时报》（Financial Times）近日发文深入探讨了这一议题，指出当前由大语言模型（LLM）驱动的自动化浪潮，正在以前所未有的速度吞噬白领和知识工作者的岗位。

麻省理工学院（MIT）著名经济学家、诺贝尔奖得主Daron Acemoglu长期警告称，如果AI的发展路径仅仅是“替代人类”而不是“赋能人类”，将会导致严重的社会极化。他将这种现象称为“平庸的自动化”（so-so automation）——即技术刚好强大到能够取代人工，但又不足以显著提升整体生产率。其结果是，大量从事行政、初级编程、文案创作和数据分析的中等技能员工被挤出市场，迫使他们向下流动到更低薪的水暖工、护理等实体服务业，形成难以逆转的阶级固化。

与工业革命时期“机器代替体力，人类转向脑力”不同，这一次AI直接冲击了人类的核心竞争优势——认知与决策。像OpenAI的GPT-4和Anthropic的Claude等工具，正在从“辅助助手”向能够独立执行复杂工作流的AI Agent（智能体）演进。这意味着，未来的企业可能只需要极少数控制AI生产资料的“超级精英”，而大部分普通劳动者将失去通过积累经验实现职业攀升的通道。

AgentUpdate 深度解析

从 AI Agent 生态的演进路径来看，这一“认知平民化”趋势正处于爆发前夜。随着 Model Context Protocol (#MCP) 等统一连接协议的成熟，AI Agent 正在从单纯的文字交互工具演变为具备全自主执行能力的“数字员工”。这种技术跃迁虽然极大地释放了企业生产力，但其底层逻辑是在将人类的“经验资产”固化为软件算法。在未来的 Agent 生态中，中级技术和管理岗位的“学徒制”链条可能会断裂——如果初级工作全部由 Agent 代劳，那么未来将不再有资深专家诞生。对于 AI 开发者和生态构建者而言，未来的设计范式不应仅仅追求“端到端全自动替代”，而亟需探索“人机协同（Human-in-the-Loop）”的互补型架构。如何让 Agent 成为人类能力的放大器，而非劳动力的终结者，将是决定未来十年社会财富分配和技术伦理的关键分水岭。
