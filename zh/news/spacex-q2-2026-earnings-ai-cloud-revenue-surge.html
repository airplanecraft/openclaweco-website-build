SpaceX首份AI财报：算力收入暴涨247%，马斯克化身AI云巨头

2026年8月5日 | 3 分钟阅读
#spacex#grok#cloud-computing#gpu#infrastructure

SpaceX公布了上市后的首份财报，虽然其以航天火箭闻名，但二季度最吸睛的业务已悄然变成了AI。财报显示，#SpaceX本季度总营收达78.14亿美元，同比增长92%，高于市场预期的69亿美元。其中，AI业务收入达到25.61亿美元，同比猛增247%，环比更是翻了两倍多，占总营收的近三分之一。

然而，AI业务的爆发式增长背后是极其高昂的资金代价。在第二季度总计183.69亿美元的资本开支中，AI资本开支独占约158.28亿美元，占比高达86%。如此高昂的前置投入和持续亏损，让SpaceX的股价在财报公布后上演了“先涨后跌”的戏码，盘后转跌逾6%。同时，做空仓位快速上升，S3 Partners估算空头头寸约占可公开交易股份的32%。

细看财报，拉动AI业务高速增长的并非广告（AI广告收入同比有所下降），而是“AI解决方案和基础设施”业务，该板块单季贡献了21.94亿美元。其中，新签署的云服务协议带来了16亿美元的AI基础设施新增收入，已签署的不可取消合同金额合计达141亿美元。SpaceX已不再仅仅服务于自家的Grok模型训练，而是快速蜕变为向Anthropic和Google等行业巨头输出算力的AI云服务商。

为了支撑如此庞大的算力供给，SpaceX在基建上的投入堪称疯狂。第二季度的一次性大额基建投入主要集中在扩建Colossus II巨型AI超算中心、大批量采购GPU服务器、建设配套电厂散热设施以及采购硬件设备。截至6月底，SpaceX的总算力供电负荷已从一季度的1GW暴增至1.4GW，算力规模在一年内翻了3倍。此外，公司在研发方面投入了21.78亿美元，主要用于训练#Grok系列模型、与代码工具Cursor联合研发，以及自研算力调度和云端服务软件。

尽管AI部门本季度仍然面临约12.6亿美元的营业亏损，但这一数字已优于市场悲观预期，且首次证实了SpaceX AI业务的强劲商业化能力。马斯克在电话会中强调，SpaceX已承诺只使用NVIDIA的GPU，并计划在明年底前将电力及散热配套容量提升至20GW。面对如此庞大的折旧与运营压力，算力出租率和单位算力价格的稳定性将是SpaceX未来需要面对的核心挑战。

AgentUpdate 深度解析

SpaceX 正在构建的吉瓦级（GW）超级算力集群，不仅是云基础设施的军备竞赛，更是未来 AI Agent 生态底座的重塑。当前的 AI Agent 正在从简单的 API 调用走向多Agent协同（Multi-Agent Collaboration）和高频自主决策阶段，这对算力延迟和实时并发提出了极其严苛的要求。SpaceX 与 Cursor 的联合研发以及对自研算力调度系统的投入，表明马斯克意在通过极致的软硬一体化，构建一个超低延迟的“Agent执行云”。横向对比 Microsoft Azure 和 AWS，SpaceX 凭借其强大的电力自给与能源配套能力，未来可能提供性价比极高且完全托管的 Agent 运行环境。这种将物理能源转化为数字智能的闭环，不仅能加速 Grok 等原生智能体的发展，更将推动下一代端侧智能与人形机器人 Agent 在太空及地面边缘侧的无缝落地。
