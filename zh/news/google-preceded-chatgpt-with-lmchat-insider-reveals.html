曝谷歌曾早一年做出ChatGPT！亲历者爆料因怕冲击搜索被毙

2026年8月3日|3 分钟阅读
#codex#openai#google#transformer#llm

谷歌真的比 OpenAI 还要早一年搞出 ChatGPT 吗？这不是谷歌事后的自我安慰。近日，OpenAI 旗下 Codex 负责人、曾任职于谷歌的 Tibo（Thibault Sottiaux）亲自下场证实了这一传闻。

事件起因于一位 Midjourney 工程师在社交平台 X 上重温了前谷歌大脑负责人 Jeff Dean 的一段旧采访。Jeff Dean 曾透露，谷歌在 ChatGPT 问世前就拥有一个内部聊天机器人，但当时管理层认为它的体验还不如直接使用谷歌搜索。对此，Tibo 回应称，该项目确实存在，最初代号为 LMChat。它几乎就是一个早了一年版本的 ChatGPT。

至于这款产品为何未能面世，Tibo 透露，当时决策层非常紧张，极度担心这种生成式大模型会直接冲击谷歌最核心的“搜索与广告”业务。同时，DeepMind 团队也因权限限制，被禁止推出可能破坏谷歌现有商业生态的产品。谷歌对搜索质量的极高标准也限制了其手脚——当时的大模型容易产生严重幻觉，与高度成熟、要求精准的谷歌搜索相比显得不够稳定。然而，正是这种“不比谷歌搜索更好就不能发”的执念，让谷歌付出了极其昂贵的代价。

这种保守策略不仅让谷歌失去了先发优势，更引发了近年来极其严重的人才流失。谷歌正在持续向竞争对手“输血”：

  • 2017年奠定大模型基础的 Transformer 论文核心作者 Noam Shazeer，曾被谷歌斥资 27 亿美元连同其创立的 Character.AI 买回，却在近期再次选择出走并加入了 OpenAI。
  • 因 AlphaFold 荣获诺贝尔化学奖的 DeepMind 副总裁 John Jumper，也已宣布跳槽至竞争对手 Anthropic。
  • 紧接着，负责谷歌 AI 编程方向的 Jonas Adler 以及负责预训练核心贡献的 Alexander Pritzel 也双双离职，目的地同样是 Anthropic。

这不禁让人联想到科技史上最著名的“Xerox 悲剧”。1970年代，施乐帕罗奥多研究中心（Xerox PARC）发明了图形用户界面（GUI）、鼠标和以太网，却因为这些技术无法直接帮公司卖出更多碳粉和 A4 纸而将其束之高阁，最终被乔布斯看中并藉此打造了麦金塔电脑。如今，谷歌手握 Transformer 这一“满级神装”，却在 AGI 时代的马拉松里，因同样的大公司病而痛失王座。

AgentUpdate 深度解析

谷歌 LMChat 的夭折与如今人才流失的闭环，为当前的 AI Agent（智能体）生态敲响了警钟。在 Agent 时代，技术的领先并不等同于商业生态的胜利。大公司（如谷歌、微软）虽然在算力与基础模型上筑起高墙，但其庞大的既有业务与用户体验惯性，构成了难以逾越的“创新者窘境”。相比之下，AI Agent 需要极高的“行动力”与极低的“合规顾虑”来完成端到端的闭环任务。像 OpenAI 和 Anthropic 这样轻装上阵、以“Ship Fast”（快速发布）为灵魂的企业，不仅在吸引那些渴望技术落地的顶尖科学家（如 Noam Shazeer），更在通过高频迭代重塑人机交互界面。未来的 Agent 生态竞争，将不再是单纯的参数量比拼，而是看谁能像当年苹果释放 GUI 潜力一样，突破传统搜索和工作流的框架限制，把大模型真正转化为能自主执行复杂任务的行动体。谷歌的教训告诉我们，谁在 Agent 落地上面露迟疑，谁就将成为下一个时代的施乐。
