Cline 开源 Agent 运行时 SDK，性能超越 Anthropic 原生工具

2026年5月15日 | 3 分钟阅读
#cline#ai-agent#mcp#sdk#anthropic

知名 AI 编程助手 #Cline 近日宣布将其核心 Agent 运行时（Runtime）正式开源，发布了名为 @cline/sdk 的开发工具包。这一举措标志着 Cline 迈向了生态开放的新阶段，允许开发者利用其底层技术构建高度定制化的 AI 智能体。该 SDK 采用了精妙的四层模块化架构设计，旨在支持复杂的工程需求，如原生插件系统、子 Agent 协作以及 CRON 定时任务调度等功能。

在性能测试方面，Cline 的这一 SDK 展现出了强悍的竞争力。根据官方公布的数据，在 Terminal Benchmark 2.0 基准测试中，基于该 SDK 的表现已经超越了 #Anthropic 官方推出的 Claude Code 工具。这种性能优势源于其对模型调用和上下文管理的深度优化，为处理复杂的终端任务提供了更稳健的支撑。

目前，该运行时已经成功驱动了 Cline 现有的命令行工具（CLI）和看板（Kanban）应用，而 IDE 扩展插件的迁移工作也正在紧锣密鼓地进行中。开发者可以非常便捷地开始体验：只要环境具备 Node.js 22 或更高版本，即可通过 npm 轻松安装。此外，SDK 还内置了对 #MCP（模型上下文协议）连接器的支持，极大地扩展了 Agent 与外部数据源及工具链的交互能力。
