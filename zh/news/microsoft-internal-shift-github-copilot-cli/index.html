微软内部叫停 Claude Code：员工强制转向 GitHub Copilot CLI

2026年5月15日 | 3 分钟阅读
#github copilot#claude code#ai agent#cli#microsoft

微软正在对其内部开发工作流进行重大战略调整，要求数千名员工从 Anthropic 的 #Claude Code 转向使用自家的 #GitHub Copilot CLI。这一举措标志着微软在生成式 AI 领域进一步收紧生态，通过推广自研工具来提升开发效率。

在此之前，微软进行了一项为期六个月的内部实验。在实验期间，公司不仅允许开发者，还鼓励项目经理和设计师等非技术岗位尝试使用 AI 工具进行编程。作为该实验的一部分，微软向员工发放了 Claude Code 的许可证。Claude Code 是 Anthropic 推出的一款基于命令行的 AI 助手，在微软内部员工中获得了极高的人气，显示出员工对高效、易用的编程助手的强烈需求。

随着实验圆满结束，微软决定不再续订第三方工具的许可，而是将所有相关用户转移到 GitHub Copilot CLI 平台。这一转变体现了微软整合生态系统的敏捷性，通过将数千名深度用户引导至自家产品，微软可以更快地收集内部反馈，加速命令行 AI 助手的迭代与创新。

此举也反映了当前 #AI Agent 领域在终端（Terminal）场景下的激烈竞争。微软通过这一战略调整，旨在确保其在开发者工具市场的领先地位，并进一步强化 GitHub Copilot 作为开发者首选 AI 平台的地位。
