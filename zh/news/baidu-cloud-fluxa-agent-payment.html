百度智能云携手FluxA：共建AI Agent全球支付基础设施

2026年6月10日 | 3 分钟阅读
#mcp#agent-payment#baidu-cloud#fluxa#daa

随着 AI 技术的爆发，百度智能云与 FluxA 正式建立战略合作伙伴关系，共同探索由 DAA（Daily Active Agents，日活跃智能体数）驱动下的新商业模式与数字基础设施建设。目前，百度 Agent 商业化产品已正式支持 Agent Payment，并与 #FluxA 共建海外分销渠道。开发者可以基于百度智能云云市场构建可被 Agent 调用和购买的 AI 服务，并触达 FluxA 生态内的数万个 Agent。

在 2026 Create 大会上，百度创始人李彦宏提出，AI 时代衡量生态价值的核心指标将是 #DAA。随着 AI Agent 从信息获取工具逐步演变为能够自主完成任务、交付结果的执行主体，商业活动正在向人与 Agent、Agent 与 Agent 之间的协作网络快速扩展。在此背景下，每一个 Agent 都迫切需要独立的身份、账户、支付和结算能力。

为了打通自雇佣市场的闭环，本次合作实现了多项技术互通。百度提供市场资源与分销渠道，而 FluxA Monetize 则作为全球化分销平台，构建海外货仓和 A2A（Agent-to-Agent）支付基建。百度智能云模型包也已正式上线，开发者只需将以下 Prompt 复制给 AI Agent 即可快速体验：Fetch https://monetize.fluxapay.xyz/llm/baidu-ai-cloud to learn how to use Baidu AI Cloud Qianfan models。

作为面向 Agent 经济的支付底座，FluxA 针对传统支付无法支持的毫秒级响应、毫厘级微交易和全天候自动交易等痛点进行了重新设计。其核心机制包括：确保 Agent 在授权范围内安全交易的 Financial Harness、支持高频微额支付的超低费率通道，以及基于 Token 充值和计量的 Token Paywall。目前，已有超过 9 万个 Agent 正在使用 FluxA 钱包，超 1 万个 AI Agent 资源在 FluxA Monetize 平台上完成商业化。

在协议层，FluxA 自研了 AEP2 开放支付协议与非托管钱包架构，兼容 MCP（Model Context Protocol）、x402、A2A 与 Google AP2 等主流智能体协议，并推出智能体协同钱包（FluxA AI Wallet）、一次性虚拟卡（AgentCard）和 AI 收款（AgentCharge）等核心产品。

此外，百度智能云宣布诚邀 30家 合作伙伴（OPC）入驻首期内测，端到端跑通从商品入驻到自雇佣、再到出海分销的完整流通链路。加入该计划的开发者无需复杂资质，即可在百度生态内购买服务并结算跨境收入，率先抢占 DAA 时代的商业红利。

AgentUpdate 深度解析

传统的金融支付体系（如 Stripe 或 PayPal）是完全围绕人类行为设计的，其固有的身份验证（KYC）、高额手续费以及低频大额的清算机制，根本无法支撑 AI Agent 时代瞬时、海量、微额的 A2A 高频交易。FluxA 通过自研的 AEP2 协议，并兼容 #MCP 等前沿智能体协议，实质上为 AI 构建了首个专用的‘数字货币信用系统’。百度智能云此次与 FluxA 的合作，标志着国内大模型生态首次打通了跨境商业化的金融‘最后一公里’。这不仅能让国内开发者无需复杂的资质即可实现‘出海变现’，更从底层确立了 Agent 作为独立经济实体的‘自雇佣’模式，对多智能体协同生态的长远爆发具有里程碑式的启示意义。
