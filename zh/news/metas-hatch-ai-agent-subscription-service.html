Meta拟推出付费AI智能体Hatch，每月最高收费200美元

2026年6月6日 | 3 分钟阅读
#meta#hatch#openclaw#ai-agent

Meta正在开发一款名为Hatch的付费AI智能体（AI Agent）产品，其订阅费用最高可达每月200美元。作为开源工具OpenClaw的易用商业版本，#Hatch旨在帮助用户通过简单语言处理诸如编写软件工具、安排日程和发送电子邮件等任务。用户只需描述需求，Hatch就能将其转化为可运行的实际工具。这一动作让#Meta直接加入了与微软Scout和谷歌Gemini Spark等类似系统的正面交锋中。

根据Meta内部文件显示，该产品将提供免费版本以及名为“Hatch Plus”的高级订阅版。后者的使用额度将比免费版高出5到10倍。此举标志着Meta将与OpenAI和Anthropic展开直接竞争，后两者的高端订阅服务月费同样在100至200美元之间。据悉，Hatch计划于2026年7月在美国市场进行更大规模的推广。

此外，Hatch还将为Meta未来的AI硬件提供核心动力，包括配备“超感知”功能的全新智能眼镜，以及计划于2027年春季进行内部测试的AI吊坠（AI pendant）。首席执行官马克·扎克伯格（Mark Zuckerberg）将AI智能体视为开辟广告之外新营收渠道的关键，这对于回收Meta在AI基础设施上的巨额投资至关重要。

AgentUpdate 深度解析

Meta 推出 Hatch 标志着 AI Agent 竞争从纯软件转向“软硬一体”的生态争夺。相比 OpenAI 和 Anthropic 的单一订阅模式，Hatch 基于开源 OpenClaw 构建，并深度绑定 Meta 的智能眼镜等下一代硬件。这种策略能让 Agent 拥有物理世界的感知能力，突破了传统网页端助理的局限。这不仅将加速开源 Agent 框架的商业化落地，也将逼迫微软和谷歌加快其端侧 Agent 的硬件整合，从而深刻改变未来人机协同的生态格局。
