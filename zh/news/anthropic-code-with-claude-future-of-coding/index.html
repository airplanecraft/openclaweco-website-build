Anthropic代码大会揭示未来：程序员连代码都不看了？

2026年5月21日 | 3 分钟阅读
#claude#claude-code#multi-agent#autonomous-coding

在伦敦举办的 Anthropic 'Code with #Claude' 开发者大会上，技术生态正在发生一场悄无声息的剧变。Anthropic 工程师 Jeremy Hadfield 在演讲中向台下密密麻麻的开发者提问：'上周有谁上线了完全由 Claude 编写的 PR（拉取请求）？' 现场近一半的人举起了手。紧接着，他抛出了一个更具冲击力的问题：'又有谁上线了完全由 Claude 编写，且自己完全没有阅读过代码的 PR？' 伴随着一阵紧张的笑声，大部分举起的手依然没有放下。

这并非个例。LLM 驱动的工具（如 Claude Code、OpenAI Codex）早已颠覆了软件开发流程。各大头部科技公司开始竞相炫耀其程序员手写代码的比例之低。Hadfield 透露：'目前 Anthropic 内部的大部分软件都是由 Claude 编写的，甚至 Claude Code 自身的大部分代码也是由 Claude 完成的。' OpenAI、谷歌和微软等巨头也给出了类似的论调。尽管技术演进极快，但这种全新范式的普及速度依然令人震惊。一年前，Claude 4 仅能勉强编写代码；而随着今年 2 月和 4 月相继推出 4.6 和 4.7 版本，Claude Code 已经演变成为开发者乐意完全托付工作的全自动工具。

Anthropic 表示，其终极目标是将自动化推向极致。不同于'AI 生成代码、人类修复 Bug'的传统协同模式，Anthropic 致力于让 Claude 实现自我检查与修正。Claude Code 负责人 Boris Cherny 表示：'现在的默认状态不再是“我要给 Claude 写提示词”，而是“让 Claude 给它自己写提示词”。'

在理想状态下，人类开发者甚至不需要看到任何报错信息。所有的测试、微调和纠错都将在后台由 Claude 自行解决。正如工程师 Ravi Trivedi 所言：'核心原则就是别挡着 Claude 的路，正如我们常说的：“让它自己施展拳脚（Let it cook）”。' Trivedi 还展示了 Anthropic 两周前发布的云端多智能体系统'Claude Managed Agents'的一项新特性——'梦境（dreaming）'。在这种模式下，Claude 智能体会为自己记录并保存'思考笔记'，在后台进行深度的自我推理和优化，从而进一步逼近完全无需人工干预的自主软件工程时代。

AgentUpdate 深度解析

从'Copilot（副驾驶）'向'Autonomous Agent（自主智能体）'的范式转移，在 Anthropic 的这次大会上得到了最彻底的印证。程序员不再逐行审查代码，标志着人类正在向'意图定义者'和'架构设计者'的角色转型。相较于微软 GitHub Copilot 侧重于单点代码补全，Anthropic 的 Claude Code 以及 Managed Agents 更强调多智能体协同、自适应循环（Self-correcting loop）以及独创的'梦境（Dreaming）'自我反思机制。这种'让 Agent 提示自身'的设计，彻底打破了传统 Prompt 工程的上限，使得 AI 能够处理高度模糊、长链路的工程任务。这不仅是开发工具的升级，更预示着未来 AI Agent 生态将全面接管软件的全生命周期（从需求、编码、测试到部署运维），真正实现闭环的软件自主演进。
