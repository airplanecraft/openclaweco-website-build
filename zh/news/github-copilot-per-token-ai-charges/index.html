GitHub Copilot启用按令牌计费：开发者成本核算新模式

2026年5月1日 | 3 分钟阅读
#github copilot#token pricing#llm#developer tools#ai credits

GitHub Copilot 即将实施一项重大的计费模式调整：从下个月起，其AI服务将改为按“令牌”（token）收费。一个令牌通常相当于英文单词的四分之三左右。这意味着，如果一个大型语言模型（#LLM）需要分析一段包含 10,000 个单词的文本，将消耗大约 12,000 至 13,000 个令牌。

对于开发者而言，如果 Copilot 要审查一段由 10,000 个“单词”（包括表达式、语句、变量名、函数等）组成的复杂代码库（例如用于重构或查找 Bug），那么进行一次查询就可能消耗 12,000 至 13,000 个令牌，这将从其每月分配的额度中扣除。此外，用户输入的提示文本和 Copilot 的生成输出都将计入令牌消耗。

新的定价层级将保持现有月费不变，但用户不再获得每月固定查询次数，而是获得等值的“AI信用点”。例如，基础级别的 Copilot Pro 订阅者（每月 10 美元）将收到 1,000 个信用点。GitHub 表示，目前一个 AI 信用点价值一美分。

每个信用点能购买的令牌数量将取决于多种因素，包括所使用的 AI 模型、输入/输出的混合比例、缓存大小（LLM 为保持上下文而存储的数据），以及具体请求的功能。这意味着，如果开发者主要进行简单的查询，他们可能无需每月额外购买信用点。相反，涉及复杂、冗长代码库的多代理查询将更快地耗尽 AI 信用点账户。此外，查询最先进的“前沿模型”将比查询性能较低的模型花费更多。

值得一提的是，GitHub 的此次定价调整也带来了一些补偿性福利：代码补全功能（类似于手机的自动完成）和 Next Edit 建议将继续免费提供给用户。
