Amazon Quick助力Aderant：云运维搜索提速90%

2026年5月19日 | 3 分钟阅读
#mcp#aws#ai-agent#cloudops

全球领先的法律行业业务管理软件提供商 Aderant，近日成功转型了其拥有 38 人的云工程团队支持其云端法律实践管理解决方案 Expert Sierra 的方式。通过部署 Amazon Quick，Aderant 极大地加速了文档处理流程，并赋能其云工程团队，为依赖 Expert Sierra 进行日常运营的客户提供更快速、更具响应性的支持。

在引入该方案之前，Aderant 的云运营团队面临着一个普遍但严峻的挑战：关键信息分散在六个互不相连的系统中。支持 Expert Sierra 平台的工程师必须在多个仪表盘中繁琐地搜索所需答案。这种零散化带来了巨大的运营阻力，单次任务的手动搜索需要耗费 30 至 45 分钟，严重拖慢了故障响应和排查速度。面对每日超过 200 个支持工单以及全球 24 小时不间断的运维承诺，这些延迟迅速累积，导致工程师将大量宝贵时间浪费在“找信息”而非“解决问题”上。

2025 年 10 月，Aderant 部署了 Quick，并首先启动了 #CloudOps Helper 机器人的试点。项目实施进展迅速，于 2025 年 11 月完成了全员部署和 Chrome 浏览器扩展程序的推广。到 2026 年 2 月，云运营团队的成功经验推动了该方案向产品支持部门的扩展，推出了 Support Helper 机器人，为另外 86 名团队成员赋能。CloudOps Helper 机器人成为该方案的核心，实现了跨六大核心知识系统的统一 AI 搜索。工程师现在可以使用自然语言提出问题，并直接从 Confluence 文档、SharePoint 文件、Git 仓库、Jira 工单、Teams 对话和 QuickSight 仪表盘中获取整合后的答案。

值得关注的是，该团队利用预构建的集成功能，成功连接了这六大系统以及三个 #MCP（Model Context Protocol，模型上下文协议）服务器，在短短数周内（而非数月）就实现了系统上线。该平台内置的安全管理机制（包括支持单点登录）确保了数据访问的安全合规性。最终，这一变革帮助 Aderant 实现了搜索时间缩短 90%、文档处理流程加速 75% 的骄人战绩。

AgentUpdate 深度解析

本次 Aderant 的成功实践，核心亮点在于其对 MCP（模型上下文协议）服务器的深度集成。在传统的 AI Agent 落地过程中，多源异构数据的打通往往面临漫长的定制化开发周期。而 Aderant 通过 Amazon Quick 与 MCP 协议的结合，仅在数周内便实现了跨 Confluence、Jira、Teams 等六大系统的数据对齐。这不仅证明了 MCP 协议作为 AI Agent 生态“统一标准接口”的巨大商业潜力，也昭示了企业级 Agent 正从“孤立对话框”向“全流程协同助手”演进。相比传统的 RAG（检索增强生成），引入 MCP 的 Agent 具备更强的主动感知与跨工具调用能力。未来，随着 #AWS 等云巨头对 MCP 生态的持续加码，基于标准化协议的无缝集成将成为企业部署 AI Agent 的行业标杆。
