英国监管新规发力：谷歌被迫允许出版商一键退出AI搜索

2026年6月3日 | 3 分钟阅读
#google#ai-search#regulation#copyright

英国刚刚对谷歌的AI搜索扩张施加了法律约束。周三，谷歌宣布遵守英国的监管要求，允许出版商选择不将其内容汇总到AI搜索中。

为了实现这一退出机制，出版商将能够使用谷歌 Search Console 中的一个新开关（Search Console 是一款允许网站所有者管理其在谷歌搜索结果中展现形式的免费服务）。

一旦选择退出，出版商的网站将不会显示在谷歌的生成式AI搜索功能中，例如 AI Overviews、AI Mode 或 Discover 中的 AI Overviews。谷歌在其公告中特意指出，其 AI Overviews 目前拥有超过25亿月活跃用户，而 AI Mode 的月用户也已突破10亿。

这家科技巨头表示，它最初将在英国出版商的一个子集中测试这一退出选项，然后再向全球推广。

英国竞争与市场管理局（CMA）称，这一让出版商重新控制其内容使用方式的举措是"全球首创"，并指出这将使包括新闻机构在内的出版商在与谷歌就AI功能中的内容使用进行内容交易谈判时处于更有利的地位。

CMA 去年10月首次将谷歌指定为具有"战略市场地位"，为未来的监管奠定了基础。今年1月，它推动谷歌给网站出版商一个选择，即他们的内容是被汇总到AI搜索功能中，还是被用于训练独立的AI模型。

除了退出开关外，谷歌现在还被要求确保AI功能中的出版商内容得到适当的归属，并使用清晰的链接。谷歌暗示它也遵守了这一点，指出它最近增加了AI回答中直接嵌入的内联链接数量，并添加了网站预览以鼓励用户点击访问。

谷歌指出，网站选择退出生成式AI搜索功能将不会被用作传统谷歌搜索的排名信号。

然而，该公司将在其 Search Console 中呈现新的指标，以期说服那些正在考虑退出的出版商，包括展示量指标以及关于他们的哪些页面出现在AI回答中以及在哪些国家的其他信息。谷歌表示，随着时间的推移，将会添加更多指标。

AgentUpdate 深度解析

英国CMA此举不仅是对谷歌搜索帝国的一次监管重击，更是AI Agent时代内容生态博弈的分水岭。随着 RAG（检索增强生成）和主动式 AI Agent 成为新一代信息入口，传统“流量换内容”的Web生态正面临瓦解。CMA强制谷歌提供“退出开关”及“明确引用归属”，本质上是在为未来的 Agent 经济树立游戏规则——即数据与内容的控制权必须回归创作者。这不仅为出版商在与 LLM 厂商的内容授权谈判中提供了核心筹码，更警示了未来的 AI Agent 开发者：依靠无偿抓取网页数据来构建应用壁垒的时代正在终结。未来，标准化、可审计的 MCP（Model Context Protocol）或类似的授权数据接口，将成为 AI Agent 合规获取高质量实时知识的刚性技术路径。
