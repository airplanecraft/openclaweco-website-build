Anthropic携手普华永道：加速Claude企业级Agent应用落地

2026年5月15日 | 3 分钟阅读
#claude#claude-code#agentic-ai#enterprise-agents

生成式 AI 独角兽 Anthropic 与全球咨询巨头普华永道（PwC）宣布深化合作，旨在将 #Claude 模型深度嵌入更多大型企业的底层基础设施中，以此巩固 Claude 作为企业首选 AI 模型的市场地位。

作为“四大”会计师事务所之一，普华永道已同意在关键业务领域采用 Claude，以此推动各行业客户的 AI 应用进程。在此次合作中，普华永道将部署 Claude Code，以加速 Agentic（智能体）技术的开发，从而显著提升软件交付效率。

普华永道指出，其在金融服务、制药和生命科学等多个行业的客户群中，对部署 AI Agent 的需求正呈现爆发式增长。除软件开发外，双方还将聚焦于优化商业交易（Deal-making）流程，使 AI Agent 能够与现有的专业团队协同工作。

AgentUpdate 深度解析

本次 Anthropic 与普华永道的深度合作，标志着 AI Agent 正在从“极客玩具”走向“企业级刚需”。值得关注的是，普华永道明确引入了“Claude Code”来加速 Agentic 技术的开发。与传统的 API 调用相比，直接在代码级和工作流中嵌入 Agent，能以极低的延迟和更高的自主性解决复杂业务逻辑。横向对比 OpenAI 在企业端的直接销售策略，Anthropic 选择绑定咨询巨头的生态，通过普华永道的行业 Know-how 将 Claude 转化为可落地的 Agent 解决方案。这种“模型+咨询+Agent 框架”的组合拳，不仅能够解决企业数据合规与场景定制的痛点，更将加速金融、医药等高门槛行业向“Agentic Enterprise”（智能体企业）的范式转移。
