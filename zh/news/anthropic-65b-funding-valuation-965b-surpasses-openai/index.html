估值逼近1万亿美元！Anthropic获650亿融资超越OpenAI

2026年5月29日 | 3 分钟阅读
#anthropic#claude#claude code#openai

生成式 AI 独角兽企业 #Anthropic 周四宣布，已在 H 轮融资中成功筹集了 650 亿美元。这笔交易使其投后估值直接翻倍，达到了令人瞩目的 9650 亿美元，逼近 1 万亿美元大关。

这意味着，这家总部位于旧金山的初创公司在估值上已经超越了其最大的劲敌 OpenAI。今年 2 月，OpenAI 曾宣布以 8400 亿美元的投后估值完成了 1100 亿美元的融资。根据 Crunchbase 的数据，那次融资曾创下了历史上规模最大的单笔融资纪录。

领投 Anthropic 最新一轮融资的机构包括 Altimeter Capital、Dragoneer、Greenoaks 和红杉资本（Sequoia Capital）。Capital Group、Coatue、D1 Capital Partners、GIC、Iconiq Capital 和 XN 参与了联合领投。本次融资还包含了超大规模云厂商此前承诺的 150 亿美元投资，其中包括来自亚马逊（Amazon）的 50 亿美元——值得玩味的是，亚马逊同样参与了 OpenAI 最近的一轮融资。

Anthropic 这一创纪录的巨额融资，距离其在 G 轮融资中募集 300 亿美元（当时估值为 3800 亿美元）仅过去了三个多月。自 2021 年成立以来，该公司已累计筹集了近 1440 亿美元的资金。

自上一轮融资以来，Anthropic 表示其企业客户群体实现了爆发式增长。据该公司透露，本月早些时候，其年化营收运行率（run-rate revenue）已经突破了 470 亿美元。

“#Claude 正在成为我们日益壮大的全球企业客户群中不可或缺的生产力工具。我们正孜孜不倦地努力，使 #Claude Code 和 Cowork 等工具更加实用、更加强大，并能完美契合他们的业务需求，” Anthropic 首席财务官 Krishna Rao 在博客文章中表示。“这笔资金将帮助我们应对目前面临的历史性市场需求，始终坚守在科学研究的最前沿，并将 Claude 引入到更多实际工作的场景中。”

AgentUpdate 深度解析

Anthropic 估值逼近万亿美元并历史性超越 OpenAI，标志着大模型之战的胜负手正从“基础模型竞赛”彻底转向“AI Agent 商业化生态”。相比 OpenAI 偏向消费级和全能型的路线，Anthropic 凭借 Claude 3.5 系列在代码生成和复杂逻辑推理上的绝对优势，通过 Claude Code、Cowork 以及开源 Model Context Protocol (MCP) 协议，深度切入企业级智能体（Agent）生态。其 470 亿美元的惊人年化营收，证明了 Agent 化开发者工具与企业级协同方案具有极强的商业变现效率。此次资金的注入，将允许 Anthropic 在 Agent 底层标准和企业级自主智能（Autonomous Agents）领域建立更深的生态壁垒，逼迫整个行业加速从“对话框”向“主动规划、多工具协同”的 Agent 2.0 时代演进。
