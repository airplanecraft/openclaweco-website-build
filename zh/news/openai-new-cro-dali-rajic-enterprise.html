OpenAI高层动荡持续：挖角Wiz前总裁接任CRO，全力加速商业化

2026年8月14日 | 3 分钟阅读
#openai#enterprise-ai#agent-ecosystem#business-strategy

OpenAI 已经更换了上任仅九个月的首席营收官（CRO） Denise Dresser，转而挖角网络安全巨头 Wiz 的前总裁兼首席运营官 Dali Rajic 接掌这家前沿 AI 实验室的顶级销售帅印。

此举是该公司过去一个月内更大规模管理层重组的一部分。此前，#OpenAI 首席运营官（COO） Brad Lightcap 以及负责 AGI 部署的二号人物 Fidji Simo 已相继离职。

在 Simo 离职后，OpenAI 联合创始人兼总裁 Greg Brockman 在管理层中承担了更大职责，并于今日在官方博客中正式宣布了 Rajic 的加入。值得注意的是，Rajic 的前东家 Wiz 此前曾因被谷歌拟以 320亿美元 巨资收购而备受业界瞩目。

“Denise 带领我们的营收部门走过了业务成型的关键时期，”Brockman 在博客中写道，“如今，我们部署技术的方式正在迅速变化，Dali 将把我们积累的经验转化为 可复制的执行力，以构建完整的系统，让 AI 对个人和企业都产生广泛价值。”尽管 OpenAI 宣称其产品周活跃用户已突破 10亿，且拥有超过 200万 家企业客户，但内部和外部消息均表明，该公司尚未完全达到其预期的营收目标。

此外，OpenAI 已向美国证券交易委员会（SEC）秘密提交了 IPO 招股说明书，但具体上市时间表尚不明确。为了在公开市场亮相前完善高管架构，OpenAI 本周还通过员工持股回购计划套现了价值 70亿美元 的股份。首席执行官 Sam Altman 今年多次强调，公司将集中精力进行 企业端部署，并削减那些偏离该目标的非核心探索性项目。

AgentUpdate 深度解析

此次高管大洗牌以及引入 Wiz 商业化强人 Dali Rajic，标志着 OpenAI 已经从单纯的技术研发主导，正式迈向了“降本增效、高阶商业化”的深水区。在 AI Agent 生态中，技术的终极护城河不在于基础大模型的参数量，而在于其在企业级工作流中的实际转化率。相比于传统的 API 调用，Agent 系统的落地更依赖于深度的安全合规、多系统协同与可持续的 ROI（投资回报率）。Rajic 在 Wiz 打造的安全级企业销售范式，将直接帮助 OpenAI 的 Agent 架构 攻克金融、医疗等高壁垒行业。这种转型对整个行业极具启发性：未来的 Agent 竞争将从“谁的推理能力强”向“谁能提供最安全、最标准化、且具备可复制商业闭环的 Agent 落地方案”演进。
