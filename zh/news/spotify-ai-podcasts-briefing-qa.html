Spotify推出AI播客功能：支持文档生成、个性化简报与智能问答

2026年5月21日 | 3 分钟阅读
#notebooklm#elevenlabs#ai-agents#text-to-speech#spotify

对于广大用户而言，#Spotify 一直是一个消费他人创作的播客内容的平台。然而，该公司正试图通过引入“个人播客”（personal podcast）功能来彻底改变这一现状。该功能利用人工智能技术，允许用户根据特定的创意或自定义提示词（Prompt）来生成专属的个人播客。

本月早些时候，Spotify 发布了一款基于 GitHub 的命令行工具，该工具适配 Claude Code 和 Codex，允许用户自行创建播客并将其直接保存到自己的 Spotify 媒体库中。该公司表示，不久后，用户将能够直接在 Spotify 移动应用程序内无缝创建播客。不仅如此，用户还可以对这些播客设置定时任务，针对自己长期关注的主题生成每日或每周的个性化简报，或者生成一次性的播客以快速理解某一特定领域的知识。

具体而言，用户可以向 AI 发出类似“分享我关注的城市每日动态，并告诉我喜爱的歌手最近有哪些本地音乐会”或“帮我在五分钟内理解经济学原理”等指令，系统便会自动生成对应的播客并存入媒体库供个人消费。此外，用户还可以上传外部链接、PDF 文档以及纯文本，并选择自定义声音来生成播客。这一做法显然借鉴了 Google #NotebookLM、#ElevenLabs Reader 以及前 NotebookLM 开发者推出的 Huxe 等产品，旨在让用户能够针对任何主题创建个人专属音频内容。

作为配套，Spotify 还推出了一款名为“Studio by Spotify Labs”的专属桌面端应用程序，该应用可以连接用户的个人电子邮箱和日历，从而智能生成极具个性化的日常简报播客。

在面向听众的交互层面，Spotify 今日起在美、瑞典和爱尔兰向 Premium 订阅用户推出了一项 AI 驱动的问答（Q&A）功能。借助该功能，用户可以直接对当前正在收听的播客单集或其中提到的某个概念进行提问并获取解答，甚至可以要求 AI 推荐特定主题的播客。在此之前，Spotify 已于今年 4 月推出了基于提示词自动创建播客播放列表的功能。

此前，Spotify 的战略重心一直放在推动视频播客的消费上。据官方数据显示，收听视频播客的用户数量同比增长了 50%。而随着本次新功能的发布，Spotify 显然希望通过引入类似 Google 本周推出的“Ask YouTube”功能，让用户通过对播客内容提问、定制兴趣播客等方式，进一步加深与 App 的高频互动。对于播客创作者，Spotify 也同步向其开放了创作者赞助工具以管理品牌合作，并新增了订阅制功能，允许创作者通过付费墙解锁独家内容和体验。

AgentUpdate 深度解析

Spotify 此次向个人 AI 播客和智能音频简报的推进，绝非简单的“音频版 NotebookLM”，而是 AI Agent 在多模态信息获取与泛在化交互（Ambient Interaction）领域的一次重大演进。通过将“Studio by Spotify Labs”直接连接到用户的邮箱和日历，Spotify 实际上是将 AI Agent 塑造成了一个主动式、个性化的“音频秘书”。它改变了传统 Agent 依赖于“对话框（Chatbox）”的被动交互模式，转向了“主动集成、跨源合成、语音输出”的无感式消费流程。在 AI Agent 生态中，声音不仅是交互媒介，更是降低高净值信息消费门槛的关键。Spotify 凭借其在移动端、车载系统和可穿戴设备上的极高渗透率，极有可能成为未来环境智能（Ambient Intelligence）时代，个人 Agent 落地和吞噬传统信息入口的核心生态平台。
