金山办公WPS新版上线：推出存储管理与AI Agent灵犀

2026年8月1日 | 3 分钟阅读
#wps#kingsoft#lingxi#wps-comate#ai-agent

7月31日，金山办公首次参展 ChinaJoy。在活动现场，金山办公不仅展示了其独立的 AI 办公 Agent 灵犀 以及面向研发场景的智能编码助手 WPS Comate，还特别设置了面向用户的反馈互动区。

同日，包含“存储管理”等多项重大更新的 WPS Office 新版本正式上线。本次更新针对用户痛点，围绕 C 盘存储管理带来了两项核心改进：

首先，#WPS 新增了统一的“存储管理”入口。原本分散在各个菜单深处的磁盘占用查看、缓存清理以及存储路径调整等功能，如今被集中整合到了同一个直观的页面中。其次，新版本支持对安装路径进行分别设置，使用户能够更加灵活地规划系统盘空间。

AgentUpdate 深度解析

随着大语言模型和 AI Agent 的深度融合，传统办公软件正在经历从“工具”到“智能助手”的范式转变。金山办公在此次展会上推出的独立 AI 办公 Agent“灵犀”以及研发助手 “WPS Comate”，代表了 AI Agent 在端侧与协同办公场景的最新落地尝试。横向对比 Microsoft 365 Copilot 或 Google Workspace，金山办公通过“灵犀”展示了更符合中国用户习惯的轻量化、场景化 Agent 交互。然而，AI Agent 的运行对本地算力和存储空间提出了更高的要求。WPS 此次同步上线的“存储管理”功能表面上是系统盘物理瘦身，实际上是为未来更大规模的端侧 AI 模型部署和本地知识库（RAG）存储预留空间。解决端侧存储与能耗痛点，将是 AI Agent 走向大众化普及的关键技术基础设施。
