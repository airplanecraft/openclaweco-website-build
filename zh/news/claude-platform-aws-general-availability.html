Anthropic Claude 平台现已登陆 AWS：集成简化 AI 访问

2026年5月12日|3 分钟阅读
#claude#aws#anthropic#ai agent#iam

Anthropic 近日宣布，其 #Claude 平台现已在 #AWS 上全面推出。这项新服务允许客户通过其 AWS 账户直接访问 #Anthropic 原生 Claude 平台体验，无需单独的凭证、合同或计费关系。AWS 也因此成为首个提供原生 Claude 平台访问的云服务提供商。

通过 AWS 上的 Claude 平台，客户可以使用与直接通过 Anthropic 访问时相同的 API、功能和控制台体验。这包括 Messages API、Claude Managed Agents（测试版）、advisor 工具（测试版）、web search 和 web fetch、MCP 连接器（测试版）、Agent Skills（测试版）、代码执行以及 files API（测试版）。更多功能详情可查阅 Claude 平台文档。

该平台与 AWS 现有功能深度集成，操作便捷。认证方面，用户可沿用现有的 AWS IAM 凭证，无需管理额外的账户或 API 密钥。计费则通过 AWS Marketplace 按使用量收费，方便用户将 AI 支出与其它 AWS 服务一同追踪和管理。此外，所有活动都会记录在 AWS CloudTrail 中，确保 AI 使用情况的监控、审计和调查方式与其它 AWS 服务保持一致。

AWS 上的 Claude 平台由 Anthropic 运营，底层请求和数据在 AWS 安全边界之外处理。这种架构特别适合没有特定区域数据驻留要求的团队，并与 Amazon Bedrock 上提供的 Claude 模型形成互补，为用户提供了根据自身需求选择访问 Claude 能力的途径。

要开始使用 AWS 上的 Claude 平台，客户可通过 AWS Marketplace 激活。账户激活后，首次进行 API 调用只需三步：创建工作区、进行身份验证并调用 API。

工作区（workspace）旨在帮助用户分离项目、环境或团队，同时实现集中的计费和管理。它也是 AWS 上的 Claude 平台主要的 AWS Identity and Access Management (IAM) 资源，允许用户通过 IAM 策略，利用工作区 ARN 对特定工作区授予或拒绝访问权限。

AWS 上的 Claude 平台支持使用现有 AWS IAM 凭证进行身份验证，从而简化了安全访问管理。
