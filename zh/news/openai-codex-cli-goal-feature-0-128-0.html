Codex CLI 0.128.0 新增/goal功能：OpenAI代码代理实现目标导向

2026年5月1日 | 3 分钟阅读
#codex-cli#coding-agents#agentic-engineering#prompt-engineering#llms

2026年4月30日，OpenAI宣布为其Codex CLI代码代理工具发布了0.128.0版本更新。此次更新的核心亮点是引入了创新的/goal功能，旨在提升代理的自主执行能力。

这项新功能被描述为OpenAI自身对“Ralph循环”理念的实现。通过设定一个明确的/goal（目标），用户现在可以让Codex进入一个持续的循环执行模式。在该模式下，Codex将自主评估任务进展，并持续工作，直至判定所设定的目标已成功完成，或者预设的代币预算（token budget）耗尽为止。

从技术实现层面来看，/goal功能主要依赖于两个关键的提示（prompts）文件：goals/continuation.md和goals/budget_limit.md。这两个提示会在每一次任务轮次（turn）结束时被系统自动注入，以指导Codex的后续行为和代币预算的管理，确保代理在目标导向的前提下高效运行。
