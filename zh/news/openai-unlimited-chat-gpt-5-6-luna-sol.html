OpenAI放开限制：免费用户可无限次聊天，引入思考按钮

2026年8月7日 | 3 分钟阅读
#openai#chatgpt#gpt-5.6#reasoning-models#llm

OpenAI今日宣布，将取消所有用户在#ChatGPT上的文本聊天限制。值得一提的是，ChatGPT最近的周活跃用户数已突破10亿大关。

这一全新体验将由全新的GPT-5.6 Luna模型提供支持。该模型将作为免费版（Free）和入门版（Go）用户的默认模型，彻底替代此前的GPT-5.5。

这两类用户还将获得一个全新的"思考"（Think）按钮，允许他们在面对复杂问题时选择更高的推理能力。不过，#OpenAI表示，针对文件、图像、语音和图像生成等功能，依然会保留独立的限制额度。

此次更新同样为Plus和Pro付费用户带来了重大改变。他们将率先体验升级版的GPT-5.6 Sol模型，该模型在快速问答、网页搜索、建言献策、规划、写作以及决策等日常任务中表现更佳。官方指出，新模型能够提供更精简、更稳健的回答。（注：该版本与用于Codex和Work的#GPT-5.6 Sol版本相互独立，后者保持不变。）

此外，ChatGPT Plus和Pro用户还将获得一个全新的"思考滑块"（thinking slider），用以调节模型在回答时投入的"思考量"。用户可以根据查询的复杂程度和解决问题所需的步骤，自由调整思考深度。

在安全性与准确性方面，OpenAI的内部评估显示，与GPT-5.5-Instant相比，GPT-5.6 Luna的虚假信息（幻觉）减少了62%，而GPT-5.6 Sol的幻觉则减少了68%。

升级版的GPT-5.6 Sol已于今日向Plus和Pro用户开放，而针对免费版和Go用户的其他更新将于本周陆续推出。下周，所有用户都将正式获得无限制的文本聊天权限以及用于应对高难度问题的“思考”按钮。

AgentUpdate 深度解析

OpenAI 此次将无限制文本聊天与“思考”功能下放到免费用户，标志着大模型行业从单纯的“算力付费”向“深度思考按需分发”的重要转变。引入“思考按钮”与“思考滑块”是交互设计上的一次关键创新。在 AI Agent 生态中，这解决了长期存在的“黑盒推理成本”与“用户控制感”之间的矛盾。相较于 Anthropic Claude 的固定推理模式，OpenAI 的“可调思考”不仅允许用户在轻量化交互（如日常对话）与深度推理（如复杂 Coding 或多步骤规划）之间自由切换，更是未来 Agent 自主决策链路（Reasoning Loop）的一种显性化控制方式。随着幻觉率下降超过 60%，GPT-5.6 系列模型将显著提升智能体在执行长期规划和复杂工作流（Workflow）时的稳定性。这种“普惠推理”也将极大地降低第三方开发者构建低延迟、高可靠 Agent 应用的门槛，进一步加速 Agent 从单一工具向生产力助手的生态演进。
