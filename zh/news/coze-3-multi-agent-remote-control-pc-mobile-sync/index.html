扣子3.0实测：跨端协同，手机秒变电脑Agent遥控器

2026年6月4日 | 3 分钟阅读
#coze#multi-agent#mcp#orchestration

字节跳动旗下AI平台“扣子”（#Coze）正式发布3.0大版本。本次升级打破了传统单点AI对话的界限，全面打通了iOS/Android手机端、Mac/Windows电脑端以及网页端。扣子3.0不再依赖单个通用AI来处理所有任务，而是引入了“多Agent协同”和“项目化”理念，让一组术业有专攻的Agent组团为用户打工。

多Agent协同实测：一个“@”实现团队化开工
在扣子3.0中，用户可以创建一个“项目”，并在其中引入多个不同分工的Agent。例如，在开发一个“AI热点追踪仪表盘”的实测中，我们引入了平台自带的Agent“小曜”，以及自定义的选题写作Agent、产品设计Agent和前端开发Agent。通过在Prompt中@这些Agent，他们便能如真实的敏捷团队一般，自行分工、交替输出：从新闻筛选、需求拆解，到直接生成可运行的前端代码。整个过程不再是单一AI给出的长篇大论，而是专业角色之间的流水线连续协作。

除了云端创建和平台内置的Agent外，扣子3.0还支持一键导入用户本地已用熟的开发工具，如Claude Code、Codex CLI或OpenClaw等，极大丰富了Agent生态的接入能力。

端到端产品与多模态创作
为进一步测试其工程化能力，我们尝试了开发一个“AI编辑部桌宠”网页Demo（React + Tailwind）。扣子3.0展现了出色的逻辑结构拆解和前端代码编写能力，成功实现了带待机、思考、提醒、夸夸四种状态的可爱交互式桌宠。此外，多模态创作项目也得到了强化。我们将一篇生成的NVIDIA科技文章丢入视频项目，调用其默认搭载的Seedance 2.0视频生成模型，在极短时间内便输出了一段音画对齐、支持资产沉淀的45秒科技感短视频。

手机遥控电脑：打破物理设备壁垒
本次更新最令人瞩目的功能之一是跨端联动。在实测中，我们在PC桌面上放置了一份NVIDIA财报PDF。随后在扣子3.0的手机App端发送指令：“帮我分析我电脑桌面上的财报”。在获得授权的前提下，手机端Agent成功调取并解析了电脑本地的文件。这种桌面端与移动端的无缝打通，让Agent能够真正触达本地工作流，使手机成为了PC端Agent的“远程遥控器”。

AgentUpdate 深度解析

扣子 3.0 的发布，标志着 AI Agent 从单一“Chat 界面”向“协同 OS（操作系统）”过渡的拐点。以往的 Agent 平台多专注于提升单体大模型的推理与执行力，而扣子 3.0 则通过“项目制多 Agent 协同”和“跨端打通（PC/Mobile/Web）”，探索了下一代 AI 工作流的范式。通过支持导入本地 Claude Code 等外部 Agent，它在事实上构建了一个异构 Agent 的调度中枢。最核心的突破在于桌面端与移动端的打通，这解决了 AI 长期无法触达本地私有物理环境的痛点。未来，Agent 的胜负手将不再仅仅是底座模型的能力，而是其在多端设备、私有本地数据和第三方异构 Agent 之间的编排与调度效率。
