GPT-5.6震撼发布！多Agent协同与程序化调用，重塑办公生态

2026年7月10日|3 分钟阅读
#gpt-5.6#openai#agent-orchestration#chatgpt-work

OpenAI 凌晨发布了迄今为止最强模型 GPT-5.6，奥特曼高调宣布其技术博客也是有史以来写得最好的。此次发布不仅重塑了 ChatGPT 桌面版，还将 Codex 进行了深度融合升级。原有的 Codex 桌面应用直接升级成了新的 ChatGPT 桌面应用，而老版 ChatGPT 桌面应用则更名为 "ChatGPT Classic"。

社区已经玩疯了。开发者 Matt Shumer 展示了让 GPT-5.6-Sol 自主运行一周，完美复刻出像素风的“曼哈顿乐高城”；而数学研究者则在它的帮助下，通过分式线性规划算法，成功突破了代数几何中关于 K3曲面 猜想的计算瓶颈。不过，也有不少专业用户吐槽，全新的 ultra 模式在 15 分钟内就能烧光 Pro 会员 5 小时的额度，可谓“Token 吞噬兽”。

GPT-5.6 家族包含三款模型：旗舰级 Sol、平衡型 Terra 和高性价比的 Luna。其中最引人瞩目的是全新的 ultra 模式，它并非只是增加单模型推理时间，而是直接在底层协同多达 4到16个 Agent 并行处理复杂任务。同时，#GPT-5.6 引入了程序化工具调用（Programmatic Tool Calling），允许模型自写轻量程序协调工具并监控进度，从而大幅缩减了中间状态的 token 消耗。

在长周期工作流测试 Agents' Last Exam 中，Sol 斩获 53.6 分，超越了 Fable 5 达 13.1 分。即便在极低成本下，小尺寸模型 Terra 和 Luna 也能成功反超 Fable 5。此外，Sol 在端到端操作和知识工作中表现亮眼，在 OSWorld 2.0 上取得 62.6% 的成绩，超越 Claude Opus 4.8 且输出 token 减少了 85%。它甚至能自主进行界面设计和电脑操作，对渲染出的最终页面进行视觉与功能上的打磨，直接生成丝滑的互动交互。

与此同时，ChatGPT Work 正式登场。它由 GPT-5.6 和 Codex 双重驱动，支持跨应用（如 Google Drive、Slack、Teams、Gmail）无缝读取数据，并能通过 Scheduled Tasks 定时或触发执行，最终直接交付符合模板规范、排版完美的 Excel 表格、PPT 演示文稿等最终完成品，而不再仅仅提供草稿。

AgentUpdate 深度解析

GPT-5.6 的发布，特别是其“ultra”模式下的多 Agent 协同以及“程序化工具调用（PTC）”，标志着 AI Agent 生态正从“单体长推理”向“集群分布式协同”演进。传统的 ReAct 框架或硬编码多 Agent 方案往往面临状态机爆炸和高延迟的瓶颈，而 PTC 赋予了 Agent 自主编写协调代码的能力，极大地收敛了系统复杂度并降低了 Token 消耗。此外，GPT-5.6 在 OSWorld 2.0 上的优异表现以及对渲染视觉效果的“自主打磨”能力，证明了 Agent 的具身生存能力已从单纯的代码生成迈向了“闭环视觉感知与操作”。这给开发者带来启示：未来的 Agent 竞争不再仅是底层大模型智商的拼杀，而是基于类似 ChatGPT Work 的系统级工程设计、多 Agent 调度编排效率、以及对复杂真实世界环境的自主质检与交付能力。
