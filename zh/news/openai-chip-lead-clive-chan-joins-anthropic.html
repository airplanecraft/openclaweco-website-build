OpenAI自研芯片骨干叛逃Anthropic！就在首款芯片量产前夜

2026年6月7日 | 3 分钟阅读
#silicon#asic#openai#anthropic#hardware

就在首款自研芯片即将量产的关键节点，OpenAI 的核心硬件骨干突然宣布出走。近日，#OpenAI 芯片团队的核心成员 Clive Chan 在 X 平台宣布离职，并透露自己已于本周正式加入竞争对手 Anthropic。

作为 OpenAI 硬件组的“二号员工”，Clive Chan 自 2024 年 1 月加入以来，在过去两年半（约 30 个月）的时间里，深度参与并主导了 OpenAI 的自研芯片设计。他坦言，前东家拥有全球顶尖的芯片设计团队和惊人的硬件人才密度，但他“无法摆脱从山脚开始攀登新高峰的冲动”。他选择加入 #Anthropic 的原因可以用三个词概括：天赋（talent）、价值观（values）和抱负（ambition）。

在 OpenAI 期间，Chan 负责的最核心项目莫过于与 博通（Broadcom） 合作设计的 10GW 定制 AI 加速器。该芯片采用 台积电 3nm 先进工艺。Chan 此前曾透露，该自研芯片计划在设计完成后 9 个月内实现量产。如今随着量产前夜的到来，Chan 选择在任务功成圆满后低调离去，开启他的下一站旅程。

Clive Chan 的履历极其亮眼。在加入 OpenAI 之前，他曾于 2021 年起在特斯拉的 Tesla Dojo 超算团队工作，负责训练 ASIC 的软件框架与数据中心协同设计，并每周直接向马斯克汇报。2024 年 1 月，他作为第二号硬件员工加入 OpenAI 自研芯片项目，成为当时仅由前 Google TPU 负责人 Richard Ho 领导、尚未最终确定路线的早期团队中的首位独立贡献者（IC）。目前，该自研芯片团队规模已扩大至约 40 人。

Chan 的加盟对于 Anthropic 而言无疑是一剂强心针。早在今年 4 月，外界就传出 Anthropic 计划推进自研芯片，但由于处于极早期阶段，团队尚未完全成型，设计路线也未明确。随着这位拥有 Dojo 和 OpenAI 成功操盘经验的硅谷老兵加入，Anthropic 的自研芯片计划大概率将从早期的探索阶段，全面转向实质性的工程落地。

业内对此也议论纷纷。著名 AI 学者 Gary Marcus 指出，人才用脚投票表明投资者在面对 OpenAI 的 IPO 估值时需要更加谨慎。同时，也有人调侃 OpenAI 如今成了 Anthropic 的“人才培训基地”。但不可否认的是，两家估值一路狂飙的超级独角兽，正在硬件底层展开更加激烈的正面交锋。

AgentUpdate 深度解析

随着大模型向具身智能和自主 Agent 快速演进，AI 军备竞赛正从单纯的“算法卷”向“软硬一体化”的底层算力重构转变。Clive Chan 从 OpenAI 功成身退并转战 Anthropic，折射出头部 AI 实验室在自研 #ASIC 领域的焦灼态势。对于 AI Agent 生态而言，通用的 GPU 算力虽然强大，但在多模态实时交互、自主规划（Reasoning）以及边缘端轻量化部署上，往往伴随着高昂的延迟与能耗成本。专属 AI 加速芯片的量产，不仅能大幅降低 Agent 运行的推理成本（Token Unit Economics），更通过端到端软硬件协同设计，为高频、复杂的 Agent 多步骤反思与工具调用提供极致的低延迟支持。这股自研芯片风潮，将加速 Agent 生态走向千行百业的商业化临界点。
