Anthropic Claude代理能“做梦”了：新特性赋能AI自主学习与记忆优化

2026年5月7日 | 3 分钟阅读
#claude#anthropic#ai agents#memory management#self-improvement

Anthropic 近期为其 #Claude Managed Agents 推出了一项名为“做梦”（dreaming）的新功能，旨在让AI代理能够通过回顾和学习来“自我提升”。这项更新基于现有记忆能力，标志着AI代理在自主学习方面迈出了重要一步。

Claude Managed Agents 于4月8日发布，它提供了一套API，旨在简化开发者构建和部署AI代理的繁琐过程，使团队能够以十倍的速度大规模推出代理。而新加入的“做梦”功能，则让代理能通过分析过往会话，识别模式、纠正错误并优化工作流程。

具体来说，“做梦”功能会为代理安排时间，让它们回顾并从过去的交互中学习。一旦该功能开启，代理可以自动更新其记忆以塑造未来的行为，开发者也可以选择性地批准这些变化。#Anthropic 在官方博客中指出，“做梦”能揭示单个代理无法自行发现的模式，例如重复性错误、代理趋同的工作流以及团队共享的偏好。它还能重构记忆，使其在演进过程中保持高信号值，这对于长期运行的任务和多代理协作尤其有用。

在“Code with Claude”活动中，Anthropic 产品团队成员演示了这一功能，并将完成的运行称为“已完成的梦想”。同时，Anthropic 还扩展了两项现有功能：用于确保代理保持任务专注的“成果”（outcomes）功能，以及处理任务委托给其他代理的“多代理编排”（multi-agent orchestration）功能。公司表示，所有这些更新旨在确保代理的准确性并持续学习。

值得注意的是，Anthropic 再次选择了一个拟人化的名称——“做梦”，这与公司一贯的做法相符。从功能上看，“做梦”能够进一步完善代理的参考池，使其在执行任务时表现更佳。Anthropic 长期以来一直致力于将其模型和产品拟人化，例如在今年1月为 Claude 发布了“宪法”，旨在塑造其决策并定义其理想的“实体”形态。文档中的一些措辞甚至暗示，Anthropic 正在为 Claude 发展意识做准备。
