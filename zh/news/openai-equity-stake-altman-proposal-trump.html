OpenAI拟推全民持股，美国家庭或分300美元

2026年7月7日 | 3 分钟阅读
#openai#anthropic#ai-agent#regulation

从某种意义上说，山姆·奥特曼（Sam Altman）的这一计划并非新鲜事。早在2021年，他就曾提出过一个更激进的版本：所有市值超过一定门槛的公司（不仅限于AI公司）每年将其市值的2.5%注入一个基金，用于向美国公民发放年度分红。今年4月，OpenAI描述了一个更为具体的方案，这与奥特曼目前正与特朗普讨论的方案非常相似。这种“全民持股”的概念在政治上具有广泛的吸引力，例如参议员伯尼·桑德斯（Bernie Sanders）就曾提议让美国人持有顶级AI公司50%的股份。

那么，这背后的逻辑是什么？对于潜在的受益者来说，主要有两个原因。首先，人工智能直接从人类创作的成果（如书籍、电影、艺术品）中进行学习，但AI公司通常从未向这些创作者支付报酬。免费提供股权可以作为一种“迟到的补偿”。其次，尽管经济学家们对此持有不同意见，但这种分红可以作为一种社会安全网，以缓解人们对AI将导致劳动力市场崩溃的普遍焦虑。

这个安全网究竟能有多大？关于#OpenAI最新提议的细节依然含糊不清。但假设美国政府直接将这笔股权分配给民众。在今年3月的融资之后，OpenAI的估值达到了8520亿美元，这意味着其5%的股份如今价值约426亿美元（据报道，该公司正推迟其IPO，直到其估值达到1万亿美元，考虑到其在数据中心上的巨额支出且尚未实现盈利，这是一项艰巨的任务）。如果将这426亿美元平均分配给全美约1.33亿个家庭，每个家庭将获得约320美元的股权。不过，如果它像其他主权财富基金那样运作，政府可能不会直接分发股权，而是让基金增值，然后将部分收益分给全民，前提是AI公司能开始持续盈利。

如果这种分红真的实现，科技公司能得到什么？奥特曼或许希望，分红的承诺能够将公众舆论引回有利于AI公司的方向。毕竟，大多数美国人并不信任公司会负责任地使用AI，也反对在其地区建设数据中心。但对OpenAI来说，更大的奖赏在于特朗普政府热衷于达成科技交易——例如其持有英特尔（Intel）的股份以及在英伟达（Nvidia）向中国销售产品中分成。与政府保持良好关系对目前的AI公司至关重要（看看Anthropic就知道了），这可能意味着免于被视为供应链风险，或者在阻止中国竞争对手方面获得白宫的更多协助。

然而，目前的这一计划更像是一个公关故事，而非实际的政策。奥特曼兜售这个想法已有五年，并在特朗普上任后不久便向其进行了推介，但目前仍没有明确的政策实施迹象。

AgentUpdate 深度解析

奥特曼倡导的“AI全民持股”计划，本质上是AI巨头在面临日益严峻的版权指控与“去就业化”社会焦虑时，所采取的一种地缘政治与公关层面的“防御性创新”。从 AI Agent 生态的角度来看，未来的 Agent 将不仅是生产力工具，更是消耗海量计算资源与数据资产的“数字劳动力”。这种将国家、公众与AI巨头利益深度捆绑的“主权财富基金”模式，若能落地，将为 AI Agent 的全自动化生产构建起一种新型的分配正义框架。对比 Web3 领域的代币经济学（Tokenomics）或传统的全民基本收入（UBI），该方案将AI生产力增值直接转化为国家资本红利，不仅能为Agent技术可能造成的劳动力市场冲击提供社会安全垫，更在客观上通过“国家队入股”的形式，为 OpenAI 及其生态内的 Agent 应用筑起了极高的合规与地缘竞争壁垒。
