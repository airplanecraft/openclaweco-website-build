Anthropic每月超12亿美元向SpaceX买算力

2026年5月21日 | 3 分钟阅读
#anthropic#spacex#colossus#compute

埃隆·马斯克（Elon Musk）旗下的航天巨头 #SpaceX 迎来了一个极其稳定的全新收入源：AI 独角兽 #Anthropic 已同意每月向其支付高达 12.5 亿美元的算力费用，该协议将一直持续到 2029 年 5 月。

根据本周三披露的 SpaceX 招股说明书（S-1 文件），这一巨额交易是在该公司筹备首次公开募股（IPO）的过程中公开的。根据协议，Anthropic 将从 SpaceX 位于田纳西州的 #Colossus（巨像）数据中心购买海量计算资源。Anthropic 本月早些时候曾宣布，由于用户群体的爆发式增长，它需要为其日益庞大的客户群及 AI 工具套件寻找更强劲的算力支撑。而 SpaceX 的 S-1 文件则进一步证实，Anthropic 将通过此项交易锁定长期稳定的算力供应。

AgentUpdate 深度解析

在这场百亿级美元的算力争夺战背后，折射出 AI 行业底座竞争的残酷现状：大模型及 AI Agent 的终极进化，依然高度依赖于极端物理基础设施的极限堆叠。Anthropic 此次放弃纯粹依赖传统云厂商（如 AWS、Google Cloud），转而向 SpaceX 租用 Colossus 算力，是一次极具战略意义的“混部”尝试。Colossus 作为全球顶尖的超级算力集群，其物理电力供给与高密度计算架构为下一代多模态 Agent 和长上下文复杂推理提供了不可或缺的硬件温床。这也表明，未来的 AI Agent 生态竞争，不仅是算法、工程和工作流架构（如 MCP 协议）的软实力比拼，更是直达电力与物理芯片底座的重资产硬核对决。拥有独立、稳定且具规模效应的算力超级节点的厂商，将在 Agent 智能涌现的下半场占据绝对的话语权。
