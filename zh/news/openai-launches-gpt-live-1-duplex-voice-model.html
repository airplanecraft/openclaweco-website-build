OpenAI发布GPT-Live-1：支持双工通话与后台Agent协同

2026年7月9日 | 3 分钟阅读
#openai#gpt-live#voice-agent#duplex-ai

OpenAI今天发布了两个全新的语音模型：GPT-Live-1和GPT-Live-1 mini，旨在大幅提升ChatGPT的语音交互体验。回顾2024年夏天，#OpenAI推出了高级语音模式（Advanced Voice Mode），虽然当时体验惊艳，但随时间推移其局限性也逐渐显现。旧版本采用的是“轮流发言”（turn-based）机制，模型必须等待用户完全停止说话才能回应。由于它将“沉默”视为发言信号，常因用户的短暂停顿而引发尴尬的插话。

相比之下，全新的 GPT-Live-1 系列模型基于全新的全双工架构（duplex architecture）构建。该架构允许模型在生成输出的同时同步处理输入，从而实现极其自然的双向对话。OpenAI官方解释称，这种设计不仅能让交流更加连贯，还能让模型更好地感知时间流逝，甚至进行实时同声传译。

值得注意的是，新模型具备强大的任务分发与Agent协同能力。如果语音模型判断用户的请求需要深度推理、联网搜索或其他更高级的Agent功能，它会在后台默默将任务委派给 OpenAI 的其他旗舰模型（包括 GPT-5.5）去执行。这些系统会在后台运行，而你与 #GPT-Live 的语音通话完全不会被打断。

在用户体验层面，新模型支持随时被打断，你甚至可以要求它“说慢一点”。在倾听时，它会发出类似“嗯哼”或“知道了”等口头确认，并且在噪音背景下的抗干扰能力也得到了显著提升。此外，ChatGPT Voice 现在的交互更加丰富，能以小卡片（widget-like cards）的形式直观展示天气、体育和股票等视觉信息，并依然支持图片、文件上传及联网搜索。

同时，OpenAI表示已在ChatGPT Voice中内置了全新的安全防护机制，当系统检测到潜在的安全威胁时会进行相应拦截。

AgentUpdate 深度解析

GPT-Live-1 的发布标志着语音交互向“主动协作式”的转变。其核心亮点不仅在于低延迟的双工通话，更在于内置的 Agent 任务分发机制。通过将实时感知与后端深度推理（如 GPT-5.5）解耦，OpenAI 构建了一个高效的语音 Agent 调度中枢。这种多模型协同架构在保障即时性的同时，赋予了系统处理复杂、长程任务的深度智能。这为未来的多模态具身 Agent 提供了一个极具启发性的演进范式。
