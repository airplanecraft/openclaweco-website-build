英伟达净利飙升，谷歌Gemini用户达9亿，思迈特发布首款Agent BI

2026年5月21日 | 3 分钟阅读
#nvidia#gemini#smartbi#doubao#agent bi

【AI与前沿科技焦点】

英伟达发布重磅财报：第一财季净利润大增211%达583亿美元
英伟达（#NVIDIA）发布了其2027财年第一季度（编者注：原文如此）财务报告。财报显示，英伟达在本季度实现营收816.2亿美元，同比增长85%；净利润达到583.2亿美元，同比大幅增长211%，继续展现其在AI算力基础设施领域的绝对统治力。

谷歌Gemini月活达9亿，AI Token处理量年增长7倍
谷歌CEO桑达尔·皮查伊在2026年I/O开发者大会上透露，Gemini AI应用的月活跃用户在过去一年中翻倍，已达9亿人次，日均请求量增长超7倍。目前，谷歌每月处理超过3.2千兆（exatokens）个AI token，较去年同期的4,800万亿增长约7倍。这一强劲增长推动Alphabet股价今年累计上涨25%，进一步巩固了其全球AI研究领头羊的地位。

思迈特软件发布业内首创企业级#Agent BI“白泽”
5月20日，思迈特软件正式发布#SmartBI白泽V5。该产品主打“自主进化、安全可信”，是业内首创的Agent BI（智能体商业智能）产品。它采用“指标体系+多智能体（Multi-Agent）”双轮驱动架构，具备全链路智能数据分析能力，打造了从智能问数到决策交付的完整闭环，在核心场景中的准确率高达99.9%。目前已在金融、制造、央国企等大型企业规模化落地。

用户尝试用“豆包”App预约餐厅，因无法闭环服务引发纠纷
近日，江苏镇江一家鱼庄因用户预约问题产生纠纷。用户称通过“正规渠道”（实为AI应用“豆包”）预约了两人餐，到店后被告知无法接待。对此，豆包客服回应，平台暂不支持通过该应用进行实际餐厅预约，且因隐私保护无法将信息传递给第三方。部分用户因社交焦虑或便利性，误将大模型的模拟对话当成了真实预订凭证，暴露了当前AI Agent在打通现实服务中的局限性。

【大公司与宏观动态】

三星电子劳资双方达成暂定协议，大罢工宣布暂缓
三星电子劳资双方签署了薪资协议暂定方案，原定于21日的大罢工宣布暂缓。暂定方案包括加薪6.2%，并向DX（设备体验）部门员工每人发放价值600万韩元的股票。工会将在5月23日至28日进行内部投票，后续行动将视投票结果而定。

商务部：中国航空将商业化引进200架波音飞机
商务部美大司负责人解读中美经贸磋商成果时表示，中国航空根据自身航空运输发展需要，将按照商业化原则引进200架波音飞机。同时，美方将为中方提供充足的发动机、零部件供应保障。

爱尔眼科自查补缴税款及滞纳金共5.24亿元
爱尔眼科发布公告称，公司根据税收法律法规开展自查，需补缴税款3.48亿元及滞纳金1.76亿元，目前已全部缴纳完毕。自查需增加2025年度企业所得税汇算清缴纳税申报金额2.32亿元。

罗欣药业因销售劣药阿奇霉素被罚186.8万，多名高管被严厉问责
罗欣药业回应其控股子公司生产的注射用阿奇霉素被判定为“劣药”事件，推测系流通储运中极端高温所致。公司已停止生产该产品，报废所有库存。质量负责人已被辞退，山东罗欣总经理被降两级并扣减薪酬。此前，该公司被药监局没收违法所得并处以180万元罚款，合计186.84万元。

【其他热点速递】

俄罗斯将延长对中国公民的免签制度至2027年底
中俄双方决定将免签政策延长至2027年12月31日。持普通护照的俄罗斯人员来华经商、旅游、探亲等，过境不超过30天可免办签证入境；俄罗斯总统新闻秘书佩斯科夫也表示，俄罗斯将同步延长对中国公民的免签制度。

美股三大指数集体收涨，ARM大涨超15%，苹果创历史新高
5月20日美股收盘，道指涨1.31%，纳指涨1.54%，标普500涨1.08%。ARM因AI需求大涨超15%，苹果涨超1%创收盘历史新高，特斯拉涨超3%，英伟达涨超1%。

寿司郎回应“盘子抽检10抽10脏”：已完成整改
杭州一家寿司郎门店因无证销售冷加工糕点、餐具消毒不到位被罚没6万余元。执法人员在1月和2月的抽检中，分别发现刺身铝盘存在大量水渍残渣（10抽10脏）以及待用餐具残留饭粒。寿司郎负责人回应称已按监管要求整改完毕。

华谊兄弟被列为失信被执行人
昔日“中国影视娱乐第一股”华谊兄弟近日因涉及60万案款未执行，被列为失信被执行人。

AgentUpdate 深度解析

本期动态折射出 AI Agent 正在从“极客玩具”加速迈向“企业级生产力”与“消费级日常”的双重深水区。思迈特发布的 Agent BI 采用“指标+Multi-Agent”架构，将准确率逼近 99.9%，直击企业决策对 AI“幻觉”的零容忍痛点，代表了垂直领域 Agent 走向高可靠性的技术路径。与此同时，用户尝试用“豆包”订餐失败的乌龙事件，则揭示了当前消费级 Agent 的“能力悬空”——大模型具备极佳的对话模拟能力，却缺乏连接现实 API 与物理世界闭环的“最后一公里”行动力。未来的 Agent 生态，不仅需要底层像英伟达、谷歌这样的算力与多模态模型支撑，更亟需建立标准化的工具调用（Tool-use）与可信授权机制，才能真正从“会说话的助理”演变为“能办事的实体”。
