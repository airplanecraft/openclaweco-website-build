OpenAI发布Codex白领工作流新功能，加速布局AI Agent生态

2026年6月3日 | 3 分钟阅读
#codex#openai#agentic-workflows#enterprise-ai#mcp

OpenAI 正在全力争取企业级用户。本周二，这家 AI 实验室为 #Codex 发布了一系列全新功能，旨在拓展这一 Agent 化工具（agentic tool）在办公场景中的应用。

伴随这些新工具的发布，#OpenAI 还公布了一份关于 Codex 如何用于知识性工作（knowledge work）的内部报告。报告显示，Codex 的应用范围已经远远超出了软件工程领域。

“Codex 目前的周活跃用户已超过 500 万，自今年 2 月推出桌面端应用以来增长了 6 倍以上，”介绍该报告的官方博客写道。“虽然开发者仍是最大的用户群体，但知识工作者目前已占到用户总数的约 20%，且其增长速度是开发者的三倍以上。”

为了进一步吸引这部分用户，OpenAI 推出了六款针对特定岗位的专用插件，涵盖：数据分析、创意制作、销售、产品设计、股权投资以及投资银行。用户可以直接在 Codex 应用内调用这些工具，每款工具都捆绑了特定的集成功能、指令模板和上下文，使 Codex 能够高度模拟特定岗位的工作流。

与所有 AI 工具一样，这些插件在经过用户个性化定制后会变得更加高效，但官方表示它们在开箱即用时就已经是非常强大的生产力工具。

在此之前，Anthropic 也曾针对 Agent 插件发起过类似攻势，于今年 2 月启动了企业 Agent 计划，并在 5 月推出了更具针对性的金融领域 Agent。相比之下，传统上偏向 C 端消费者的 OpenAI 在争取企业客户方面显得较为迟缓，直到今年 3 月才首次为 Codex 引入插件支持。

除了插件之外，OpenAI 还推出了一项全新的“Sites”（站点）功能。该功能允许 Codex 直接将工作成果输出为一个托管的交互式网站，而不仅仅是本地文件。作为该系统的一部分，OpenAI 正在与 Wix、Base44、Replit、Lovable、Figma 和 Emergent 展开合作，并计划未来构建一个更庞大的合作伙伴生态来支持这一服务。

此外，全新的“Annotations”（批注）功能允许用户在 Codex 内部指定文档或文件的特定部分，从而进行更精准的指令下达和上下文操作。

这些全新的企业级功能发布前仅三周，OpenAI 刚成立了一家专门服务企业客户的新合资公司，命名为“OpenAI 部署公司”（OpenAI Deployment Company）。该合资公司获得了来自全球投资机构超过 40 亿美元的资金支持，旨在将 OpenAI 的工具更深地融入全球企业的实际业务中。

“AI 正在变得能够组织内部承担起越来越有意义的工作，”OpenAI 首席营收官 Denise Dresser 在合资公司成立时表示。“现在的挑战是帮助企业将这些系统整合到驱动其业务运转的基础设施和工作流当中。”

AgentUpdate 深度解析

OpenAI 此次更新标志着大模型从“单一对话框”向“深度协作工作空间”的范式转变。通过将 Codex 演进为支持多模态批注、一键网页化输出并深度整合垂直行业插件的 Agent 平台，OpenAI 正在重新定义人机协同界面。相较于 Anthropic 偏向于后台自主运行的 Agent，OpenAI 更强调端侧交互（Sites, Annotations）与伙伴生态（Replit, Figma 等）的闭环，这与 #MCP（Model Context Protocol）生态倡导的上下文互通有异曲同工之妙。40亿美元的 Deployment Company 更提供了强大的地面部队支持。长期来看，这种“工具集成+端侧交互+商业地面战”的打法将极大加速 Agent 在企业高价值场景的渗透，使 AI 真正成为不可或缺的协同生产力。
