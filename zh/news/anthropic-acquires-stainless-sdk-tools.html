Anthropic超3亿美元收购SDK神器Stainless，背刺OpenAI

2026年5月19日|3 分钟阅读
#sdk#api#anthropic#mcp

美国人工智能独角兽 #Anthropic 于周一宣布，已收购由前 Stripe 工程师 Alex Rattray 创立的开发者工具初创公司 Stainless。该公司此前在 AI 行业内极具影响力，其客户包括 OpenAI、谷歌和 Cloudflare 等 Anthropic 的强劲竞争对手。

虽然 Anthropic 未披露具体交易条款，但据《The Information》上周报道，该公司曾与 Stainless 洽谈收购事宜，估值超过 3 亿美元。Stainless 的背后投资方包括红杉资本（Sequoia Capital）和安德里森·霍罗维茨（Andreessen Horowitz）。

此次收购直接将一个关键的基础设施供应商从 Anthropic 竞争对手的手中剥离。Anthropic 告诉 TechCrunch，它将逐步关停 Stainless 的所有托管产品，包括其核心的 #SDK 生成器。不过，Anthropic 的发言人表示，Stainless 的现有客户仍将拥有迄今为止生成的 SDK，并享有根据自身需求进行修改和扩展的完整权利。

Stainless 成立于 2022 年，总部位于纽约。由于能够自动创建和维护软件开发工具包（SDK，即开发人员用来与 #API 进行交互的库），它在蓬勃发展的 AI 行业中迅速声名鹊起。创始人 Rattray 开发的软件能够读取 API 规范，并自动将其转化为支持 Python、TypeScript、Kotlin、Go 和 Java 等多种主流编程语言的生产级 SDK。由于它能随着 API 的更新自动同步更新 SDK，从而彻底消除了繁琐的手动维护过程，因而大受欢迎。

对于 Anthropic、OpenAI、谷歌、Replicate、Runway 和 Cloudflare 等致力于构建能连接外部软件并代表用户执行任务的 AI Agent（人工智能体）的公司来说，这项技术极其关键。Stainless 的 SDK 工具提供了构建和维护这些连接的最简便路径。然而，未来该工具将仅供 Anthropic 专属，竞争对手将无法再使用。

据 Anthropic 介绍，自其 API 推出早期以来，Stainless 的软件就一直在为其官方 SDK 的生成提供技术支持。

Rattray 在一份声明中表示：“我创立 Stainless 是因为我认为 SDK 应该像它们所封装的 API 一样受到精心对待。Anthropic 是最早与我们并肩作战的团队之一。过去几年里，我们亲眼见证了开发者在 Claude 之上构建的成果，这使得我们决定走到一起。现在，我们的团队能够继续在我们最重视的平台上，做我们热爱的工作。”

AgentUpdate 深度解析

Anthropic 此次对 Stainless 的并购是一次极其精准的生态“卡脖子”行动。在 AI Agent（人工智能体）向实用化、多工具调用（Tool Use）演进的今天，API 和 SDK 是 Agent 触达真实物理与数字世界的唯一桥梁。Stainless 解决的不仅是开发效率问题，更是 Agent 动态适应外部接口变化、保持高可靠性的底层基石。通过将这一关键基础设施据为己有并对竞争对手“断供”，Anthropic 不仅强化了自身 Claude 生态（如其力推的 MCP 协议）的工具调用和开发者体验，也极大地增加了 OpenAI 和谷歌在构建统一、高可用 Agent 开发者生态时的边际成本。这也预示着，AI 竞争的战场已从单纯的大模型参数竞赛，全面延展到开发者工具链和底层基础设施的生态霸权争夺战。
