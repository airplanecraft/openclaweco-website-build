Claude Code 源码泄露：Anthropic AI Agent未来蓝图浮出水面

2026年4月2日 | 3 分钟阅读
#claude#anthropic#ai agent#kairos#autodream#memory system

Anthropic的#Claude Code源代码近日意外泄露，为我们揭示了该公司围绕其专有Claude模型所构建的“氛围编程”框架的诸多细节。除了已有的功能，观察者在超过2000个文件中挖掘了逾512,000行代码，并从中发现了许多被禁用、隐藏或非激活特性的引用，这些信息为#Anthropic未来可能推出的功能路线图提供了一瞥。

在这些特性中，最引人注目的是名为“Kairos”的持久化守护进程。即使Claude Code终端窗口关闭，Kairos也能在后台持续运行。该系统将利用周期性的“<tick>”提示来定期审查是否需要采取新的行动，并设有一个“PROACTIVE”标志，用于“主动呈现用户尚未提出但现在需要看到的信息”。

Kairos利用一套基于文件的“内存系统”，旨在实现跨用户会话的持久化操作。代码中一个隐藏在被禁用“KAIROS”标志后的提示解释说，该系统的设计目标是“全面了解用户是谁，他们希望如何与你协作，需要避免或重复哪些行为，以及用户提供的工作背后的上下文信息。”

为了在不同会话中组织和整合这个内存系统，Claude Code的源代码中还提到了一个名为“#AutoDream”的系统。当用户进入空闲状态或手动指示Anthropic进入休眠模式时，AutoDream系统会告诉Claude Code：“你正在进行一次‘梦想’——对你的内存文件进行一次反思性整理。”

这个描述AI“梦想”过程的提示要求Claude Code扫描当日的对话记录，以寻找“值得持久保存的新信息”，并以避免“近似重复”和“矛盾”的方式整合这些新信息。同时，它还会修剪过于冗长或已过时的现有记忆。Claude Code还将被指示留意“已发生漂移的现有记忆”，我们此前在Claude用户尝试将记忆系统嫁接到其Agent框架时也遇到过类似问题。根据提示，其总体目标是“将你最近学到的知识综合成持久、组织良好的记忆，以便未来的会话能够快速定向。”
