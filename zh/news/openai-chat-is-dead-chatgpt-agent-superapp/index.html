OpenAI宣告“对话已死”：ChatGPT将重构为超级智能Agent

2026年6月7日 | 3 分钟阅读
#openai#chatgpt#ai-agent#superapp

“对话已经死了，”一位OpenAI的高级员工向《金融时报》透露。该公司正将重心从仅能回答问题的聊天机器人，转向能够自主处理复杂任务的AI Agent（人工智能代理）。这一战略转向正推动着ChatGPT自2022年发布以来最大规模的一次彻底重构，旨在将其打造为一个集成了编程工具、智能体以及诸如Canva和Booking等合作伙伴生态的“超级应用”（#Superapp）。

OpenAI首席产品官Thibault Sottiaux告诉《金融时报》：“它将超越现有的交互界面……我们正在努力构建的，是一个能够在你个人生活和工作的方方面面提供协助的个人专属智能体。”该报道汇总了十多位现任及前任员工的消息。事实上，#OpenAI此前已证实其正在研发一款“超级应用”。

在接下来的几周内，OpenAI将重新设计ChatGPT的网页和移动端界面，引入新功能来引导用户使用代码编写、图像生成以及第三方合作伙伴应用。随着时间的推移，当底层模型能够自主理解并预测用户需求时，这些引导性提示将逐渐淡出。目前，#ChatGPT、Codex以及其他产品团队已经在Sottiaux的领导下完成了团队合并。

AgentUpdate 深度解析

从“Chat”到“Agent”的转变，标志着AI正式从“对话生成”迈向“自主执行”。OpenAI重构ChatGPT为超级应用，是在抢夺下一代AI原生入口。相比于LangChain或CrewAI等开发者框架，OpenAI直接在消费端发力，利用庞大用户群将第三方服务“Agent化”。这将重塑流量分发逻辑，对传统App生态产生颠覆性打击。未来，Agent生态的壁垒将是端到端的自主规划能力，这也将倒逼整个软件产业彻底走向“Agent-First”时代。
