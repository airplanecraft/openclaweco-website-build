DeepSeek首轮融资510亿元，创始人梁文锋出资200亿领投

2026年6月16日 | 3 分钟阅读
#deepseek#venture-capital#agi#llm#funding

据投资机构透露，中国大模型独角兽企业 DeepSeek 已完成首轮融资，整体融资规模高达约 510亿元人民币（折合约71亿美元）。在当前的AI融资浪潮中，这一数额创下了全新纪录。更为罕见的是，#DeepSeek 创始人 梁文锋 个人出资约 200亿元，成为本轮融资中的最大单一出资方，展现了创始团队对公司 #AGI 长期愿景的极强控制力与信心。

本轮融资的投资方阵容极为豪华，堪称中国科技、产业与国资力量的一次大汇聚。参与方包括国家级投资平台 国智投，互联网巨头 腾讯、网易、京东，新能源巨头 宁德时代 体系，以及知名风投机构 正心谷投资、拾象科技、Monolith砺思资本 等。此外，老牌头部创投 IDG资本 本轮出资约 30亿元。本轮充沛的资金将主要用于算力基础设施的持续扩容以及下一代前沿模型的研发。

AgentUpdate 深度解析

DeepSeek 此次斩获 510 亿元的巨额融资，不仅刷新了国内乃至全球大模型领域的单笔融资纪录，也为 AI Agent 生态的演进注入了极强的发展动能。创始人梁文锋以 200 亿个人资金重仓，这在科技史上极其罕见，确保了团队对 AGI 愿景的绝对控制权，避免了硅谷式“被资本裹挟”的治理困境。从技术与生态角度看，DeepSeek 凭借极高的推理性价比与开源策略，已成为全球开发者构建智能体（AI Agent）的核心底座之一。相比 OpenAI 的闭源帝国，DeepSeek 的充沛资金将加速其推理模型（如 DeepSeek-R1 系列）的迭代，直接降低下游 Agent 应用开发者的算力门槛。腾讯、网易、京东等场景巨头以及宁德时代等工业巨头的集体入局，预示着 AI Agent 将加速从“工具属性”向“原生工业与消费级生态”渗透，构建起一条横跨云端算力、具身智能与垂直行业应用的超级 Agent 闭环。
