中信证券：AI投资回报闭环已现，北美云巨头大增资本开支

2026年8月4日 | 3 分钟阅读
#capex#optical-communication#aws#ai-infrastructure#agentic-workflows

2026年Q2，北美四大云厂商的资本开支（#Capex）维持高速增长。谷歌、亚马逊等巨头进一步上修了全年指引，其中亚马逊AWS在营收、营业利润率以及未结订单（Backlog）上均超出市场预期。亚马逊CEO Andy表示，服务器与网络设备的投资盈亏平衡点“不到三年”，这正面回应了业界对于AI巨大投入回报率（ROI）的质疑。

中信证券认为，AI投入-回报的良性循环已经初步形成，大幅减缓了市场对于AI Capex巨额投入可持续性的担忧。在云厂商业绩不断印证AI对业务增长驱动的背景下，AI集群规模将进一步扩张。光互联作为集群网络的重要环节，将在GPU配比提升、端口速率升级和“光进铜退”三重因素下持续高速增长，光通信板块中长期景气度依然向上。

与此同时，国内二级市场也在积极布局。私募排排网最新数据显示，股票私募已连续4周加仓，整体仓位创近220周新高。百亿级私募更是通过密集自购释放看多信号，自7月以来自购金额已超过14亿元。业内人士指出，随着市场调整释放风险，权益资产配置价值进一步显现，私募机构整体保持较高仓位运行，但短期仍将以结构性行情为主。

AgentUpdate 深度解析

：北美云巨头资本开支的高速增长以及“三年内回本”的强劲ROI，为全球 AI 产业吃下了一颗定心丸。从技术演进路径来看，底层算力红利的持续释放与光通信技术的升级，正在直接赋能上层 AI Agent 生态的爆发。多模态、长上下文以及高频交互的 AI Agent 集群（Agentic Workflows），其运行高度依赖极低延迟与极高吞吐的算力网络。光通信的“光进铜退”与万卡、十万卡集群的扩容，解决了多 Agent 协同（Multi-Agent Collaboration）中因网络延迟带来的性能瓶颈。相较于早期的单点式大模型，未来的分布式 Agent 生态将表现出更强的工程落地能力，而底层算力成本的逐步摊薄，则是 Agent 迈向大规模商业化普及（Ubiquitous Agents）的决定性基石。
