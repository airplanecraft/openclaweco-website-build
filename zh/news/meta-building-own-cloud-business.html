传Meta计划推出自研云业务，变现巨额AI算力基础设施

2026年7月2日 | 3 分钟阅读
#meta#meta-compute#cloud-computing#ai-agent#llama

据彭博社报道，Meta 可能会推出自己的云计算业务，以变现其为了训练和运行人工智能模型所做出的巨额基础设施投资。这家社交媒体巨头传统上依靠其庞大的在线广告业务来支撑智能眼镜和虚拟现实等高风险押注。而销售云基础设施将使 #Meta 直接与 Amazon Web Services (AWS)、Google Cloud 以及新晋云服务商 SpaceX 展开正面竞争。

报道指出，该云业务可能会提供多种服务，例如通过 Meta 的基础设施提供 AI 模型 的访问权限，或者将数据中心算力租赁给其他有 AI 训练需求的公司。提供类似于亚马逊 AWS 的服务，有助于回收 Meta 在 AI 领域投入的部分资金。作为其 AI 战略的一部分，Meta 已承诺到 2028年 在美国投资 6000亿美元。此外，Meta 还斥巨资挖角，组建了其 AI 超级智能（Superintelligence）团队。

据悉，Meta 于今年 1 月成立的、专注于数据中心和 AI 的新举措 —— Meta Compute 部门目前正在开发这项全新的云业务。媒体已就此数据中心计划联系 Meta，目前尚未获得官方回复。

至少到目前为止，Meta 为使用 Facebook、WhatsApp、Instagram 或独立 Meta AI 应用的用户免费提供其 Muse Spark AI 模型（注：原文如此，可能指特定变体）。付费订阅仅能解锁更高的图像生成限制和更高级的推理能力。该公司的全新 AI 模型将逐步集成到包括近期发布的 Meta Glasses 智能眼镜在内的可穿戴设备中。与谷歌类似，Meta 也在积极研发能够代表用户处理个人和工作任务的 AI Agent（智能体）。

AgentUpdate 深度解析

Meta 进军云计算市场，是其 AI 战略从“纯投入”走向“商业闭环”的必然选择。对于 AI Agent 生态而言，此举影响深远：首先，Meta 拥有开源生态的绝对王牌 Llama 系列模型，一旦其打通“模型 + 自建算力云”的链路，将极大降低开发者部署高吞吐量 Agent 的成本，直接冲击 AWS 和 Azure 的垄断地位。其次，AI Agent 的核心痛点在于端侧与云侧算力的协同效率，Meta 拥有数十亿社交用户端及 Meta Glasses 等硬件端，其自建云能提供更低延迟的边缘计算与 Agent 托管服务。这种“端-模型-云”三位一体的闭环，将加速 Agent 走向低成本、高并发的大规模商业化落地。
