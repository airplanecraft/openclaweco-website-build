Claude Code创始人：AI时代技术团队将重构为5大新型角色

2026年6月29日 | 3 分钟阅读
#claude-code#anthropic#ai-agents#software-engineering

在 AI 时代，传统的职业头衔正在经历前所未有的剧烈变革。你可能自称为“构建者”（Builder），或者在名片上印着“前沿部署”（Forward-deployed）。Claude Code 的创造者 Boris Cherny 近期在社交媒体 X 上分享了他对于这种职业变革的深度思考。他认为，传统的软件工程、产品管理和设计等领域正在加速融合，而他自己的团队正是观察“未来技术角色”的一个极佳窗口。

Cherny 指出，AI 辅助开发工具的爆发使得传统职责的边界变得模糊。他将自己团队中的员工归纳为 5种全新的核心角色原型（Archetypes）：

1. “原型师”（Prototyper）：专注于快速生成全新概念，尽管其中许多尝试最终并不会直接发布上线；
2. “构建者”（Builder）：负责将不成熟的原型转化为高可用性、生产级（Production-grade）的成熟产品；
3. “清道夫”（Sweeper）：致力于代码清理、系统简化以及性能优化工作；
4. “拓展者”（Grower）：通过不断迭代和扩展现有功能，以实现更好的市场契合度；
5. “维护者”（Maintainer）：在产品规模化扩张的过程中，保障现有系统的高安全、高可靠、高并发和高效率。

Cherny 特别强调，Claude Code 团队中的许多成员实际上同时横跨了多种角色原型。一个健康且高效的开发团队必须同时具备这五种角色的混合体，而不同角色的具体比例则取决于产品自身的成熟度与生命周期阶段。未来的产品和研发岗位将不再受限于传统的条线框架，而是更加契合这种基于行动和价值输出的全新组织范式。

AgentUpdate 深度解析

随着 Claude Code 和 Cursor 等 AI 编程智能体（AI Coding Agents）的普及，传统的软件工程链路已被深度重构。过去，一名工程师需要兼顾架构设计、编写样板代码、调试以及部署。而在 Agent 协同时代，生成代码（Builder）的门槛已被大幅降低。这也解释了为什么 Cherny 强调“原型师”和“清道夫”的重要性：未来的差异化竞争不在于写代码的快慢，而在于业务原型的构想能力（Prototyper），以及对 AI 生成庞杂代码进行提炼、精简和重构的控制力（Sweeper）。这种从“传统岗位”向“角色原型”的转型，揭示了 AI Agent 生态不仅是在替代工具，更是重塑团队的组织架构。未来的技术人才必须从单一技能持有者转变为能够驾驭多个 Agent 矩阵的“超级个体”。
