Claude Code之父：AI产品进入“删除”时代，模型保质期仅半年

2026年7月30日 | 3 分钟阅读
#claude#agentic#anthropic#llm#unhobbling

每六个月，删掉你的Claude.md，删掉所有的skills和hooks。这是Claude Code之父Boris Cherny在YC访谈中给出的惊人建议。他呼吁开发者对AI产品勇敢按下“删除键”，通过大刀阔斧的消融实验，精简系统的提示词与底层封装代码。

在Anthropic的Opus 5测试中，他们将原有的system prompt大幅削减了80%，因为模型能力的飞速迭代使得传统的预设指令已成为负累。Boris认为，模型是某种“有机生物”，每一代的性格与行为逻辑均有差异，开发者应停止猜测，转而通过实测定位模型“卡壳”的点。

Boris提出了Product Overhang（产品悬余）与Unhobbling（解缚）两大核心理念。前者指模型能力的跳跃式进化常超出现有产品边界，后者则强调应通过设计，激发模型本已具备但未被调用的深层能力。通过赋予模型更高难度的任务并要求其自我验证，AI Agent将不再局限于补全代码，而是具备长周期独立工作的能力。他分享了自己让模型重构Electron应用并持续运行两周的案例，展示了“解缚”后的惊人产出。

AgentUpdate 深度解析

本文揭示了AI开发范式的根本性转变：从“提示词工程”转向“以模型为中心的演化工程”。横向对比来看，相比于传统的LangChain或CrewAI等框架往往通过大量复杂的硬编码逻辑来控制工作流，Boris提出的“少即是多”理念更加激进。这种思路的本质在于承认#LLM已不再是单纯的函数调用对象，而是具备内生逻辑的智能体。对于AI Agent生态而言，这意味着未来的开发重心将从“如何写出完美的Prompt”转移到“如何构建有效的自我修正与验证闭环”。当模型推理能力达到临界点，过度的封装反而是对智能的阻碍。开发者应将注意力放在构建稳定的基础设施（如更强的沙箱环境、即时反馈机制）上，而不是尝试用固定的代码去捕捉动态的智力，这种“解缚”思维将是未来顶尖Agent产品与普通产品的分水岭。
