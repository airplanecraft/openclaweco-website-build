因美政府出口管制，Anthropic将停用其最新大模型

2026年6月13日 | 3 分钟阅读
#anthropic#export-control#fable-5#mythos-5#ai-regulation

人工智能初创公司 Anthropic 宣布，计划停用其最新且最顶尖的 AI 模型 Fable 5 和 Mythos 5。这一决定是在美国政府发布一项出口管制令后做出的，该管制令旨在禁止外国个人和实体使用这些尖端产品。

根据 #Anthropic 上周五晚间发布的官方博客文章，公司在东部时间下午 5:21 收到政府信函，信中出于“国家安全担忧”对上述模型提出了限制要求。该命令的约束范围极广，涵盖美国境内外的任何外籍人士，甚至包括“外籍 Anthropic 员工”。其产生的实际效果是，公司必须面向全球所有人停用这些模型，以确保完全符合合规要求。

尽管政府信函中并未提供具体安全隐患的细节，但 Anthropic 认为，官方的担忧可能在于 Fable 5 存在某种被“越狱”（jailbreak）的潜在技术漏洞。然而，Anthropic 驳斥了这一风险的严重性，声称该技术手段非常局限，并非普适性漏洞，且涉及的漏洞早已为人所知，其他公开可用的模型同样可以识别此类缺陷。

此次事件是 Anthropic 与 特朗普政府 之间在 AI 安全、国家安全以及政府对前沿模型控制权方面冲突的最新升级。今年 2 月，在 Anthropic 试图对其 AI 模型在某些国防领域的应用做出限制后，美国国防部曾将这家初创公司列为“供应链风险”企业。

作为回应，Anthropic 已经起诉了 美国国防部，目前两起涉及该“供应链风险”标签的诉讼仍处于待审状态。尽管 Anthropic 明确表示不同意政府的裁决，但仍选择遵守出口管制令。公司发言人尚未透露停用这些模型的具体执行时间，但确认其他模型的访问将不受影响。

AgentUpdate 深度解析

此次 Anthropic 被迫在全球停用其最先进的 Fable 5 和 Mythos 5 模型，揭示了地缘政治和出口管制对 AI Agent 生态系统的深远影响。AI Agent（智能体）的协作网络高度依赖前沿大模型的 API 调用。当尖端模型因“国家安全”而突然下线或限制外籍开发者使用时，跨国团队和多智能体系统的全球协同将被切断。相比于闭源厂商受制于强监管，这一制约将极大刺激全球开发者倒向去中心化、端侧以及开源模型（如 Llama 3 和其他地方性替代方案），加速 AI 智能体生态的阵营分化。技术合规与自主可控已成为 Agent 架构设计的核心命题。
