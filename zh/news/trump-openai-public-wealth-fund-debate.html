特朗普欲推动“全民持股OpenAI”，AI主权财富基金引发监管利益冲突争议

2026年6月6日 | 3 分钟阅读
#openai#sovereign wealth fund#ai policy#anthropic#mcp

美国总统特朗普周四表示，他计划于下周在白宫会见人工智能企业，讨论建立一项联邦政府“合作伙伴关系”，使美国公众能够从AI行业的成功中获益。特朗普指出：“我们正在构想一种模式，将部分股份分给美国公众，让他们本质上成为这些企业的合伙人。”该计划甚至可能包括向国民发放公司股息。

这一想法并非首次出现。OpenAI首席执行官奥特曼（Sam Altman）在2025年初就向特朗普政府提出了让政府持有大型AI企业股份的设想，并在最近几周再次提及。然而，总统的公开表态，加之参议员桑德斯（Bernie Sanders）提出的一项更为激进的平行提案，瞬间将“谁该拥有AI经济收益权”这一问题推向了华盛顿政策辩论的核心。

两套提案在执行力度上截然不同。奥特曼的方案完全是自愿性的。#OpenAI在四月份的政策文件中提出了一个“公共财富基金”（Public Wealth Fund）概念，旨在让每个公民都能分享AI驱动的经济增长成果。在这种框架下，OpenAI将主动向政府捐赠股权以注入种子基金，将公司定位为积极的参与者而非被监管的靶子。

相比之下，桑德斯的方案则是强制性的。他宣布了《AI主权财富基金法案》（AI #Sovereign Wealth Fund Act），拟对最大型的AI企业征收一次性50%的股票税，以股权形式支付而非现金。政府将管理该基金，通过投票权获得董事会席位，并有权否决其认为有害的决策。该法案直指OpenAI、Anthropic和xAI等行业巨头。虽然该立法通过的概率极低，但它彻底拉宽了华盛顿政策讨论的边界。

这一安排面临的最犀利批评来自倡导组织 Public Knowledge 的 Nat Purser。他警告称，任何让政府持有企业股权的机制，都可能导致政府在实施或执行安全监管时产生顾虑，因为监管政策一旦收紧，可能会直接削弱其持股的账面价值。这种担忧绝非凭空捏造。就在特朗普发表利润分成言论的三天前，他签署了一项行政命令，要求AI公司“自愿”在公众发布前最多30天将前沿模型（frontier models）提交给政府进行测试。在这种情境下，“自愿”一词的实际效力令人存疑。如果政府本身就是其应当监管的公司的利益关联方，监管的公正性将面临极大考验。

AgentUpdate 深度解析

国家级主权财富基金入股头部AI企业，不仅是经济利益的博弈，更将深刻重塑未来的 AI Agent 生态底座。当 OpenAI、#Anthropic 等前沿模型提供商与国家资本深度绑定，大模型将正式被视为国家关键基础设施。这在短期内虽然能为 AI Agent 的规模化落地提供极强的政策绿灯与资金保障，但长远来看，却可能筑起极高的行业壁垒，加剧算力与模型的垄断。对于中下游的 Agent 开发者和开源生态（如 LangChain、MCP 协议等）而言，这种“国字头”的收编可能导致 API 定价、数据隐私以及合规门槛的剧烈波动。未来的 AI 代理网络将不仅受技术演进支配，更受制于国家安全与主权资本的底层意志。
