顶级风投不选边站？数据揭秘 OpenAI 与 Anthropic 背后的同一批金主

2026年6月5日 | 3 分钟阅读
#openai#anthropic#venture-capital#ai-agent

OpenAI 与 Anthropic 在人才、客户和公众关注度上竞争惨烈。这两家对手级别的 AI 实验室在政策提案上针锋相对，其 CEO 在今年早些时候的一次商业峰会上，更是十多位行业领袖中唯一没有携手合影的两位。然而，他们在一个巨大的领域存在重合：那就是他们的投资人。

根据外媒对数据追踪平台 PitchBook 数据的分析，过去几年中，约有 90家风险投资机构和其他资金管理公司同时投资了 #OpenAI 和 #Anthropic。数据显示，OpenAI 约有 42% 的投资者与 Anthropic 重合。而 Anthropic 的投资者中约有三分之一也是 OpenAI 的支持者，其中包括 红杉资本（Sequoia Capital）、Greylock、Founders Fund、红点创投（Redpoint Ventures）、Emerson Collective 和 Sound Ventures 等大牌机构。

就在上周，Anthropic 宣布了一项融资公告，列出了 31家投资方，而根据 PitchBook 的数据及媒体报道，其中至少有 13家 持有 OpenAI 的股份。由于收集私募股权投资信息的难度极大，实际的共同投资人数量可能被低估了。例如，在 PitchBook 的 OpenAI 投资者名单中就漏掉了包括 亚马逊（Amazon） 在内的至少几家关键投资方。

对于两家成立时间相差仅两年、且融资竞争极度白热化的对手来说，这种投资人重合度令人震惊。三位研究风投行业的专家表示，这种现象非常罕见，甚至可以说前所未有。它反映了风投行业近期的演变、两家超级独角兽融资金额的空前巨大，以及 AI 领域群雄逐鹿的开放式竞争格局。哈佛商学院教授、风投历史学者 Tom Nicholas 指出，这种所有权结构表明，老练的投资人并不认为这是一个“赢家通吃”的市场。

此外，随着 Anthropic 和 OpenAI 计划在今年启动上市（IPO），投资者的交集也愈发引人关注。风投研究机构 PitchBook 的研究总监 Kyle Stanford 指出，大型投资机构此举并非看重技术的重叠，而是在保护自己创造回报的能力，通过双向押注来翻倍成功的概率。

AgentUpdate 深度解析

从 AI Agent 生态的演进来看，OpenAI 与 Anthropic 的“双重股权”结构具有深远的战略指示意义。目前，AI Agent 的底层大脑高度依赖最先进的基座大模型（如 Claude 3.5 Sonnet 与 GPT-4o）。Anthropic 凭借 MCP（模型上下文协议） 和 Computer Use 深度布局主动型 Agent 生态，而 OpenAI 则通过 Operator 和 Swarm 框架发力行动端。风投机构对两者的双重下注，本质上是对 Agent 时代底层基础设施的“双保险”投资。这种非排他性的资本结构，避免了单一巨头垄断可能带来的生态闭塞，反而促进了多模态基座技术在 Agent 端的良性竞争，为开发者提供了更具弹性和开放性的双轨选择，长期来看将加速智能体应用的全面爆发。
