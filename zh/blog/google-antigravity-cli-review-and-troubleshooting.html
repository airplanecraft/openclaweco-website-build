🚨 突发：Gemini CLI 强制退役，谷歌掏出了新武器

就在刚结束的 Google I/O 2026 大会上，谷歌扔出了一个让很多开发者半夜惊醒的重磅炸弹：2026年6月18日起，老牌的 Gemini CLI 将彻底停止服务。取而代之的，是一个叫做 Antigravity CLI 的全新命令行工具。

大白话来说，如果你以前习惯在终端黑框框里敲命令让 Gemini 帮你写代码，那么下个月开始，那套老工具就彻底瘫痪了。你必须强制搬家到这个名叫 Antigravity（意为“反重力”）的新平台。

作为在代码堆里摸爬滚打了 10 年的老兵，我第一时间去体验了这把“新武器”。这玩意儿到底是个换皮的玩具，还是真能帮我们提效的神器？它跟目前市面上的老大哥 Claude Code 相比咋样？今天咱们就用最接地气的大白话，把它的安装、核心能力、以及那些让人抓狂的“坑点”一次性给你盘明白。

🤔 什么是 Antigravity CLI？它解决了什么痛点？

为了照顾刚入门的兄弟，咱们先解释下概念。CLI 就是 命令行界面 (Command Line Interface)，也就是程序员平时敲敲打打的那个黑底白字的终端窗口。而 Antigravity CLI 是一款 终端优先 (Terminal-First) 的 AI 编程智能体 (Agent) 工具。

以前我们用 AI 写代码，是典型的“问答模式”：你在网页端问，AI 给你一段代码，你再手动复制粘贴到你的项目里。这就导致摩擦力极大，而且 AI 根本不知道你本地项目长啥样。

Antigravity CLI 解决的核心痛点就是：让 AI 像一个真实的同事一样，直接“住进”你的项目文件夹里。你只需要一句话授权，它就能自己去读文件、改代码、运行测试命令、看报错日志，甚至自己去修复 bug。这就叫 智能体工作流 (Agentic Workflow)。

这次升级到底牛在哪？

  1. 底盘换了，速度碾压：以前的 Gemini CLI 是用 Node.js 写的，跑起来有点笨重。这次 Antigravity CLI 直接用 Go 语言 (Golang) 彻底重写。Go 语言天生支持高并发，编译出来就是一个极小的二进制文件。实测启动速度不到 1 秒，代码分析响应在 50-200 毫秒之间，比老版快了 5 到 10 倍！
  2. 多智能体并发 (Multi-Agent Orchestration)：这是最大的亮点。老工具只能单线程干活。现在，你可以同时拉起好几个子智能体 (Subagents) 帮你干活。比如一个去查文档，一个去写 UI，一个在后台跑测试，互相不耽误。
  3. 终于能用 Claude 模型了：以前谷歌很封闭，只让用自家的 Gemini。现在 Antigravity CLI 把后端打通了，除了默认快且便宜的 Gemini 3.5 Flash，你居然可以在里面直接调用 Anthropic 家的 Claude Opus 4.6 和 Claude 3.5 Sonnet！这对很多实战派程序员来说，绝对是个巨大的好消息。

🛠️ 安装、迁移与极速上手

别怕麻烦，安装和迁移其实就几行命令的事儿。下面是手把手的保姆级教程。

1. 安装 Antigravity CLI

只要你是 macOS 或者 Linux 系统，直接打开终端，复制下面这行代码跑一下就行：

bash

使用 curl 工具从谷歌官网静默下载 (-fsSL) 安装脚本，并直接交给 bash 执行。

这里的管道符 '|' 的作用是把前面下载的内容直接作为后面 bash 命令的输入。

curl -fsSL https://antigravity.google/cli/install.sh | bash

(注：Windows 用户如果在 PowerShell 下，可以使用 irm https://antigravity.google/cli/install.ps1 | iex，但据部分群友反馈 Windows 下环境报错较多，建议先在 WSL 环境下折腾。)

2. 从老版本无缝迁移

装好之后，怎么把以前在 Gemini CLI 里攒下的自定义快捷指令 (Alias) 和配置搬过来呢？

bash

启动终端命令行，输入 agy 就是启动 Antigravity CLI

agy migrate from-gemini --import-history --import-aliases

参数解释：

migrate from-gemini: 告诉工具我要从老版本搬家

--import-history: 把我以前的聊天历史记录导过来

--import-aliases: 把我以前自定义的快捷命令统统搬运过来

3. 启动你的第一个多智能体工作流

配置完之后，咱们就可以让它干活了。比如你想让它帮你重构一个项目：

bash

创建一个名为 frontend-expert 的前端专家智能体

agy agent create --name "frontend-expert" --role "React specialist"

创建一个后端专家智能体

agy agent create --name "backend-expert" --role "Go microservices"

并行跑任务：让它俩一起去构建一个 todo app

agy workflow run "build a full-stack todo app" --agents frontend-expert,backend-expert

💣 避坑指南：这些反人类的设计差点把我逼疯

说实话，Antigravity CLI 在模型能力和多智能体并行上确实惊艳（我用它跑一个高难度的医疗影像 3D 渲染测试，它配合 Gemini 3.5 Flash 居然 4 分 25 秒零报错通关，破了历史纪录）。

但是！谷歌这帮工程师在基础的交互体验上，简直留下了几个逆天的“巨坑”。我在这里给大家提前排雷。

坑位一：终端代理失效，连不上网（最坑的一集）

症状：你在终端里明明敲了 export https_proxy=... 挂了代理，但一让 agy 读代码，它就直接甩脸报错：Agent execution terminated due to error（智能体执行因错误终止）。鉴权完全过不去，模型列表也拉不出来。

底层真凶：Antigravity CLI 底层大量使用了 gRPC 通信协议（一种高性能的远程数据传输协议）。Go 语言编译的后台守护进程，会直接无视你当前 Shell 里的临时环境变量，它会选择“裸连”直撞防火墙。

🎯 破局大招：抛弃在终端里手动配 export 的幻想。直接打开你的代理客户端（如 Clash、Surge 等），开启 TUN 模式（增强模式/虚拟网卡模式）。这会在你电脑底层接管所有网络流量，不管 agy 怎么悄悄发请求，都会被强行塞进代理隧道。开启后，鉴权秒过，极其丝滑。

坑位二：反人类的登录交互

症状：第一次输入 agy 回车后，它不会像其他现代工具那样自动拉起浏览器，而是要在终端里显示一串授权链接让你复制。

底层真凶：UI 焦点设计缺陷。授权链接和粘贴验证码的输入框，居然不在你当前屏幕的可视范围内！

🎯 破局大招：当你发现屏幕卡死在 Signing in... 或者回车没反应时，请务必疯狂按下 Shift + 下方向键 (Down)。你会发现原来提示内容和输入框藏在下面！在 iTerm2 等终端里，记得提前开启“允许终端访问剪贴板”的权限。

坑位三：肌肉记忆的挑战 (Ctrl+C 失效)

症状：平时我们在终端里跑程序，遇到卡死或者想强行退出，脑子不用动就会按 Ctrl + C。但在 Antigravity 里，按烂了都没用。

🎯 破局大招：必须按下 Ctrl + D 才能强行杀死当前任务或退出终端。这点非常反直觉，需要大家重新适应一下肌肉记忆。

🎨 其他差异化亮点：不仅会写代码，还能原生画图

除了上面提到的多智能体，Antigravity 还有一个独门绝技：原生图像生成。

由于它内置了谷歌自家的 Nano Banana Pro 2 代模型，你可以直接在终端里让它出图。比如你说：“根据我现在的代码逻辑，给我画一张系统架构图”，它能直接调用底层工具画出来，而不是凭空乱编。这对于独立开发者做演示、写 Readme 文档来说，堪称神器。

另外，它在终端沙箱 (Terminal Sandbox) 上也做得很好。它给智能体本地跑命令加了一层操作系统级别的隔离（比如 macOS 用的 sandbox-exec）。这能防止 AI 发疯误删你的核心文件，或者偷偷往外发乱七八糟的网络请求，安全性拉满。

💡 总结提炼 / 写在最后

总的来说，Antigravity CLI 绝不是一个简单的“换皮”产品，它是谷歌在 AI 编程领域从“你问我答”向“你授权我干活”迈出的巨大一步。

给你的实战建议：

  1. 不要犹豫，赶紧迁移：6 月 18 日老版本就停服了。现在的 Antigravity CLI 免费且支持 Sonnet 4.6 和 Opus 4.6，光冲着这个白嫖前沿模型的机会，也值得立刻装一个,以前的Gemini CLI不支持
  2. 转变你的工作思维：未来的程序员，手写代码的能力会被弱化。你要把自己当成一个 “技术包工头”。你要练的本事是：如何把一个大任务拆解清楚？如何给 AI 设定明确的边界？如何快速 Review (审查) AI 写的代码？
  3. 防爆指南：让 AI 动手大改代码之前，一定要先 git commit 保存当前状态！CLI 工具权限很大，每次让它干活前，确保你的代码随时可以回滚。

工具在变，但用工具创造价值的核心逻辑永远不变。如果你还没试过，今晚就搞个 TUN 模式，装上 Antigravity 体验一把什么叫“代码起飞”的感觉吧！
