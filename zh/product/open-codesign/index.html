关于产品

Open CoDesign 是 OpenCoworkAI 开发的开源、本地优先的设计工具，旨在作为 Claude Design 和 v0.dev 的替代品。它基于 Electron 构建，允许用户通过“自带模型 (BYOK)”或登录 ChatGPT 账号，将 Prompt 直接转化为精美的交互原型、幻灯片或网页。其核心采用 Agent 工作流，能自动规划、编写代码并自检生成物。特点是隐私安全、多模型支持（Claude、GPT、Ollama等）以及可导出 HTML、PPTX 等源码文件。

核心能力
  • 本地优先与隐私加密存储
  • 多模型兼容及自带密钥 (BYOK)
  • Agent 驱动的自动化原型设计
  • 支持 HTML/PDF/PPTX 多格式导出
  • 实时 Agent 任务面板与可视化微调
