notebooklm-py

由 teng-lin 研发
开源项目Python全球free
关于产品

notebooklm-py 是一个功能强大的非官方 Google NotebookLM Python API、CLI 及 MCP 服务。它支持完整编程访问 NotebookLM 的核心功能（如笔记本管理、多源导入、网页深层研究、带引用的对话等），并提供 Web UI 缺少的批量下载、思维导图 JSON 导出等高级特性。它可作为零 Token 推理和持久化记忆层，深度融入 OpenClaw、Claude Code 等 AI 智能体生态。

核心能力
  • 非官方全功能 API 与 CLI：支持对 NotebookLM 笔记本、数据源、便签及对话的完整编程控制
  • 多格式制品生成与导出：一键生成并批量下载音频、视频、幻灯片、评测问答及思维导图
  • 零 Token 智能体中继：可作为 OpenClaw 等 Agent 的高性能外部知识合成、检索与推理层
  • 内置 MCP 与 REST 服务：提供标准的 Model Context Protocol 服务，支持本地和远程跨平台集成
