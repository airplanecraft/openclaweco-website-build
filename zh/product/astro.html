关于产品

Astro 是一款现代 Web 网站构建工具，专注于极速的页面加载性能。它采用“群岛架构”，允许开发者使用 React、Vue、Svelte 等多种 UI 框架构建组件，默认输出零 JavaScript 的纯 HTML，仅在需要时按需加载交互脚本。Astro 结合了卓越的开发者体验与极简轻量的输出，非常适合构建博客、文档、官网等内容驱动型站点。

核心能力
  • 现代 Web 极速构建工具
  • 群岛架构与零 JS 默认输出
  • 无缝集成多 UI 框架 (React/Vue/Svelte等)
  • 支持静态生成 (SSG) 与服务端渲染 (SSR)
  • 丰富的官方插件与社区生态
