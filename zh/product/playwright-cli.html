playwright-cli

由 microsoft 研发
开源项目 TypeScript 全球 free #playwright
关于产品

playwright-cli 是由微软专门为 Claude Code、GitHub Copilot 等 AI 编码 Agent 打造的命令行工具。它将浏览器自动化封装为简洁的 CLI 命令（SKILLs），相比传统的 MCP 模式更加节省 Token，避免了将庞大的页面 Schema 或无障碍树载入 LLM 上下文。该工具支持 Headless/Headed 模式、多 Session 状态隔离与持久化，并内置可视化仪表盘用于实时监控和手动接管操作。

核心能力
  • Token 效率优化：避免向大模型传输冗长的页面数据与无障碍树
  • Agent 深度协同：专为高吞吐量编码 Agent 的命令行工作流设计
  • 可视化仪表盘：通过 playwright-cli show 实时监控会话并支持键鼠接管
  • 多会话管理：支持多浏览器 Session 隔离，可选择内存运行或磁盘持久化
  • 全能自动化指令：涵盖 DOM 操作、键鼠模拟、网络拦截、存储管理及录屏
