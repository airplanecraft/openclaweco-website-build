WeKnora

由 Tencent 研发
开源项目 Go 全球 freemium #go
关于产品

WeKnora 是腾讯开源的、基于大型语言模型（LLM）的知识框架，专注于企业级文档理解、语义检索和自主推理。它通过 RAG（检索增强生成）实现快速问答，利用 ReAct Agent 处理复杂多步任务，并创新性地提供 Wiki 模式，能将原始文档提炼成自维护、互链接的 Markdown 知识库及交互式知识图谱。支持多源数据摄取（飞书、Notion、语雀等），兼容20+LLM服务商，提供Langfuse可观测性，并支持私有化部署，旨在将分散的文档转化为可查询、可推理、持续演进的知识资产。

核心能力
  • RAG 知识检索与智能问答
  • ReAct Agent 自主推理与任务编排
  • Wiki 模式与动态知识图谱构建
  • 企业级多源数据集成与隐私部署
  • 全面的可观测性与LLM/VectorDB兼容
