lowfat

由 zdk 研发
开源项目 Rust 全球 free #agentic-coding-tool#cli#cost-reduction#developer-tools#llm
关于产品

lowfat 是一款轻量级的 CLI 工具，旨在通过过滤冗余的命令行输出来显著降低 AI Agent 的 Token 消耗。它通过内置或自定义的过滤器拦截 git、docker、ls 等常用命令的繁琐输出，精简内容后再传递给 AI。其特点包括本地优先（完全无遥测）、支持 UNIX 管道风格组合、提供多级压缩策略（lite/full/ultra），并能无缝集成到 Claude Code、OpenCode 等主流 AI Agent 环境中。

核心能力
  • 轻量级且高度可扩展的命令行过滤引擎
  • 本地优先执行，完全无数据遥测
  • 支持多级输出压缩策略 (lite/full/ultra)
  • 无缝集成主流 AI Agent (Claude Code, OpenCode, Pi)
  • 支持自定义 .lf DSL 插件与 UNIX 管道组合
