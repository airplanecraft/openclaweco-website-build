whatsapp-mcp

由 lharries 研发
开源项目 Go 全球 free
关于产品

这是一个专为 WhatsApp 开发的 Model Context Protocol (MCP) 服务器，允许大模型（如 Claude）直接访问和操作用户的个人 WhatsApp 账户。它采用双端架构：基于 Go 的桥接端利用 whatsmeow 库通过 Web API 实现与 WhatsApp 的实时连接，而 Python 端则通过 MCP 协议暴露搜索联系人、读取历史消息、发送多媒体文件（图片、音视频、文档）等工具。所有数据存储在本地 SQLite 中，确保隐私可控，并支持利用 FFmpeg 自动将音频转为 WhatsApp 语音格式。

核心能力
  • 多媒体全能交互
  • 本地隐私数据存储
  • 多设备API原生连接
  • 语音消息自动转码
  • 全量聊天上下文检索
