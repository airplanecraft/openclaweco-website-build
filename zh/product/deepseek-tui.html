DeepSeek-TUI

由 Hmbown 研发
开源项目Rust全球paid#rust
关于产品

DeepSeek TUI 是一个专为 DeepSeek V4 模型设计的终端原生编码 Agent，支持1M上下文和思维链推理，提供完整的工具使用能力。它在终端中运行，让 DeepSeek 模型直接访问用户工作区，进行文件读写、Shell 命令执行、Web 搜索、Git 管理以及子 Agent 编排。其特点包括原生 RLM 并行推理、实时展示思维链、多达百万级上下文处理，以及 Plan、Agent 和 YOLO 三种交互模式，支持会话保存与恢复、工作区回滚和实时成本跟踪。

核心能力
  • 终端原生编码 Agent 与 DeepSeek V4 模型集成
  • 支持 1M 上下文、思维链推理与并行 RLM
  • 全套工具集：文件操作、Shell、Git、Web 搜索、子 Agent
  • 多交互模式（Plan
  • Agent
  • YOLO）与会话管理
  • 工作区回滚、实时成本跟踪与多语言 UI
