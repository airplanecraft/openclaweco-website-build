winboat

由 TibixDev 研发
开源项目 TypeScript 全球 free #docker#docker-compose#linux#rdp#virtualization
关于产品

WinBoat 是一款专为 Linux 用户设计的开源容器化 Windows 应用运行工具。它通过在 Docker 或 Podman 容器中运行 Windows 虚拟机，并利用 FreeRDP 和 Windows RemoteApp 协议，将 Windows 应用程序无缝集成到 Linux 桌面，使其表现得像原生系统窗口。用户无需繁琐配置即可自动安装，并支持主目录挂载以实现无缝文件共享，轻松在 Linux 环境下运行 Windows 软件生态。

核心能力
  • 容器化虚拟化：基于 Docker/Podman 容器高效运行 Windows 虚拟机
  • RemoteApp 无缝集成：利用 FreeRDP 协议实现窗口级原生桌面融合
  • 极简自动安装：一键配置系统偏好、硬件规格并自动完成部署
  • 双向文件系统互通：自动挂载 Home 目录，实现跨系统无缝文件共享
