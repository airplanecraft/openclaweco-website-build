ag-kit

由 vudovn 研发
开源项目 TypeScript 全球 free
关于产品

AG Kit 是面向 Google Antigravity 运行时的 Agent 工程开发套件。它通过结构化的规则、技能、多角色 Agent 智能路由及持久化内存，建立了一套完整的本地 Agent 协作与编排体系。该套件内置了原生的 PreToolUse 安全钩子，可自动识别并阻止高危破坏性指令的执行。同时它还提供了命令行工具和 MCP 同步助手，帮助开发者安全地定义、测试和部署复杂的智能体工作流。

核心能力
  • 多角色智能路由与任务编排
  • 原生 PreToolUse 工具调用安全钩子
  • 声明式工作流与技能自动发现
  • 多模型上下文协议 (MCP) 安全同步
  • 基于 SemVer 的代理组件版本管理
