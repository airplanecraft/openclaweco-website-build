go-micro

开源项目Go全球free
关于产品

Go Micro 是一个面向 Go 语言的 Agent 运行容器（Harness）与微服务框架。它将 AI Agent、微服务和工作流融合在统一的运行时中。通过 Go Micro，开发者可将服务端点自动转化为 AI 可调用的工具，支持 MCP 和 A2A 协议进行 Agent 间协作。它提供模型、记忆、多步规划、任务委派和安全护栏等核心能力，非常适合构建需要操作复杂系统的分布式 AI Agent 生产级应用。

核心能力
  • 服务即工具：微服务端点自动转换为 AI 可调用的 Tool，支持从自然语言 Prompt 自动化生成服务
  • Agent 运行容器：内置模型、记忆、多步规划（Plan）和任务委派（Delegate）等核心 Harness 能力
  • 多协议互操作：原生支持 MCP（模型上下文协议）与 A2A（Agent-to-Agent）分布式 RPC 协作
  • 生产级安全护栏：提供 MaxSteps、LoopLimit 限制以及工具执行审批（ApproveTool）等运行安全机制
