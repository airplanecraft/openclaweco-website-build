关于产品

New API 是由 QuantumNous 开发的下一代大模型流量网关与 AI 资产管理系统。它基于 One API 进行二次开发，旨在解决多模型集成、流量分发与计费管理。其核心工作原理是将 OpenAI、Claude、Gemini 等不同厂商的 API 协议统一转换为 OpenAI 兼容格式，并提供智能路由、失败自动重试、多级权限控制及可视化看板。它特别支持了思维链输出、Realtime 实时接口及 Midjourney/Suno 扩展，是目前社区主流的私有化 AI 接口分发与管理工具。

核心能力
  • 多协议统一转换与分发
  • 智能负载均衡与重试机制
  • 全自动支付计费与额度管理
  • 支持思维链与实时语音接口
  • 多语言现代化管理看板
