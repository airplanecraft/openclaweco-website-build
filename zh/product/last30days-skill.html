last30days-skill

由 mvanhorn 研发
开源项目 Python 全球 free #ai-prompts#ai-skill#bluesky#claude#claude-code
关于产品

last30days-skill 是一个由 AI Agent 驱动的社交舆论搜索引擎。它打破平台壁垒，并行搜索并聚合 Reddit、X (Twitter)、YouTube、TikTok、Hacker News、GitHub 以及 Polymarket 预测赔率等多源平台，通过真实用户的点赞、互动和资金博弈对内容进行评分，最终由 AI 整理出高含金量的趋势简报。作为一款 Skill 插件，它无缝适配 OpenClaw、Claude Code、Cursor 等多 Agent 生态。

核心能力
  • 跨社交与预测市场多源并行搜索
  • 基于真实热度与资金赔率的智能评分机制
  • 多 Agent 平台原生集成 (OpenClaw/Claude Code/Cursor)
  • 零配置免 Key 快速启动与自动环境检测
  • 深度舆论合成与高赞评论提取
