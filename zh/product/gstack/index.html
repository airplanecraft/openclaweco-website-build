gstack

由 garrytan 研发
开源项目 TypeScript 全球 free #ai-software-engineering#claude-code#ai-agents#developer-tools
关于产品

gstack 是 Y Combinator 总裁 Garry Tan 基于 OpenClaw 生态开发的开源软件工厂，旨在将 Claude Code 转化为一个高效的虚拟工程团队。它通过提供 23 位专业“专家”和 8 种强大工具（以 slash 命令形式），覆盖软件开发全生命周期，包括构思、规划、构建、审查、测试和发布。gstack 显著提升了个人开发者的生产力，并支持与多种 AI 编码代理集成，是技术创始人、AI 新手以及技术负责人快速交付高质量产品的利器。

核心能力
  • 虚拟工程团队：23位专家角色与8种工具
  • 全生命周期管理：覆盖构思、规划、构建、审查、测试、发布
  • 多AI代理兼容：支持Claude Code、OpenClaw及其他主流AI编码器
  • Slash命令交互：基于Markdown的直观命令界面
  • 团队协作与自动更新：支持共享仓库自动同步
