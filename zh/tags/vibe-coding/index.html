DesktopCommanderMCP
开源社区

Desktop Commander MCP 是一个功能强大的模型上下文协议 (MCP) 服务器，旨在将桌面级开发工具直接集成到 AI 聊天界面中。它不仅能进行复杂的文件管理（支持 Excel、PDF、Word 深度编辑与搜索），还支持执行长时终端命令、管理后台进程以及在内存中运行 Python、Node.js 和 R 代码。其特点包括可视化的文件预览、远程 AI 控制、Markdown 编辑器以及通过 Docker 实现的安全隔离，让 AI 能够像资深开发者一样直接操控本地环境。

awesome-design-md
开源社区

awesome-design-md 是由 VoltAgent 维护的开源 DESIGN.md 集合库，旨在为 AI 编程代理提供精确的视觉系统指导。DESIGN.md 是 Google Stitch 提出的纯文本设计系统规范。开发者只需将对应的 Markdown 文件放入项目根目录，无需 Figma 导出或配置复杂的 JSON 结构，AI 即可读取品牌的主题色、排版和组件规则，并直接生成视觉高度一致的高质量 UI。
