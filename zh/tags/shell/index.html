claude-code-harness
开源社区

Claude Code Harness 是一个为 AI 编程助手（如 Claude Code）提供严格交付循环的工具插件。它将随意无序的 Agent 生成过程转换为“计划、工作、审查、发布”的可重复标准流程。它通过 `/harness-plan` 生成并让用户确认规范与计划文档，接着用 `/harness-work` 仅实现已批准的任务切片并配合 TDD，最后由 `/harness-review` 独立审查。特点是有效防止计划偏移，基于 Go 原生护栏引擎确保可靠的代码交付。

orbstack
开源社区

OrbStack 是一款极速、轻量级的 macOS 原生应用，旨在作为 Docker Desktop 和 WSL 的高性能替代方案。它能够高效运行 Docker 容器、Kubernetes 集群以及各种 Linux 发行版。其核心优势在于仅需 2 秒即可极速启动，并且大幅度降低了 CPU 和内存等系统资源占用。此外，OrbStack 还提供自动域名解析、无缝的 CLI 与本地文件系统集成、原生 Swift UI 以及 Rosetta 模拟器加速等特性，极大提升了容器化开发的体验和效率。
