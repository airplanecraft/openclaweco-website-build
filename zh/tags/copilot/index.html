9router
开源社区

9Router 是一款专为 AI 编程工具（如 OpenClaw、Claude Code、Cursor）设计的智能路由与 Token 节省器。其核心 RTK 技术能自动压缩 tool_result 内容，降低 20-40% 的 Token 消耗。它支持智能三级降级机制：优先使用订阅额度，耗尽后自动切换至廉价 API，最后退守免费模型。此外，它提供 OpenAI 与 Claude 协议的实时互转，支持多账号轮询及配额追踪，确保 AI 辅助编程工作流的高可用与低成本。

agentmemory
开源社区

agentmemory 是专为 AI 编码智能体（如 OpenClaw、Claude Code、Cursor）设计的持久化内存系统。它基于 iii 引擎构建，通过静默捕获 Agent 的操作并将其压缩为可搜索的混合记忆，解决了开发者在不同会话间重复解释架构、Bug 和偏好的痛点。该工具利用知识图谱、置信度评分和本地嵌入技术，在无需外部数据库的情况下实现了极高的检索准确率，能显著降低 Token 消耗，让智能体具备真正的跨会话记忆能力。

OpenMontage
开源社区

OpenMontage 是首个开源的智能体视频制作系统，能将 AI 编程助手转化为完整的视频制作工作室。用户只需用自然语言描述需求，Agent 即可自主处理调研、脚本撰写、素材生成、剪辑与最终渲染。该系统支持通过分析参考视频生成方案，不仅能动态化静态图片，还能利用免费素材或 AI 生成 API 制作真正的视频。它内置 Remotion 与 HyperFrames 双渲染引擎，并具备多维度自审机制，支持完全免费的本地工作流。
