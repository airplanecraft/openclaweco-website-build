symphony
开源社区

Symphony 是 OpenAI 推出的一款前瞻性 AI Agent 产品，旨在重塑企业级项目工作流管理。它能够将复杂的项目智能分解为一系列隔离且高度自主的执行单元，并通过强大的AI代理编排机制，使AI Agents独立完成从需求分析、方案规划到代码生成和测试部署等全链路任务。Symphony 将团队成员从繁琐的代码细节监督中解放出来，使其能聚焦于宏观项目战略、业务目标设定及最终成果验收。这显著提升了项目整体效率、加速产品上市，并优化人力资源配置，为追求高效与创新的组织提供关键赋能。目前，Symphony 作为一项工程预览版，正面向信任环境下的测试开放。

OpenClaw
开源社区

OpenClaw 是一个领先的开源自主AI Agent平台，赋能个人用户在本地设备部署并运行专属AI助手。它通过逾20种主流消息应用（如WhatsApp、Telegram、Discord等）无缝连接大型语言模型与本地文件系统。平台具备强大的多模态交互能力，涵盖Shell命令执行、文件管理、网页自动化、语音听写及实时画布控制。OpenClaw 致力于提供快速、始终在线且高度可定制的个人助手体验，并以严格的DM安全策略确保用户隐私。凭借超336K的GitHub星标，它已成为全球最大的AI Agent开源项目之一，致力于助力实现设备智能化与任务自动化。

edict
开源社区

Edict 是一款基于古代“三省六部”制度设计的 OpenClaw 多智能体协作架构。它由12个专属 Agent 组成，包含太子分拣、中书规划、门下审核、尚书派发及六部并行执行。相比传统框架，它引入了强制的制度性审核机制（可封驳打回）和军机处实时可视化看板，支持任务中途干预、热切换模型和完整流转审计，彻底解决了多智能体协作中的黑盒与失控问题。

NemoClaw
科技巨头

NVIDIA NemoClaw 是英伟达推出的开源参考堆栈，专门用于在 OpenShell 环境中安全地运行 OpenClaw 常驻智能助手。它通过 NVIDIA OpenShell 运行时提供加固的沙盒环境（利用 Landlock、seccomp 和网络命名空间），实现了自主 Agent 的分层安全保护。核心功能包括引导式安装、状态管理、路由推理以及实验性的模型路由器，能够根据查询复杂度自动选择最经济高效的模型，确保 Agent 在复杂任务中的安全性与性能平衡。

pentagi
开源社区

PentAGI 是由 vxcontrol 开发的开源自主渗透测试 AI 智能体平台。它基于多智能体（Agent）架构，在隔离的 Docker 沙箱环境中自动规划并执行安全测试。系统集成了 20 多种专业安全工具（如 nmap、metasploit），并结合 Graphiti 知识图谱与 pgvector 长期记忆系统，实现上下文理解与经验累积。支持主流大模型，提供详细的漏洞报告和可视化监控，是安全研究员的智能化助手。
