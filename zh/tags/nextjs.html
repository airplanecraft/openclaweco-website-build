onyx
开源社区

Onyx 是一个开源的 AI 平台，作为大型语言模型（LLM）的应用层，提供功能丰富的界面，易于部署和托管。它通过 Agentic RAG、深度研究、网络搜索、代码执行和文件创建等高级功能，增强 LLM 的能力。Onyx 支持超过 50 种基于索引的连接器，并提供轻量级和标准两种部署模式，同时为企业用户提供协作、单点登录、RBAC 和审计等增强功能。它提供社区版（MIT 许可）和企业版，可部署在 Docker、Kubernetes 等多种环境中。

blinko
开源社区

Blinko 是一款由 AI 驱动的开源卡片式笔记工具，专为捕捉瞬间灵感而设计。它通过集成的 RAG（检索增强生成）技术，允许用户利用自然语言轻松检索历史笔记。产品核心优势在于数据所有权，支持私有化部署，确保个人知识库的隐私安全。其架构基于 Tauri，轻量且高效，提供全平台支持与 Markdown 渲染能力，帮助用户快速构建碎片化的第二大脑。

ai-website-cloner-template
开源社区

AI Website Cloner Template 是由 JCodesMore 开源的模版，旨在利用 AI 编程智能体（如 Claude Code）将任意网站逆向工程为干净、现代的 Next.js 代码库。它通过 `/clone-website` 触发多阶段管线：自动分析目标网页并提取设计令牌与资产、撰写组件规范，随后在 Git 工作区中调度多个 AI 智能体并行构建各个区域，最后进行合并装配与视觉对比，适合平台迁移与源码重构。
