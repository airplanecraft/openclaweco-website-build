multica
开源社区

Multica 是一个开源的托管 Agent 平台，旨在将代码 Agent 转化为真实的团队成员，实现人类与 AI 的高效协作。它允许用户像分配给同事一样将任务分配给 Agent，Agent 会自主接管工作、编写代码、报告障碍并更新状态。Multica 提供完整的 Agent 生命周期管理，包括任务分配、执行监控和技能复用，支持多种主流 Agent CLI（如 OpenClaw、Gemini 等），并提供统一的运行时管理和多工作区隔离，作为面向团队的开放式基础设施，显著提升开发效率。

open-design
开源社区

Open Design 是 Claude Design 的开源、本地优先替代方案。它通过检测本地环境中的 16 种主流编程 Agent CLI（或兼容的 BYOK 代理）作为设计引擎，由 137 种可组合的 Skill 与 150 个品牌级设计系统驱动。工作时，本地守护进程会生成真实项目文件夹，Agent 根据内置的视觉方向与检查表生成设计代码，并通过沙盒 iframe 实时渲染工件。它还支持图片与视频等多模态生成，提供零锁定的专业级设计交付体验。

html-anything
开源社区

html-anything 是一款专为 Agent 时代设计的本地优先 HTML 编辑器。它颠覆了传统 Markdown 写作，通过探测并复用本地已登录的 8 种主流 AI 编程助手（如 Claude Code、Cursor 等），无需额外 API Key，即可将输入（如 Markdown、数据或笔记）秒转为排版精美的单文件 HTML。内置 75 个涵盖杂志、幻灯片、社交卡片等专业设计模板，支持一键无缝导出至微信、知乎、X 平台或保存为高分 PNG，实现“生成即发布”。
