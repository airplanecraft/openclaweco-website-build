cmux
开源社区

cmux 是一个基于 Ghostty 的 macOS 终端，专为 AI 编码 Agent 设计。它通过引入垂直标签页、智能通知系统和内置浏览器，优化了开发者与 AI Agent 协作的体验。cmux 旨在解决传统终端在多 Agent 并行工作时上下文丢失和通知混乱的问题，提供专注于 AI Agent 交互的定制化功能，如 Agent 状态通知环、聚合通知面板和可脚本化的内置浏览器。它以原生 macOS 应用构建，启动快速，内存占用低，并支持 SSH 工作区和 Claude Code Teams 等高级功能。

orca
开源社区

Orca 是一个面向开发者的 AI 编排工具，旨在提升开发效率百倍。它允许用户在独立的工作区（worktree）中并行运行 Claude Code、Codex 等多种 AI Agent，并统一管理。Orca 内置了版本控制、GitHub 集成、多 AI Agent 终端，以及创新的“工作区浏览器和设计模式”，用户可以直接点击UI元素将其作为上下文发送给AI。它还提供命令行接口，方便从终端编排AI Agent。
