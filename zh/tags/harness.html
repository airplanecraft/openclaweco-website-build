DeerFlow（深度探索与高效研究流程）是一个由字节跳动开发的开源超级Agent协调框架，旨在通过编排子Agent、内存和沙盒来执行各种复杂任务。它核心驱动力在于可扩展的技能系统，支持用户自定义和集成功能。DeerFlow 2.0是其全新重写的版本，提供了更强大的Agent能力和灵活的部署选项，推荐搭配 Doubao-Seed-2.0-Code、DeepSeek v3.2 和 Kimi 2.5 等大型语言模型使用，并集成了InfoQuest智能搜索与抓取工具集。

open-code-review
开源社区

OpenCodeReview 是由阿里巴巴开源的 AI 驱动代码评审（Code Review）CLI 工具。它源自阿里内部服务万名开发者的实践，结合了确定性工程与 Agent 混合架构。该工具通过 Git diff 读取变更，并借助具备工具调用能力的 AI Agent 进行精准的行级代码评审。其具备智能文件打包、高精度定位及规则匹配等特点，相比通用 Agent 能以更少的 Token 消耗实现更精准、噪声更低的评审反馈。

agentmemory
开源社区

agentmemory 是专为 AI 编码智能体（如 OpenClaw、Claude Code、Cursor）设计的持久化内存系统。它基于 iii 引擎构建，通过静默捕获 Agent 的操作并将其压缩为可搜索的混合记忆，解决了开发者在不同会话间重复解释架构、Bug 和偏好的痛点。该工具利用知识图谱、置信度评分和本地嵌入技术，在无需外部数据库的情况下实现了极高的检索准确率，能显著降低 Token 消耗，让智能体具备真正的跨会话记忆能力。
