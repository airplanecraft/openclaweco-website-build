QtScrcpy
开源社区

QtScrcpy是一款由barry-ran基于scrcpy项目开发的高性能开源跨平台安卓设备投屏与控制软件。它无需Root权限，即可通过USB或WiFi网络实现安卓设备屏幕的实时显示与精准操控。QtScrcpy以其轻量、流畅（30-60 FPS）、高清（1080P+）、低延迟（35-70ms）及快速启动（约1秒）特性，提供无侵入式的卓越体验。与原始scrcpy相比，QtScrcpy采用Qt框架构建直观GUI，C++异步编程结合OpenGL渲染，显著提升了用户交互性和性能。其核心亮点包括强大的自定义按键映射功能，支持键鼠畅玩手游，以及高效的多设备群控能力，使其成为游戏玩家和多设备管理用户的理想选择。

Wazuh
开源社区

Wazuh是一个领先的免费开源统一安全平台，专为现代IT环境的威胁预防、检测与响应而设计。它为企业提供全面的XDR（扩展检测与响应）和SIEM（安全信息与事件管理）能力，覆盖本地数据中心、虚拟化基础设施、容器化应用以及多云环境（如AWS、Azure、Google Cloud）。Wazuh通过轻量级端点代理、中央管理服务器和与Elastic Stack的深度集成，实现日志数据分析、高级入侵检测、实时文件完整性监控、精确漏洞检测和配置评估。此外，它还提供强大的事件响应机制、专门的云安全与容器安全功能，并帮助组织轻松满足PCI DSS、GDPR等严格的合规性要求。Wazuh以其卓越的功能、可扩展性和灵活性，成为各类组织构建弹性安全防御体系的理想选择。

LiteRT-LM
开源社区

LiteRT-LM 是 Google 推出的一款生产级、高性能、开源推理框架，专为在边缘设备上高效部署大型语言模型（LLMs）而设计。它通过利用 GPU 和 NPU 加速器实现卓越性能，支持 Android、iOS、Web、桌面和 IoT 等多种平台。该框架还具备多模态处理（视觉和音频）、工具使用（函数调用）能力，并广泛兼容 Gemma、Llama、Phi-4 等主流模型。它已赋能 Google 旗下的 Chrome、Chromebook Plus 和 Pixel Watch 等产品的设备端生成式 AI 体验。

llama.cpp
开源社区

llama.cpp 是由 ggml-org 开发的开源 C/C++ 大模型推理引擎，旨在以最简设置在各类硬件上实现高效的本地及云端推理。其核心基于无外部依赖的纯 C/C++ 架构与 ggml 库，广泛支持 Metal、CUDA 和 Vulkan 等硬件加速及 CPU+GPU 混合推理。特点是高度便携跨平台、原生支持 GGUF 格式与 1.5 到 8-bit 的模型量化，并自带 REST API 服务与 WebUI。

zvec
开源社区

Zvec 是阿里巴巴开源的进程内（嵌入式）向量数据库。它设计轻量且极速，可直接嵌入到应用程序中运行，无需部署外部服务器。Zvec 支持稠密与稀疏向量、标量过滤及原生全文检索，并提供混合检索功能。通过引入 DiskANN 磁盘索引技术，它能在保证低延迟检索的同时大幅降低内存占用，配合预写日志（WAL）确保数据高可靠性，非常适合边缘设备、桌面端和服务器等多种场景。

intelligent-terminal
开源社区

Intelligent Terminal 是微软基于 Windows Terminal 开发的实验性分支，原生集成了 AI 智能体。它支持任何兼容 ACP 协议的命令行智能体（如 GitHub Copilot、Claude）。该终端作为本地传输层，可自动将 Shell 输出和上下文传递给 AI，实现错误自动检测、智能修复建议、侧边栏对话和后台任务托管，无需手动复制粘贴，大幅提升命令行交互效率。
