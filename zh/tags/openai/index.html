CLIProxyAPI
开源社区

CLIProxyAPI 是一款专业的代理服务器，旨在为开发者提供统一、高效的命令行界面（CLI）大型语言模型访问方案。它无缝封装 Gemini CLI、Antigravity、ChatGPT Codex、Claude Code、Qwen Code 和 iFlow 等服务，转换为兼容 OpenAI/Gemini/Claude/Codex 的标准化 API 接口。开发者因此能便捷地通过现有订阅或 CLI 访问主流 LLM。核心功能涵盖多账户负载均衡、支持 OAuth 认证的 Codex 与 Claude Code、多模态输入、函数调用及流式响应。此外，产品深度集成 Amp CLI 及 IDE 扩展，提供智能路由与模型回退，并附带可复用 Go SDK，显著提升 AI 编程与应用开发效率。

one-api
开源社区

One API 是一个开源的大模型接口管理与分发系统，支持通过标准的 OpenAI API 格式访问包括 OpenAI、Claude、Gemini、DeepSeek 及国内主流模型（如文心一言、通义千问等）在内的数十种模型。其核心功能包括多渠道负载均衡、流式传输、令牌额度管理、用户/渠道分组倍率设置以及模型映射。支持 Docker 快速部署和多机横向扩展，是目前开发者构建统一 AI 聚合接口的首选网关工具。

edict
开源社区

Edict 是一款基于古代“三省六部”制度设计的 OpenClaw 多智能体协作架构。它由12个专属 Agent 组成，包含太子分拣、中书规划、门下审核、尚书派发及六部并行执行。相比传统框架，它引入了强制的制度性审核机制（可封驳打回）和军机处实时可视化看板，支持任务中途干预、热切换模型和完整流转审计，彻底解决了多智能体协作中的黑盒与失控问题。

new-api
开源社区

New API 是由 QuantumNous 开发的下一代大模型流量网关与 AI 资产管理系统。它基于 One API 进行二次开发，旨在解决多模型集成、流量分发与计费管理。其核心工作原理是将 OpenAI、Claude、Gemini 等不同厂商的 API 协议统一转换为 OpenAI 兼容格式，并提供智能路由、失败自动重试、多级权限控制及可视化看板。它特别支持了思维链输出、Realtime 实时接口及 Midjourney/Suno 扩展，是目前社区主流的私有化 AI 接口分发与管理工具。
