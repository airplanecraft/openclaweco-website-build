alt-tab-macos
开源社区

AltTab 是一款专为 macOS 开发的增强型窗口切换工具。原生的 macOS 切换器仅支持在“应用程序”层级间切换，而 AltTab 完美引入了 Windows 经典的 Alt-Tab 逻辑，允许用户直接在所有独立“窗口”间进行可视化切换。它的核心特点包括：提供实时窗口缩略图、支持多显示器及多空间 (Spaces) 过滤、以及提供极高自由度的快捷键自定义。近期推出 Pro 版后，它更支持高级窗口搜索与动态外观适配，是多任务处理与 Windows 迁移用户的效率利器。

orbstack
开源社区

OrbStack 是一款极速、轻量级的 macOS 原生应用，旨在作为 Docker Desktop 和 WSL 的高性能替代方案。它能够高效运行 Docker 容器、Kubernetes 集群以及各种 Linux 发行版。其核心优势在于仅需 2 秒即可极速启动，并且大幅度降低了 CPU 和内存等系统资源占用。此外，OrbStack 还提供自动域名解析、无缝的 CLI 与本地文件系统集成、原生 Swift UI 以及 Rosetta 模拟器加速等特性，极大提升了容器化开发的体验和效率。

omlx

oMLX 是一款专为 Mac (Apple Silicon) 优化的本地大模型推理服务器，是 OpenClaw 等 Agent 生态的高性能后端。它基于 MLX 框架，支持文本 LLM、视觉模型 (VLM)、OCR 及向量模型。核心技术包括“冷热分层 KV 缓存”：常用缓存驻留内存，溢出部分转储至 SSD 并支持重启后复用，极大提升了 Claude Code 等工具处理长上下文的响应速度。提供原生 macOS 菜单栏应用与 Web 控制面板，支持多模型并发调度、LRU 自动显存管理及 MCP 协议。
