playwright-cli
开源社区

playwright-cli 是由微软专门为 Claude Code、GitHub Copilot 等 AI 编码 Agent 打造的命令行工具。它将浏览器自动化封装为简洁的 CLI 命令（SKILLs），相比传统的 MCP 模式更加节省 Token，避免了将庞大的页面 Schema 或无障碍树载入 LLM 上下文。该工具支持 Headless/Headed 模式、多 Session 状态隔离与持久化，并内置可视化仪表盘用于实时监控和手动接管操作。

crawlee
开源社区

Crawlee是一个由Apify开发的网络抓取和浏览器自动化库，旨在帮助开发者快速构建可靠的爬虫。它能够模拟人类浏览行为，有效规避现代反爬机制。该库提供统一的接口来支持HTTP和无头浏览器（如Playwright、Puppeteer）抓取，并具备持久化请求队列、可插拔的数据存储、自动代理轮换和会话管理等核心功能，同时支持CLI工具进行项目快速启动，并可轻松部署至云平台。
