Chat2DB
开源社区

Chat2DB 是 CodePhiliaX 推出的一款智能数据库工具和多功能 SQL 客户端。它深度融合人工智能技术，提供 AI 驱动的智能 SQL 生成与智能数据报告功能，显著提升数据开发与分析效率。产品具备直观的图形用户界面（GUI），广泛支持 MySQL、Oracle、PostgreSQL 等超过 16 种主流数据库（并持续扩展至 100+ 种）。其核心功能包括全面的数据库管理、数据结构同步、数据迁移、数据导入导出以及代码生成等，旨在为用户提供一个高效、一体化的数据库操作、报表生成及数据治理解决方案。

open-cdm
开源社区

CloudDM (open-cdm) 是由 ClouGence 推出的开源数据库管理与协作平台。它通过统一的 Web 控制台提供多源数据库访问、可视化查询及 SQL 审计功能。产品核心采用资源与功能分离的 RBAC 授权模型，支持细粒度权限管控、敏感数据脱敏及数据库 CI/CD 变更流水线。其内置工作流引擎可对接钉钉、飞书等企业办公软件，旨在解决团队协作中的数据库安全合规与开发运维效率问题。

JeecgBoot
开源社区

JeecgBoot 是一款基于 SpringBoot3 和 Vue3 的企业级 AI 低代码平台。它首创“低代码+零代码”双模式，通过 AI Skills 实现自然语言编程，支持一句话生成 CRUD 代码、流程图、报表及大屏。平台内置类似 Dify 的 AI 应用管理系统，支持 RAG 知识库与多模型接入（如 DeepSeek、ChatGPT），通过“AI生成+手工合并”模式大幅提升开发效率，同时兼顾系统的灵活性与信创兼容性。

spring-ai-alibaba
开源社区

Spring AI Alibaba 是阿里云推出的生产级 AI 开发框架，旨在简化 Agentic、工作流及多智能体应用的构建。它深度集成 Spring 生态，提供 Agent Framework 开发框架、Graph 状态机运行时以及可视化 Admin 管理后台。核心功能涵盖多智能体编排（顺序、并行、路由、循环）、上下文工程（人机协同、上下文压缩）、多模态支持及实时语音交互。通过 A2A 协议实现分布式智能体协作，并兼容 MCP 协议，助力 Java 开发者构建高性能 AI 应用。
