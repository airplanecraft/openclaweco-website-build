Midjourney-Prompt-Gen

Midjourney-Prompt-Gen 是 Midjourney OS 推出的一款专业级反向提词重构引擎。它旨在革新用户在文生图AI平台上的创作流程，通过将复杂视觉构想或现有图像智能转化为高效、精确的文本提示。该产品深度分析用户意图与图像细节，进行智能重构并生成细致的Prompt，从而显著降低了提示工程的专业门槛。其核心功能涵盖将抽象视觉概念具象化为可执行的Prompt，以及对既有提示进行深度优化与迭代。Midjourney-Prompt-Gen 有效赋能艺术家、设计师及内容创作者，使其能够更便捷、高效地实现创意，极大地提升AI图像生成的质量与效率。

caveman
开源社区

caveman 是由 JuliusBrussee 开发的一款智能代理（Agent）技能/插件，旨在通过模仿“原始人式”的简洁语言来大幅减少大型语言模型（LLM）的输出令牌数量，同时保持技术内容的完整性和准确性。它能将输出令牌削减约 75%，并提高响应速度约 3 倍。此外，它还提供了输入压缩工具，能削减约 46% 的输入令牌。产品支持多种简洁程度（Lite, Full, Ultra, 文言文模式），并提供用于生成简洁提交信息和代码审查的专用命令。
