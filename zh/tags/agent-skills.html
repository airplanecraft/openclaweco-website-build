OpenCodeReview 是由阿里巴巴开源的 AI 驱动代码评审（Code Review）CLI 工具。它源自阿里内部服务万名开发者的实践，结合了确定性工程与 Agent 混合架构。该工具通过 Git diff 读取变更，并借助具备工具调用能力的 AI Agent 进行精准的行级代码评审。其具备智能文件打包、高精度定位及规则匹配等特点，相比通用 Agent 能以更少的 Token 消耗实现更精准、噪声更低的评审反馈。

Open Design 是 Claude Design 的开源、本地优先替代方案。它通过检测本地环境中的 16 种主流编程 Agent CLI（或兼容的 BYOK 代理）作为设计引擎，由 137 种可组合的 Skill 与 150 个品牌级设计系统驱动。工作时，本地守护进程会生成真实项目文件夹，Agent 根据内置的视觉方向与检查表生成设计代码，并通过沙盒 iframe 实时渲染工件。它还支持图片与视频等多模态生成，提供零锁定的专业级设计交付体验。

开源社区

Zvec 是阿里巴巴开源的进程内（嵌入式）向量数据库。它设计轻量且极速，可直接嵌入到应用程序中运行，无需部署外部服务器。Zvec 支持稠密与稀疏向量、标量过滤及原生全文检索，并提供混合检索功能。通过引入 DiskANN 磁盘索引技术，它能在保证低延迟检索的同时大幅降低内存占用，配合预写日志（WAL）确保数据高可靠性，非常适合边缘设备、桌面端和服务器等多种场景。
