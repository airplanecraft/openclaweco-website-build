Anthropic's Claude Platform Now Generally Available on AWS for Seamless Integration and Direct Access

May 12, 2026 | 3 Min Read
#claude#aws#anthropic#ai agent#iam

Anthropic today announced the general availability of #Claude Platform on #AWS, offering customers direct access to #Anthropic's native Claude Platform experience via their AWS account. This integration eliminates the need for separate credentials, contracts, or billing relationships, positioning AWS as the first cloud provider to offer such seamless access to the native Claude Platform.

The Claude Platform on AWS provides the same APIs, features, and console experience available directly through Anthropic. Key capabilities include the Messages API, Claude Managed Agents (beta), advisor tool (beta), web search and web fetch, MCP connector (beta), Agent Skills (beta), code execution, and files API (beta). A comprehensive list of functionalities is available in the Claude Platform documentation.

Integration with AWS streamlines access through familiar services. Authentication utilizes existing AWS IAM credentials, removing the need for separate API keys. Billing is handled via AWS Marketplace on a consumption basis, allowing users to track and manage AI spending alongside other AWS services. Furthermore, all activity is captured in AWS CloudTrail for consistent monitoring, auditing, and investigation of AI usage.

Anthropic operates Claude Platform on AWS, with underlying requests and data processed outside the AWS security boundary. This design caters to teams without strict regional data residency requirements and complements existing Claude models available on Amazon Bedrock, offering flexibility in how users access Claude's capabilities.

To get started, customers can activate Claude Platform on AWS through the AWS Marketplace. The process involves three main steps after activation: creating a workspace, authenticating, and making an API call.

A workspace allows for the separation of projects, environments, or teams while maintaining centralized billing and administration. It also functions as the primary AWS Identity and Access Management (IAM) resource for Claude Platform on AWS, enabling granular access control through IAM policies based on the workspace ARN.

Claude Platform on AWS supports authentication using existing AWS IAM credentials, simplifying secure access management.
