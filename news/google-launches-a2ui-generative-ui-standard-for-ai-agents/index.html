Google Unveils A2UI v0.9: A Framework-Agnostic Standard for Generative UIs in AI Agents

April 19, 2026 | 3 Min Read
#a2ui#ai agents#generative ui#ui standard#sdk

Google has officially launched #A2UI version 0.9, a new framework-agnostic standard for generative user interfaces. This protocol enables #AI agents to dynamically construct UI elements by drawing from an application's existing components across various platforms, including web and mobile.

The latest A2UI 0.9 release includes a shared web core library, an official React renderer, and updated renderers for Flutter, Lit, and Angular. Additionally, Google has introduced a new Agent #SDK, designed to streamline development and installation processes via Python, with upcoming versions planned for Go and Kotlin. Key enhancements in this update also feature client-defined functions, client-server data synchronization, and improved error handling mechanisms.

Google highlights the rapid expansion of the A2UI ecosystem, noting integrations with AG2, A2A 1.0, Vercel's json-renderer, and Oracle's Agent Spec. Early sample applications built using A2UI include a "Personal Health Companion" from Rebel App Studio and a "Life Goal Simulator" developed by Very Good Ventures. Comprehensive documentation and examples are available at A2UI.org.
